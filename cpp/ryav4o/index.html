chunk-fixedallocator-smallobjallocator(用户使用的) 从低阶到高阶

chunk 块，chunk.pData会指向分配的那一大块内存的首地址，chunk.firstAvailableBlock第一个可用区块位于这一大块内存的哪个位置 就是个索引，根据pdata和这个索引就能找到那个区块的首地址(其他被分配出去了),chunk.BlockAvailable_目前可用的区块数。比如上图的这个例子 chunk内存块被切为64块其中索引为0-3的区块被分配出去了，第一个可用区块的索引是4，余下可用60块可用。

void FixedAllocator::Chunk::Init(std::size_t blockSize,unsigned char blocks)
{
    pData_ = new unsigned char[blockSize*blocks];//array new调用malloc申请 区块数量*每个区块大小 这个总大小的内存
    //完成第一步chunk.pData指向分配的那一大块内存的首地址
    Rest(blockSize,blocks);//对chunk的其他成员变量进行初始化
}
void FixedAllocator::Chunk::Reset(std::size_t blockSize,unsigned char blocks)
{
    firstAvailableBlock_ = 0;//此块chunk刚申请 所以可用的第一块一定是0块
    blockAvailable_ = blocks;//刚申请可用块数为传入的blocks块

    //跟之前嵌入式指针obj有点像
    //将每块内存(1块blocksize大)的首字节用于存当前内存的标号
    //首字节保存索引(obj是 大内存的前四个字节被转成obj类型用于保存指针 现在是每块内存的前1个字节转为unsiged char型用于保存此块内存的索引--从1开始)
    //从1-blocks 效果像上图
    unsigned char i = 0;
    usinged char* p = pData_;//指向首块
    for(;i!=blocks;p+=blockSize)
    *p = ++i;
}
void FixedAllocator::Chunk::Release()
{
	delete[] pData_;//释放申请到的这块大内存 因为是array new申请的所以要array delete来释放
}

chunk.pData会指向分配的那一大块内存的首地址，chunk.firstAvailableBlock_第一个可用区块位于这一大块内存的哪个位置 就是个索引，根据pdata和这个索引就能找到那个区块的首地址(其他被分配出去了),chunk.blockAvailable_目前可用的区块数

上图中的数字是firstAvailableBlock_计数规则从0开始，稍微解释一下 当前第一个可用块为4号(从0开始计数)，四号块 其内存空间的第一个字节用于保存下个可用块 这个值是3(3号 从0开始计数)–图中灰色箭头就是表达了 本块内存和下个可用块的关系。4块的下个可用为3块，3块的下个可用为2块，2块下个可用为1块，1块下个可用为0块，0块下个可用为5块，5块下个可用为6块，6块下个可用为7块。

void* FixedAllocator::Chunk::Allocate(std::size_t blockSize)
{
    if(!blockAvailable_)return 0;//目前可用块数为0 直接返回0
    unsigned char* pResult = pData_ + (firstAvailableBlock*blockSize);
    //指向第一块可用区块
    firstAvailableBlock_ = *pResult;//取区块的内容注意pResult 为char*所以取出的内存就是char型的
    // 因为在reset中我们将每一区块的第一字节保存了此区块的索引--索引从1开始。
    // 正因为索引从1开始，而firstAvailableBlock_计数规则又是从0开始
    // 正好*pResult值就充当了当当前区块分出去后下一可用区块的标号(firstAvailableBlock_计数规则从0开始)
    --blockAvailable_;//分出当前第一个可用区块后 总区块数-1
    return pResult;//返回第一个可用区块 给要求者
}

相比于gnu std allocator，loki采用数组代替链表 索引代替指针的方式。注意我们使用的是数组，在allocator时不是像链表一样将节点从链表中剥离，剥离后我们无法再找到这个节点。loki用的是数组，当我们将这一块的使用权交出去后，依旧还是可以由pDdata_首地址和索引找到这块使用权交出去的内存块。
