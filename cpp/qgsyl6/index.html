1 VC6 malloc()

之前讲过VC6 malloc后得到的一块内存的实际布局

其中block size是我们申请的大小(图中我们申请的是ch 十六进制 对应12字节)，上下cookie占用8个字节，当我们申请的内存比较小 cookie的在这块内存(比如我们申请的12字节)的占比比较大，这造成了较大的浪费，所以在std::allocator中对于申请较大的内存直接调用malloc,而对于较小的内存为了减少cookie带来的浪费用的就是我们之前讲的先申请一大块内存专门用于某个 大小较小的对象 的内存分配(大内存 分为sizeof(对象)大小 的节点 并用指针将这些节点首位相连变为一条链表)。

我们工程中遇到较多的是 需要海量的小区块这种情况，对象的占用大小不大，但是需要申请大量的对象。 此时大量对象造成的cookie浪费是无法忍受的，所以就需要allocator对大小较小的对象进行内存管理。

2 标准分配器实现 std::allocator

不同编译器对于分配器的实现都有所不同

vc6 的allocator只是直接使用全局版本的 ::operator new，::operator delete (背后就是 malloc和free)来完成allocate()和deallocate() 并没有什么改进。所有内存块都是带着cookie

BC5标准分配器也是直接使用全局版本的 ::operator new，::operator delete (背后就是 malloc和free)来完成allocate()和deallocate() 并没有什么改进。所有内存块都是带着cookie(去除cookie的前提区块的大小都一样大即同种数据类型放在一起，但如果一块内存为不同类别分配内存，需要cookie记录每个分配出去的空间大小)

G2.9(Gnu 2.9)也是直接使用全局版本的 ::operator new，::operator delete (背后就是 malloc和free)来完成allocate()和deallocate() 并没有什么改进。

这个allocator的头文件中有这样的注释

此头文件并没有被include到任何的容器类中，此文件仅仅是为了与老版本兼容。

G2.9的所有容器使用的分配器不叫std::allocator而是叫std::alloc,

template<class T,class Alloc=alloc>
class vector{....};
void* p = alloc::allocate(512);//alloc是个类 allocate，deallocate是其中的静态函数才可以这样不通过对象来直接调用
alloc::deallocate(p,512);

在较新的Gnu编译器版本中 比如GNU4.9 std::alloc叫做__gnu_cxx::__pool_alloc(体制外非std分配器)，其实跟2.9版没有区别 就是变量名称换了

就是我们之前写的链表的形式

两个的allocate的行为也都是一样的

GNU4.9体制内的分配器std::allocator实现(容器的默认分配器)

std::allocator 继承自 __allocator_base,s__allocator_base是__gnu_cxx::new_allocator的宏定义，在__gnu_cxx::new_allocator也是直接使用全局版本的 ::operator new，::operator delete (背后就是 malloc和free)来完成allocate()和deallocate() 并没有什么改进。

鼓励使用__gnu_cxx::__pool_alloc这个链表实现的分配器下面是个使用的例子

#include <ext\pool_allocator.h>//要使用std::allocator外的allocator就需要自行include<ext\...>
vector<int,__gnu_cxx::__pool_alloc<int>> v;
template<typename Alloc>
void cookie_test(Alloc alloc,size_t n)
{
    typename Alloc::value_type *p1,*p2;
    p1 = alloc.allocate(n);
    p2 = alloc.allocate(n);
    cout<<”p1=”<<p1<<”  p2=”<<p2<<endl;
    alloc.deallocate(p1,sizeof(typename Alloc::value_type));
    alloc.deallocate(p2,sizeof(typename Alloc::value_type));
}
cookie_test(__gnu_cxx::__pool_alloc<double>(),1);//调用测试
//构造了一个临时分配器对象
//p1 = 0xae4138 p2 = 0xae4140 相距08h = sizeof(double)表示不带cookie
