4 new handler(new中出现错误的异常处理)

当op new无法分配出你所申请的memory,会抛出一个异常std::bad_alloc exception。

某些老的编译器则是不抛出异常返回0，我们现在也可以通过new(nothrow) Foo来实现不抛出异常。

如果抛出异常，在抛出异常之前会先(不止一次)

p==0只要malloc返回0，就循环调用_callnewh(size),_callnewh(VC下叫这个)就是我们的new_handler,在_callnewh调用完后 异常不一定会被抛出(前提是我们的new_handler起作用了 出现了一些空余空间)，再次循环

调用一个由客户(我们)定义的handler,一下是new handler的形式和设定方法

typedef void(*new_handler)();//函数指针 指向new异常处理函数
//返回值为void 无参数的函数
new_handler set_new_handler(new_handler p) throw();
//set_new_handler的函数原型  我们登记函数p 函数将会把上级的处理函数指针返回给我们

new_handler是为了让更多的内存可用，在无内存的时候看看哪些不重要的内存先释放。我们也可以在new_handler中调用abort()或exit()

举个例子

set_new_handler原型

#include <new>
void noMoreMemory()
{
    cerr << "out of memory";
    abort(); //若没有abort 会不断输出out of memory"
    //因为全局默认的op new就是在不断地循环调用new_handler
    //直到获得足够的内存
}
void main()
{
    set_new_handler(noMoreMemory);
    int *p = new int[100000000000]; //故意申请超大内存 引起new_handler
    assert(p);
}

5 =default,=delete(c++ 11新增关键字)

class Foo{
public:
    //=default 表示这个函数要用默认版本
    //有默认版本的函数=default只适用于 拷贝构造函数 拷贝赋值函数= 析构函数
    //=delete 表示不要这个函数
    //=delete也适用于 new/new[] delete/delete[]
    Foo()=default;
    Foo(const Foo&)=delete;
    Foo& operator=(const Foo&)=delete;
    ~Foo()=default;
    .....
};
