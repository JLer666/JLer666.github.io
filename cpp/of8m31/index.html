4 placement new

placement new允许我们在已经得到(分配)堆内存(allocated memory)上构造对象 ，所以placement new不会分配内存，而是在传进来的内存上 构造对象

#include <new>
char* buf = new char[sizeof(Complex)*3];//先用new在堆上申请内存
//delete[] buf;
Complex* pc = new(buf)Complex(1,2);//在已经存在堆内存上构造对象

上面这句话会被编译器翻译为

Complex* pc;
try{
	void* mem = operator new(sizeof(Complex),buf);
    //与之前申请内存的调用的函数不一样 之前是
    //operator new(sizeof(Complex));
    //若Complex没有重载这个两个参数的operator new那么调用的是默认全局函数 这个原型写在下面了
    pc = static_cast<Complex*>(mem);
    pc->Complex::Complex(1,2);
}
catch(std::bad_alloc){
//如果operator new 内存装配失败 不执行构造函数
}
....

void operator new(size_t,void loc){return loc;}//含两个参数的op new用于placement new 直接返回了传入的那块内存的首地址loc 其他什么都没做**

上面的buf是3个complex的空间所以也可以

Complex* pp = (Complex*)buf;
for ( int i=0; i<3; ++i )
{
	new (pp+i)Complex(1,2);
}
 for ( int j=0; j<3; ++j )
{
    pp[j].~Complex();
}

总结一下new expression,op new,placement new

使用new expression delete expression (不可改变无法重载)

Foo* p = new Foo(x);
...
delete p;

new expression 先调用op new申请内存 再构造对象

delete expression 先析构 再调用op delete

所以上面两句话可以扩展翻译为

Foo* p = (Foo*)operator new(sizeof(Foo));//先申请内存
new (p) Foo(x);//在已经存在的内存的基础上 构造对象
...
p->~Foo();//先析构对象
operator delete (p);//再释放内存

如果我们有重载 operator new，operator delete(有写

Foo::operator new(size_t) Foo::operator delete(void*) 在重载的函数中我们有大概率还是会调用全局的op new和op delete)

则上面的几句代码会去调用我们重载的op new,delete否则调用的是全局的::operator new(size_t)，::operator delete(void*) (这两个全局函数也是可以重载的 但是很少去重载) 全局的op new op delete中调用了malloc(size_t)和free(void*)。

5重载 op new delete,placement new

1 重载 ::operator new，::operator delete (全局的op new和 op delete)

注意重载这两个全局函数 将会影响深远

因为是全局函数所以这四个重载函数都不能被声明于一个name space中

inline void* operator new(size_t size){....}
inline void* operator new[](size_t size){....}
inline void operator delete(void* ptr){....}
inline void operator delete[](void* ptr){....}

2 类内重载 Foo::operator new，Foo::operator delete 专属于这类对象的op new和op delete

class Foo{
public:
//这四个函数在被调用的时候 一般是对象还未被创建完成(所以无法通过对象去调用成员函数)，所以如果想调用这四个函数 这四个函数必须是静态函数(才可以不通过对象就能调用)
    static void* operator new(size_t);
    static void operator delete(void*);
    static void* operator new[](size_t);
    static void operator delete[](void*);
};

上面讲过很多次了在调用new/delete expression时会调用op new/delete 如果我们新建对象的类有重载op new/delete 那么就会调用这个类内的重载版本。

3 重载placement new

placement new – 重载operator new()(和上面的op new不一样 上面的op new特指只含一个形参的new) (delete())

全局版的含两个参数的op new用于placement new

void* operator new(size_t,void* loc){return loc;}

传入大小 和已存在空间的指针

但其实两个参数 第二个参数可以不传指针可以传任意类型

我们可以在类内重载operator new(),可以写出很多的版本前提是每一版本都必须有其独特的参数，其中第一参数必须是size_t(在以placement new语法形式调用时 sizeof(类别)会作为参数自动传入这个第一参数中) 其余参数就作为placement argument(在new (p) Foo(x) 这个p就是placement argument–**在new(…)其中…就是placement argument 并且可以有不止一个参数 可以有多个参数new (p,”as”) Foo(x) **)。

我们也可以重载operator delete()(带参数的delete 也可以叫placement delete 虽然这么叫有点怪)，但是他们绝对不会被delete(expression)调用。只有当new所调用的构造函数抛出exception 才会调用这些重载版本的operator delete()，它只有可能被这样调用 主要用于归还未能完全创建成功的对象所占用的内存。

class Foo{
public:
    //标准库提供的两个参数的new就是这种形式 我们只是在类内又重写一次
    void* operator new(size_t size,void* start){return start;}//standard placement new

    //我们自己写的两个参数的new 在sizeof(Foo)的基础上多申请extra个字节   new(7) Foo(...);//多申请7个字节
    void* operator new(size_t size,long extra){
    return malloc(size+extra);
    }
    //new(7,’a’) Foo(...);
    void* operator new(size_t size,long extra,char init){
    return malloc(size+extra);
    }
    ////注意op new的第一个参数必须是size_t size

    // 处理operator new(size_t size,void* start) 中调用的构造函数出现的异常
    void operator delete(void*,void*){
    ......
    }

    // 处理operator new(size_t size,long extra) 中调用的构造函数出现的异常
    void operator delete(void*,long ){
    ......
    }
    //没有写 void operator delete(void*,long,char )
    //则当operator new(size_t size,long extra,char init)异常时不做任何异常处理
};
