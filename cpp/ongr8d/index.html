1 const

用const修饰的函数内成员变量全部变为const只能读

对象为const对象(成员变量不可写) 调用const函数(函数内部保证不写成员变量) ok

非cosnt对象 调用const函数 ok

非const对象 调用非const函数 ok

const对象 调用非const函数 fasle!!!!

const对象只能调用const修饰的函数

注意c++规定当成员函数的const版本和非const版本同时存在，const对象只能调用const版本的成员函数，非const对象只能调用非const版本的成员函数。

string的[]重载 有两个函数–const函数修饰 能作为重载的依据，这也是为什么两个函数的形参类型和个数一样，但是可以共存

上面的[]的重载是在用作右值的时候 比如 char c = s[1];

此时是只读字符串内容所以加上了const修饰，此时的s为常量或非常量都ok—普通变量=同类型的引用变量是ok的

下面的[]的重载是在用作左值的时候 比如 s[1] = ‘c’;

此时的s一定为非常量

此时需要写s的内容所以[]返回的是个char引用，并且如果s这个字符串是由其他字符串拷贝得到的，在调用左值[]时会发生 写时拷贝 会为其申请属于它自己的堆上内存，并且初始化自己这块堆上内存的reference counting引用计数为1

c++ string是内存共享的并且是写时拷贝(copy on write)

通常，string类中必有一个私有成员，其是一个char*，用户记录从堆上分配内存的地址，其在构造时分配内存，在析构时释放内存。

因为是从堆上分配内存，所以string类在维护这块内存上是格外小心的，string类在返回这块内存地址时，只返回const char*，也就是只读的，如果你要写，也只能通过string提供的方法进行数据的改写。

string str1 = “hello world”;

string str2 = str1;

string str3 = str2;

str1,str2,str3都是拷贝构造得到的，其内部的char指针指向的是同一块堆上内存。

printf ("\tstr1 的地址: %x\n", (unsigned int)str1.c_str() );

printf ("\tstr2 的地址: %x\n", (unsigned int)str2.c_str() );

printf ("\tstr3 的地址: %x\n", (unsigned int)str3.c_str() );

str1 的地址: 83f9017

str2 的地址: 83f9017

str3 的地址: 83f9017

先修改str[3]内容，但是不能直接修改str3 char的堆上内容因为此时str1,str2还共享着这块内存，所以需要重新为str3 char开辟一块新的堆上内存并拷贝原来的char堆上内存然后再依照索引修改对应内容。此后str1 char堆上内存被str2共享，str3 char指向其自己的堆上内存–str[2]内容修改发生的变化同理

str3[1]=‘a’;

str2[1]=‘w’;

str1[1]=‘q’;

printf (“通过写时拷贝之后:\n”);

printf ("\tstr1 的地址: %x\n", (unsigned int)str1.c_str() );

printf ("\tstr2 的地址: %x\n", (unsigned int)str2.c_str() );

printf ("\tstr3 的地址: %x\n", (unsigned int)str3.c_str() );

通过写时拷贝之后:

str1 的地址: 83f9017

str2 的地址: 83f9054

str3 的地址: 83f9034

在str3,str2修改开辟新的堆上内存时会多申请1个count变量,char*指向的头4个字节,(str1也有这个变量)，这个count就是引用计数
