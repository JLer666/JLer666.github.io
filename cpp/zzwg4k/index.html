Deallocate–将p的下块(p内存第一个字节保存的索引)设定为Chunk当前的第一个可用块，将归还来的p作为Chunk的新的第一个可用块(将p转为在Chunk中的索引 这个索引就是新的firstAvailableBlock_下次再来要就又把这块分配出去)。

void* FixedAllocator::Chunk::Deallocate(void *p,std::size_t blockSize)
{
    unsinged char* toRelease = static_cast<unsigned char*>(p);//先将归还这块内存p按字节划分
    *toRelease = firstAvailableBlock_;//将p的下块(p内存第一个字节保存的索引)设定为Chunk当前的第一个可用块
    //在Deallocate前已经知道p落在哪个Chunk内
    //现在需要知道p是这个Chunk的哪个内存块
    //很简单 [p-pData_(头)]/blockSize(每块的大小) = p在Chunk数组中的索引(也就是书面上的落在哪一块上)
    //知道p索引后就将归还来的p作为Chunk的新的第一个可用块(下次再来要就又把这块分配出去)
    firstAvailableBlock_ = static_cast<unsigned char>((toRelease - pData_)/blockSize);
    ++blockAvailable_;//可用块数加1
}

这个归还的过程很像gnu std allocator,将归还来的内存块放在链表的头部 下次申请时也是优先将头部分配出去，loki则是将归还来的这块设为第一个可用块 下来申请时也是优先将此块分配出去(原先的最高优先级块 变为次高优先级块 归还来的这块的第一个字节存的索引是这个次高优先级块 表示如果下次我被分配出去了 下一个最高优先被分配的就是这个次高优先级)。

#######FIXDALLOCATOR

FixedAllocator.chunks_–vector,内存块向量保存了一些内存块chunk的信息。FixedAllocator.allocChunk_–Chunk标出最近的一次满足一次Allocate动作的Chunk(即上次内存块是从这个Chunk中拿的则记录下它–标定它为allocChunk_,当下次又有拿内存块的需求时先看这个allocChunk_内是否有内存块可分)，FixedAllocator.deallocChunk_–Chunk*，上次回收的内存块p是落在某个Chunk中则我们将其标定为deallocChunk_，下次要回收新的p我们优先看这个p是否落在deallocChunk_中。

void* FixedAllocator::Allocate()
{
    if(allocChunk_==0||allocChunk_->blocksAvailable_==0)
    {
        //目前没有标定chunk(allocChunk) 或者 标定的allocChunk_中没有内存块FixedAllocator.allocChunk_
        //--Chunk*标出最近的一次满足一次Allocate动作的Chunk(即上次内存块是从这个Chunk中拿的则记录下它--标定它为allocChunk_,当下次又有拿内存块的需求时优先看这个allocChunk_内是否有内存块可分
        Chunks::iterator i = chunks_.begin();//chunks_--vector<Chunk> 从向量头找起
		for(;;++i)//遍历chunks知道找到拥有可用内存块的chunk
        {
            if(i == chunks_.end())//end指向最后一个元素的下一个位置
            {//遍历完chunks也没找到拥有可用区块的chunk
                //初始化
                chunks_.push_back(Chunk());//创建新区块
                //Chunk()为临时变量 生命只在这一行，push_back会在容器内调用拷贝构造 将其信息拷贝到堆上对象
                Chunk& newChunk = chunks_.back();//新的这个chunk的引用
                newChunk.Init(blockSize_,num_Blocks_);//对新Chunk进行初始化 设定其的一些属性
                allocChunk_ = &newChunk;//标定 稍后如果再取内存块优先从此Chunk中取内存块
                deallocChunk_ = &chunks_.front();//另一标定
                //push_back可能会发生搬动内存(内存成长)的行为，如果发生搬动，之前相关迭代器(指针)的指向将失效,不再是和之前一样指向某个容器内元素
                //就怕在push_back后发生搬动，所以在push_back后为了防止出现野指针重新对迭代器(指针)的指向进行标定，指向当前vector的明确的头部
                break;
            }//i == chunks_.end()
        }//for
        if(i->blocksAvailable_>0)
        {//当前Chunk有可用内存块
            allocChunk_ = &*i;//取迭代器内容(迭代器对*取内容符进行了重载)得到chunk对象 再取chunk对象地址
            break;
        }
    }//allocChunk_==0||allocChunk_->blocksAvaulable_==0
    return allocChunk_->Allocate(blockSize_);//向这个标识出来的一定有内存块的allocChunk内取一个内存块
}


void FixedAllocator::Deallocator(void* p)
{
    deallocChunk_ = VicinityFind(p);
    DoDeallocate(p);
}

VincnityFind 查找被回收p区块所属于的Chunk，并返回这个Chunk的首地址。双指针法，lo指针从deallocChunk_向上往chunks.front方向找，hi指针从deallocChunk_+1向下往chunks.back()方向找。(两个指针背向而行查找 p区块地址是否落在当前检查的Chunk地址范围内)

FixedAllocator::Chunk* FixedAllocator::VincnityFind(void* p)
{
    const std::size_t chunkLength = numBlocks_*blockSize_;
    Chunk* lo = deallocChunk_;
    Chunk* hi = deallocChunk_+1;
    Chunk* loBound = &chunks_.front();//chunks_的首元素
    Chunk* hi = &chunks_.back()+1;//back+1指向的是vector的end 不是一个Chunk对象
    for(;;)
    {//兵分两路
        if(lo)//上路未到尽头
        {
            if(p>=lo->pData&&p<lo->pData_ + chunkLength)
            return lo;//p位于lo这个Chunk内
            if(lo == loBound) lo = 0;//到底了
            else --lo;//注意是-- 是向chunks_的front这个方向查找
        }
        if(hi)//下路未到尽头
        {
            if(p>=hi->pData&&p<hi->pData_ + chunkLength)
            return hi;//p位于hi这个Chunk内
            if(++hi == hiBound) hi = 0;//往chunks_i的back继续找 若到最尾则让loop结束
        }
    }
    return 0;
}

注意！如果传入的p并非由loki申请得到的(比如是自己malloc得到的一块内存)，那么在chunks_中必定找不到p所归属的Chunk,那么这个VincnityFind将会陷入死循环。(感觉是作者故意这么做 警告使用者不要乱传指针进来)

if(lo == loBound) lo = 0;//到底了

改为

if(lo == loBound){

lo = nullptr;

if(nullptr == hi)break;

}

if(++hi == hiBound){

hi = nullptr;

if(nullptr == lo)break;
