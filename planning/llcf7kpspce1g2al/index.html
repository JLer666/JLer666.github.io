深蓝学院 汪博 机器人中的数值优化

如何保证问题优化过程中的数值稳定，给了很多理论算法到工程实际的例子

一般的数值优化问题可以由上图描述

对于长上面这样的待优化目标，由于在某个x处为无穷大无法被浮点数表示。此问题不在本课程的讨论范围内

本课程要求 对任意x f(x) >= 某一数(无论正负) — f(x) has lower bound

对于某优化目标，若其最优x在正无穷或负无穷处取到，则此最优x计算机无法用浮点数表达，无法求解。

本课程要求 f(x) <= 某一数的区间是有界的(区间任一边不能为正负无穷) — f(x) has bounded sub level set

本课程只处理连续问题，f(x)、g(x)、h(x)均连续但可非光滑

对于有约束优化问题，定义f delta (essential objective function)，当约束被满足时其值为f本身，约束不被满足时其值为无穷大。这个函数也要满足 has lower bound 和 has bounded sub level set 两个条件

目前的凸函数在凸几何中的优化已经被研究的比较透彻，即便非凸的数值优化算法也需要一些凸的性质来分析问题

某些非凸问题可以通过更换问题描述形式，或者一定的松弛来变为凸问题。

很多非凸问题的最小值处是局部凸的！

本课程只讨论确定性(De)的local minima问题。对于f有多个近似的local minima时不做决策和进一步判优。

定义凸集合

集合中的任意两点连线上的任意点都在集合内部，对于二维凸集合可表达如下,表示x1、x2线段上的每一点

more general 的形式为 所有的凸组合(由两个即以上的x组成的线段或凸多边形内部)都在此集合内

$ \begin{gathered} y = \sum \theta_i x_i \in set \\ \sum \theta_i = 1 ;\theta_i \geq 0 |\forall i \end{gathered} $

上述公式就被称为all convex combinations （凸组合），若集合为凸，取凸集合的边界顶点$ x_i(1\to n) $再通过取不同的 $ \theta_i(1\to n) $组合可以取到此凸多边形内部(上)的任意一个点(y)。

$ \theta $向量被称为凸集关于y的重心(barycenter)坐标。

若x1-5不像上图都在凸集的边界点上，又任意在凸集合内(上)取一冗余的x6，则$ \theta_{1\to 6} $被称为凸集关于y的广义重心坐标。

对于下面这个图形，由于边上有几段时无定义的，此集合不为凸集合。

凸包(convex hull)为集合中所有点的凸组合组成的集合。凸集合的凸包为自身，非凸集合的凸包为 将此非凸集合完整地包起来的最小凸集合如下图

超平面(=) 为凸集合

半空间(>=)为凸集合 (多个half sapce的交集为polytope高维多面体 也是凸的)

超球面(=) 为非凸集合(二维为环，还上两点连线上的点并没有都在环上)

超球(<= 面+内) 为凸集合

多项式 为凸集合

锥不一定为凸集合。锥集合(Conic set)的定义为，集合内任一点，乘上一大于等于0的数a，得到的点一定依旧在集合内。

二阶锥C2可被表达为$ ||x|| \leq t $ – 点到0的模长小于等于一大于0变量t。上图中的x取自超球集合所以此锥为凸集合。 X:(x1,x2,t)任意两X连线依旧在锥内 or 上

t=常值的切片为非凸形状(x本身属于非凸集合)则此锥非凸

半定锥(semi definite cone)对称半定矩阵元素作为变量构成的集合为一种比较特殊的锥其一定为凸

矩阵A对称且半定($ \forall x ;x^TAx \geq 0 $且$ x^TAx = 0 $只在x=0处取到则A为正定，若在$ x \neq 0 $可得到$ x^TAx=0 $则A为半正定，其符号如图，注意图上的并非$ \geq $哦而是半正定的特殊符号)

上述矩阵之所以被称为半定锥是因为(将以下的矩阵视为一变量)

$ \begin{gathered} \forall A_x \in \{A_x \in R^{n\times n}|A_x=A_x^T,A_x\succeq 0\}\\ \end{gathered} $

$ \forall \lambda \geq 0 $有$ \lambda A_x \in \{ \lambda A_x \in R^{n\times n}| \lambda A_x = \lambda A_x ^T, \lambda A_x \succeq 0\} $

此 $ \{ \lambda A_x \in R^{n\times n}| \lambda A_x = \lambda A_x ^T, \lambda A_x \succeq 0, \lambda = \lambda_x(\gt 0)\} $ 集合是 $ \{A_x \in R^{n\times n}|A_x=A_x^T,A_x\succeq 0\} $的一子集，满足上述对锥的定义。

将$ A_x $内的元素作为多维变量为变量画出来的图为一锥(如上图的二维半定锥)。

A、B均对称且半定，则$ \theta A + (1-\theta)B $也一定对称且半定($ 0 \leq \theta \leq 1 $)所以半定锥也是凸集合

凸集合的交集依旧是凸集合，凸集合的并集不一定为凸集合

$ \forall x $点(n维向量)代入$ x^TAx\geq 0 $反算A矩阵(由其内部的矩阵元素组成的多维变量表达)，将所有x得到的A矩阵取交集得到n维半定锥。每一个具体x代入后的$ x^TAx\geq 0 $相当于就是一个A元素变量组成half space， $ \forall x $再取交集相当于所有半平面的交集( polytope)为凸。

A凸且B凸

(1)则A内任意元素加B内任意元素得到的集合依旧是凸集合

(2)则set prodct后也依旧是凸集合，set product举个简单的例子

A为(x1,x2)二维圆(凸)，B为0<=y<=1(凸)则set product后为一圆柱(凸)

set product可理解为将另一集合作为一个新的维度得到的新集合
