closed-form solution to minimum snap(闭式解析解)

matlab中有凸优化问题的求解器，直接求解问题的数值解。下面讲解如何求解minimum snap QP的解析闭式解。

decisinon variable mapping(待优化变量的映射)

我们问题中待优化的是分段多项式，每一段多项式的系数p1-pM。这些系数是没有物理含义的，直接解算得解后的值有可能出现非常小或非常大的奇异值，会造成规划轨迹的数值不稳定(numerically unstable)。

解决办法是将待优化参数从多段多项公式系数，变为优化轨迹必经点(每段多项式的首尾点–除第一和最后一段)的各阶导数(必经点只有位置p是硬约束是必须要达到的,加在凸优化问题的等式约束中 但是必经点的v,a是自己规划的，和多项式参数一样是是待优化变量，我们优化计算必经点v,a其实有优化每段参数是一个道理)的约束问题 — 问题从优化没有实际物理意义的多项式系数变为优化有实际物理意义的轨迹必经点的各阶导数值。有实际物理含义的参数数值稳定性会好很多，且隐形地让问题可以闭式求解 不需要通过数值计算的方法其优化系数。

通过映射矩阵M将轨迹多项式系数p映射成轨迹端点(轨迹必经点)的各阶导数d

Mjpj=dj

这个映射矩阵怎么求呢？

d1-dm 是第一个必经点-第m个必经点的各阶导数组成的列向量，

下面以一段轨迹的两个必经点为例 — 一个d与两个必经点相关

这段轨迹的一阶和二阶导 (v,a)如下

M[p5 p4 .. p0]T = [d0 d1 d2 d3 d4 d5]

d参数意义 d0必经点位置硬约束t=0位置–此参数不能优化我们直接给一个常数 d1t=0速度 d2t=0加速度

d3必经点位置硬约束t=T位置–此参数不能优化我们直接给一个常数

d4t=T速度 d5t=T加速度

Fixed and free variable separation(固定的参数和待优化参数分解)

设计参数挑选矩阵C将固定的参数约束参数df和自由参数dp分离

自由参数 – 轨迹的高阶导数未定义，只做了连续性约束 必经点v,a

固定参数 – 始末态p,v,a 必经点位置p

C阵(只有0，1的选择矩阵)的目的就是将固定的参数排在上面，自由的参数排在下面

此时问题已经变成没有约束的二次规划问题了，约束哪去了呢？

必经点同时连接前后两段轨迹，同时作为前后两段轨迹的必经点，这个点的v,a是前段轨迹的终点以及后段轨迹的起点共用，我们可以通过选择矩阵将这同一个v,a映射到[d1..dm]属于前段终点以及后段起点所代表的一阶二阶导数的位置上(这样就通过C强制完成了连续性约束)

而导数约束在我们上面分离自由和约束变量时就已经完成了，我们分离的固定参数df可以直接填导数约束规定的常量(初末p,v,a必经点p)。

将有约束的QP问题变为了无约束QP问题，对于无约束QP问题，有下闭式解

对待优化参数J对dp求导=0 d dfT RFP dp / d dp = RFPTdf

d dpT RPF df / d dp = (RPF df)T

d dpT RPP dp / d dp = RPPdp + RPPTdp

(RFP T+RPF)*df + (RPP+RPP T ) dp= 0

下图是左是原论文中通过RRT找到必经点，图右是通过minimum snap优化得到的轨迹

随之而来又有一个问题，我们在轨迹优化时没有考虑障碍约束，如何保证优化后的轨迹不会发生碰撞(轨迹优化会产生overshot 会碰到障碍)

minimum snap原论文的做法是，取path finding找到的轨迹，发生碰撞那一段的path新增一个 此段轨迹首尾必经点的中点 作为新增的必经点 再求解一次minimum snap问题得到的轨迹如右没有发生碰撞。 如果又发生碰撞了，那就在发生碰撞那一段的path再新增一个必经中点。不断迭代 直到不再发生碰撞

本质上就是让优化出的轨迹不断逼近 前端规划出来的轨迹

有没有更好的解决这个问题的方法？

硬约束 – 给空间里加上很多bounding box 下节课讲

上图就是先听过bounding box 将空间中的静态障碍物 用框框起来，找到最快的从起点到终点的路径上的所有框(蓝框)，再搜索空间中的可行区域(没有障碍物区域 黄框)，再在黄框区域内生成一条动力学约束的轨迹。

最后问题依旧是个QP问题

常线性约束

1首尾姿态约束 – 等式约束

2 希望规划出的轨迹位置在黄框上或里 – Ap<=b等式约束(上)+不等式约束(里)

3 连续性约束,两段轨迹的连接点导数连续 – 等式约束

区间 线性约束

4 Boundary constraint 希望轨迹在框内 (A(t)p<=b, tl<=t<=tr)

5 dynamic constraint 动力学约束 含速度约束，加速度约束 (A(t)p<=b, tl<=t<=tr)

如何让一段轨迹被完全包含在一个box中

box和box之间是有重叠区域的，我们将两个box轨迹的连接点规定在两个box的重叠区域中

但是我们这个约束还是不够，只能保证连接点一定在box中，还是不能保证整条轨迹都在box里。

一个可行方案是我们先生成轨迹再检查轨迹多项式的极值是否在这个box内。多项式极值检查就是求导数=0的根，计算起来还是很快的，可以很快地检查出轨迹是否在box里

比如下图是规划出的y轨迹，以及box的y值上限yb

可以看出规划出的轨迹的极值是超出了box的限制，那我们在规划轨迹中超出范围的部分施加一个额外的约束，将轨迹向下压。但这种解决方法依旧是要不断地检查迭代求解，还是不高效求解很缓慢

Online generation of collision-free trajectories for quadrotor flight in unknown cluttered environments , J. Chen, ICRA 2016

还有一种方法是 在前端找出的path点上，添加bounding box,可以得到一条密集的bounding box轨迹。

每个boundingbox都有很大的重叠区域，同时控制每段轨迹的运行时间(速度)，使无人机不会飞出boundingbox。 要加很多约束，求解会很慢，并且无人机的飞行速度很慢

A hybrid method for online trajectory planning of mobile robots in cluttered environments , L Campos-Macías, RAL 2017

2 Numerical Stability (数值稳定)

上面讲了要用相对时间线，每段轨迹的起点都从0开始。

这还不够，因为有时会出现 运行时间非常小的轨迹，一样会导致数值不稳定

所以做法如下，将每段的运行时间归一化0-1

有的轨迹很长对问题求解也是非常不利的 轨迹在100m

一样通过放缩来求解，地图缩小，在缩小的地图上求解，求解完再放大

3 是否要3轴独立求解

通常解决3个小问题比解决一个大问题 比是更加稳定 快速的

对于minimum snap问题 ok

但是当我们在代价函数(软约束问题)中加入了某种距离场去评估障碍代价，此时距离计算需要用到所有轴，那么将不能将3轴分离

4 闭式求解是否最好

矩阵求逆的代价很大，当矩阵很大时，数值求解凸优化问题是更好的

5 多项式是否可以解决任何轨迹规划问题

现已证明 对于J = 积分(0,T) (x的某阶导数)^2dt 最优解是多项式

对于J = 积分(0,T) 权重1*(x的某阶导数)^2 + 权重2*(x的某阶导数)^2dt 最优解并不是多项式，和多项式比差了一点。

对于有bounding box or bounding circe的方法

允许轨迹连接点在交叠区域自由移动(不像mini snap中间点是必经点位置是一个硬约束)

我们给定一个T，这些方法会移动连接点到 我们给定的这个T下的较优位置。可以一定程度的缓解给定的T不够好的问题

比较好的做法是 将每段的轨迹时间也作为优化参数加入 代价函数中

但是这个形式的代价函数，不再是凸优化问题可以求解的

不再能闭式求解 此问题就需要用类似梯度下降法去数值求解 所有最优参数

还有问题，当我们得到代价最小的轨迹 以及每段轨迹的运行时间。 如果轨迹最优时间是动力学上不可行的(速度和加速度超过给的上限了 – 注意 我们J里优化还是minimum snap的形式 没有加 不等式约束)。 文章里的方法，是不管不等式约束，先梯度下降求一个较优解，再检查每段的T，如果出现，某段T超出限制,**直接拉长整个轨迹的总T，同时保证保证每段轨迹之间的T比例不变,**再进行梯度下降 直到每段都在动力学范围内
