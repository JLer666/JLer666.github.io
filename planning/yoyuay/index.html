接下来构造哈密顿函数 和无人的构造不一样(其实和哈密顿函数定义的构造方法都不一样)

设约束的终止状态为sf,我们实际规划出的终止状态为s(T) = s0 + 积分(0,T) s’(s,u(P))dt

得到终态约束 C(s,P) = s(T) - sf = s0 + 积分(0,T) s’(s,u(P))dt - sf

目标优化P使C趋向于0，设一开始的参数为P1，修改P1->P2使C接近0

将C在P1处一阶泰勒展开

C(s,P) = C(s,P1) + dC(s,P)/dP|P=P1 * (P-P1)

将P=P2代入

C(s,P2) = C(s,P1) + dC(s,P)/dP|P=P1 * (P2-P1)

我们希望C(s,P2) = 0 则将C(s,P2) = 0代入

0 = C(s,P1) + dC(s,P)/dP|P=P1 * (P2-P1)

得到 P2-P1=deltP=-(dC(s,P)/dP|P=P1)^-1 * C(s,P1)

注意dC/dP是个矩阵 并且可能不是方阵无法直接求逆 则需要求伪逆

比如 dCi,j(s,P)/dPk = (Ci,j(Pk+e) - Ci,j(Pk))/e e是个很小的值

接下来构造哈密顿函数， 注意和无人的构造出来的形式不太一样

H(P,/) = J(P) + /\T C(P) = J(P) + /\T (s(T) - sf)

J(P) = 积分(0,T) Y(s,P,t)dt

Y(s,P,t) = 权重1风险评价(s) + 权重2能耗(s,t) + …

J是实用函数，描述了我们想要优化的东西 比如 能耗，接近障碍的代价…

通过改P和协态/\使H最小

dH/dP = 0 n个方程,n为P的参数量 dH/d/\ = 0 m个方程，m为/\的数量–系统中状态的数量

dH/dP = dJ/dP + /\T dC/dP = 0T dH/d/\ = dC/d/\ = 0 (?疑问 不对吧)

将两个一阶导方程线性化,再加上上面得到的deltP优化步长得到(xf就是我们上面说的C) 怎么求出来的？

移项，再添加一个步长因子(控制每次更新的幅度) 得到P和/\的更新步长

我们通过最优参数和参数化控制就得到了最优控制u*，以及最优轨迹s*

人类开车不是以world坐标系为准，而是以车道线为基准所以提出frenet坐标系

frenet坐标系是一个动坐标系，为以与车辆位置最近的参考线(道路 光滑)点(下图R点)作为frenet坐标系原点，以参考线R点处的切线作为T轴，以R点处的向外法线作为N轴

r(s)向量表达了R点在世界笛卡尔坐标系下的位置,s为从参考线起点到R点的沿参考线的参考线长度。

x(s,l)相连表达了车体位置P点在笛卡尔坐标系下的位置，s为从参考线起点到R点的沿参考线的参考线长度，l为R点和P点连线在Nr轴方向的的偏移量。

thetax和thetar分别为P点切线Tx的yaw角(Tx与笛卡尔x轴正向所成角)，R点切线Tr的yaw角(Tr与笛卡尔x轴正向所成角)

Tr,Nr,Tx,Nx全部为单位向量可以表达为

Tr=[cos theta r,sin theta r]T Nr=[-sin theta r,cos theta r]T

Tx=[cos theta x,sin theta x]T Nr=[-sin theta x,cos theta x]T

根据平面几何可得 向量x(s,l) = r(s) + l(s)*Nr 向量合成,Nr为单位向量乘上膜长l(s)

上面的是lattice planner的表达 论文中的表达有一点点不一样

横向偏移量为d(不叫s了)，认为横向偏移为时间t的函数(lattice中认为 横向偏移l是路径长度s的函数),参考线坐标系下标用c表示(lattice中用r表示)

x(s,d) = r(s) + d*nc 详细写就是 x(s(t),d(t))=r(s(t))+d(t) nc(s(t))

为了使车能够完成在快速行驶和距离保持模式下的规划，将规划轨迹时min的代价定义

J[d,s]=Jd[d]+ks*Js[s] ks>0 ，将横纵向的代价分开来写并加上权值，这样的区分对待使得我们在轨迹规划时可以分别规划横向和纵向位移轨迹

state lattice不是说对无穷的终点state采样画出轨迹这是不可能的，我们只对自己挑选出来的终点进行最优控制求解。Lattice就是一种基于对终点采样的算法，一次先产生若干个终点再产生若干条路径，在这些路径中选择最好的一条。

首先对终点做约束 约束终点状态的v,a与参考线终点位置的一阶导和二阶导相同。没有约束终态位置和参考线位置相同是因为参考线是路边，车肯定不能开到路边的一定要和路边有一定的横向位移
