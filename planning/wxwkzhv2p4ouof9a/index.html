只讨论二维情况

基点Site：具有一些几何意义的点(可能为区域的重心或其他)

细胞Cell：Cell中任意点到其他基点的距离都一定大于其到Cell内部基点的距离

对于只有两个基点的情况，两个基点对应的Cell就是半平面，分界线在两点连线的中垂线上

Cell的划分：对于多个基点情况，某个基点的Cell就表达为其与其他基点连线的中垂线互相相交构成的多边形(多个半平面的交集，因此Cell一定是凸的)如下图

由于基点所处区域为边界区域(比如路口和UNKNOW的交界)则交界处的边并非由求交得到，为交界的原始形状并不能保证凸如上图的黑色外包边。

维诺图在存储时用线段、射线(在没有边界的空间中，外层site对应Cell的某些边为射线)，直线(两个site的特殊维诺图中间的交集线为直线无界)，这些线在维诺图中都是edge,edge间的交点就是顶点vertex.

二维维诺图的性质

1 非空性 每个site一定存在一个对应的非空cell

2 空圆性

Cell中任意点到其他基点的距离都一定大于其到Cell内部基点的距离–>

以Cell中任意点为圆心，以<=其到Cell对应基点的距离为半径，这个圆的内部一定不包含任何基点–>

Cell的边界(由交集产生的边界非区域边界)上的任意点都在构成此边的两个Site的中垂线上，其到这个两个Site的距离一定相等–>

以Cell的边界上的任意点为圆心，以<=其到Cell对应Site的距离为半径，圆内部一定不存在Site–>

Cell的顶点vertex由edge相交构成，以顶点为圆心，其到构成顶点edge对应的Cell的Site的距离都是相等的，以<=此为半径,圆内部一定不存在Site

共圆性(Concyclic) 顶点位置存在3个最近site,这些site一定共圆这个圆也叫最大空圆

空间中任一点x

x在cell内部(不在边上)，最近site唯一就是cell内的那个site

x在两个cell的边界上，最近site有两个就是构成这条边的2个cell内的site

x在cell的顶点上属于多个cell,最近site有至少3个(对图顶点来说其度至少为3)，以此点为顶点的cell内的site到此点距离相等共圆

三个site点构成的三角形，voronoi edge为三角形各边的垂直平分线，edge交点为vertex也即三角形三边垂直平分线的交点也被称为三角形外心。 — 若所有顶点在general positions(非退化位置，退化位置即存在大余3个site共圆这种概率几乎为0)，每个vertex的度为3

扫描线算法Plane-Sweep

在从左往右的扫描过程中，会遇到在出现新的3个site的组合后产生一个新的vertex，此时vertex很可能在第三个site的左边，此时必须将扫描线回溯到vertex位置重新向右扫才能保证结果的正确。

Fortune重新用了一种新的距离判断标准来构造维诺图，这张新的维诺图与欧式距离下的维诺图是同构的，即拓扑结构相同所以当得到了变形的维诺图后也就得到的我们要的维诺图结构。经过改良后目前只需要将扫描线变形(非直为曲的)就可得到正常维诺图。

期望凡是扫描过的地方就成为历史确定下来，不需要再回溯回去，将图分为三个部分(自上而下扫描)，蓝色为Frozen不变部分(边界为Beachline抛物线组合连接构成)，深紫色为Unfrozen待变部分(Sweepline直线)

Frozen:区域内点到Sweepline(SL)据的距离大于其到SL上方距离此点最近site的距离

UnFrozen:区域内点到Sweepline(SL)据的距离小于其到SL上方距离此点最近site的距离

Beachline定义:上面的每一点 其到SL上方距离此点最近site的距离=此点到SL距离。其在x方向上是单调的(y=?线与其只有一个交点)。对于BL上方任意点，其最近site都已经确定即其归属于哪个Cell已经确定，所以这些部分可以冻结不再变动。

抛物线可由一个焦点加一条准线构成，在维诺图的例子中可以用site作为焦点,BL作为准线。抛物线定义：其上任意点到焦点和准线的距离是相等的。随着准线距离焦点越近此抛物线会变的越"尖"，当准线与焦点相交时，准线退化为从交点开始垂直于准线向左(我们的例子中)的射线。

对于被SL扫过的site都可能作为抛物线焦点，SL作为准线，这样就得到了一系列抛物线，取这些抛物线的下包络(y=?时的max x)也就得到了BL。

对于SL上方有n个site的情形，某条抛物线可能最多为BL贡献n段弧，BL的弧数量不会超过2n-1

将抛物线间的连接点称为break point，根据BL性质可推出这个断点必然位于某个未来Cell的edge上。

随着SL运动遇到一个新site后，此时edge中止延申的break point成为VD的vertex(上面讲过的split过程），至此构造VD的过程就变为在SL扫描过程中记录BL的break point的过程，记录edge以及vertex。

实际计算机计算时SL的前进步长是离散的，其实只需要在一些特定的位置上需要计算break point。这些特定位置被称为event，经过这些event位置后BL上方的图结构将发生变化。

event 1:上述SL穿过某个新event时，此后BL中将新增一条弧。某条边终结新增一vertex,edge split为两条(方向为site垂直平分线方向)。

当遇到新site需要新增抛物线，但是由于还没过这个site，位置正好处于这个site，此时的抛物线是退化的射线， 始于新增event往左(上)的射线，射线与BL相交的位置将会在后续生成新弧，注意新增的是两段弧(原弧被一分为2，并新增了新site对应的弧,即出现了线的三段弧关系，新增2个break point),新增的break point将会在后续画出新的edge,但是注意这两个点将会画出一条(下图橙色边)边而非两条边，这条边的两头都还未知需要这两个点来画，在后续发生circle event后确定vertex(此边发生merge确定了一个vertex)

Delaunay Triangulation

三角抛分是将无序点集互相联系起来的最基本方式，将点和点之间增加三角形式的拓扑

对于任何点集中的a、b点，连线ab被称为点集的diagonal(对角线)

对点集的三角化(traiangulation)是，任意两条diagonal不会相交，三角化后点集最外层边组成的就是点集的凸包，也可视为对点集凸包的2-simplices。

对点集的三角抛分是不唯一的，但可确定3(n-1)-h条diagonal构成的2(n-1)-h个三角，n为点数h为凸包边数

对于一个四边形的三角抛分方案有上面两种，对其中某条边进行edge flipping后可得到另一种抛分方案。

Dual Graph对偶图:voronoi diagram的对偶图为连接site垂直平分原edge的新边构成的图

对voronoi diagram求对偶后就能得到对图的Delaunay Triangulation，反过来说对点集进行Delaunay Triangulation后其对偶就是voronoi diagram

Delaunay Triangulation由于来自维诺图(nlogn)，其具有以下特点

1 像维诺图一样有空圆性，三角抛分后三角的外接圆内为空不存在其他点(当然圆和圆之间是存在交集的)，**所有三角的外接圆心都是维诺图vertex，**存在一极大空圆以某条三角边作为弦(DT充分条件)

2 DT内的三角边必然包括某个site以及其最近邻site的连线，会存在以此连线为直径的空圆

NNG(最近邻图，有向图最近邻关系并非互相的)是DT的子图

Gabriel graph

两点为直径的空圆，是此连线作为GG的边的充要条件–其他site与此边所成角为锐角

同样点集的VD中，cell(p1)和cell(p2)存在共同edge,则p1p2为一GG边，连接各个VD中的site只要与Cell相交则site-site为GG边

GG是DT的子图

Relative neighorhood graph

相对邻居图

点集中的site1和site2，以site1和site2为圆心以site1-site2距离为半径的两个圆会交于一个纺锤形区域，此区域若为空则site1-site为RNG图内一条边

RNG是GG的子图–RNG是DT的子图

与DT相关的问题

EMST(euclidean Minimun spanning tree)

Minimun spanning tree最小生成树:用最小代价使得图完整连通(从任意节点可到任意其他节点)–将原图的全部顶点以最少的边连通的子图(无环路,边数为点数-1)

对于一个带权连通图，生成树不同，树中各边上权值总和也不同，权值总和最小的生成树则称为图的最小生成树。

EMST就是以节点间欧式距离作为权值的最小生成树，即以边的欧式距离为代价，最小的连通图

EMST是RNG的子图,EMST可从DT得到

总结 $ NNG(S)\subseteq EMST(S)\subseteq RNG(S)\subseteq GG(S)\subseteq DT(S)--VD(S) $

欧式距离邮差问题(ETSP 欧式旅行商问题)–从一点出发遍历所有其他点并回到起始点需要的欧式距离最小path

在EMST基础上，只需要O(n)时间可得到最差是最优解两倍长度的ETSP近似解，在EMST上从起点开始遍历全图(视为双向 twin edge,最优解是期望经过每个城市一次即可，但是在EMST上遍历大概率会重复经过某一城市，每个节点会被进入其度数此出去度数次)，在搜索时尝试只进出某个城市1次，若需要进出某个城市多次尝试跳过这个城市check下个城市

minimun weight triangulation(最小权三角抛分，MWT)

累积三角边权重最小的那个三角抛分求法–NP，DT三角抛分标准是空圆

圆内弦对圆上点的支撑角是相等的(等弦对等角，注意是圆上点需要在弦的同一侧才有这个性质，当点运动到另一侧弦对应的弧已经发生变化)，此弦对圆内点的支撑角大于圆上，对圆外点支撑角小于圆上

每个三角抛分所含的角数量固定为6n-3h-6(n为site数，h为凸包边数)

事先计算出所有角度并pre sort。我们希望三角抛分中尽量不要出现狭长的三角形(三角形中有很小的锐角)，DT抛分内含maximizing the minimum angle趋势即极大化计算出来的角度序列的字典序(即极大化最小角度)，DT空圆的性质使得圆外site的支撑角一定小于圆上支撑角，使得圆上构成的三角角度序列极大

void DynamicVoronoi::checkVoro(int x, int y, int nx, int ny, dataCell& c, dataCell& nc) {

  if ((c.sqdist>1 || nc.sqdist>1) && nc.obstX!=invalidObstData) {
    if (abs(c.obstX-nc.obstX) > 1 || abs(c.obstY-nc.obstY) > 1) {
      //compute dist from x,y to obstacle of nx,ny
      int dxy_x = x-nc.obstX;
      int dxy_y = y-nc.obstY;
      int sqdxy = dxy_x*dxy_x + dxy_y*dxy_y;
      int stability_xy = sqdxy - c.sqdist;
      if (sqdxy - c.sqdist<0) return;

      //compute dist from nx,ny to obstacle of x,y
      int dnxy_x = nx - c.obstX;
      int dnxy_y = ny - c.obstY;
      int sqdnxy = dnxy_x*dnxy_x + dnxy_y*dnxy_y;
      int stability_nxy = sqdnxy - nc.sqdist;
      if (sqdnxy - nc.sqdist <0) return;

      //which cell is added to the Voronoi diagram?
      if(stability_xy <= stability_nxy && c.sqdist>2) {
        if (c.voronoi != free) {
          c.voronoi = free;
          reviveVoroNeighbors(x,y);
          pruneQueue.push(INTPOINT(x,y));
        }
      }
      if(stability_nxy <= stability_xy && nc.sqdist>2) {
        if (nc.voronoi != free) {
          nc.voronoi = free;
          reviveVoroNeighbors(nx,ny);
          pruneQueue.push(INTPOINT(nx,ny));
        }
      }
    }
  }
}

void DynamicVoronoi::reviveVoroNeighbors(int &x, int &y) {
  for (int dx=-1; dx<=1; dx++) {
    int nx = x+dx;
    if (nx<=0 || nx>=sizeX-1) continue;
    for (int dy=-1; dy<=1; dy++) {
      if (dx==0 && dy==0) continue;
      int ny = y+dy;
      if (ny<=0 || ny>=sizeY-1) continue;
      dataCell nc = data[nx][ny];
      if (nc.sqdist != INT_MAX && !nc.needsRaise && (nc.voronoi == voronoiKeep || nc.voronoi == voronoiPrune)) {
        nc.voronoi = free;
        data[nx][ny] = nc;
        pruneQueue.push(INTPOINT(nx,ny));
      }
    }
  }
}

    // 用P_3_8对(x,y)的上下左右进行merge,每个检查都只检查了3个像素是因为(x,y)一定是freeQueued的所以不需要检查
    if (x+2<sizeX && r.voronoi==occupied) {
      // fill to the right
      if (tr.voronoi!=occupied && br.voronoi!=occupied && data[x+2][y].voronoi!=occupied) {
        r.voronoi = freeQueued;
        sortedPruneQueue.push(r.sqdist, INTPOINT(x+1,y));
        data[x+1][y] = r;
      }
    }
    if (x-2>=0 && l.voronoi==occupied) {
      // fill to the left
      if (tl.voronoi!=occupied && bl.voronoi!=occupied && data[x-2][y].voronoi!=occupied) {
        l.voronoi = freeQueued;
        sortedPruneQueue.push(l.sqdist, INTPOINT(x-1,y));
        data[x-1][y] = l;
      }
    }
    if (y+2<sizeY && t.voronoi==occupied) {
      // fill to the top
      if (tr.voronoi!=occupied && tl.voronoi!=occupied && data[x][y+2].voronoi!=occupied) {
        t.voronoi = freeQueued;
        sortedPruneQueue.push(t.sqdist, INTPOINT(x,y+1));
        data[x][y+1] = t;
      }
    }
    if (y-2>=0 && b.voronoi==occupied) {
      // fill to the bottom
      if (br.voronoi!=occupied && bl.voronoi!=occupied && data[x][y-2].voronoi!=occupied) {
        b.voronoi = freeQueued;
        sortedPruneQueue.push(b.sqdist, INTPOINT(x,y-1));
        data[x][y-1] = b;
      }
    }
  }
