Boundary Value Problem (BVP)

BVP没有泛解 需要具体例子具体分析，是状态空间采样规划的基础

实现状态空间的离散化， 给定两个状态 解出两个状态之间的轨迹

举一个最简单的一维空间的例子

求 x(0)=a x(T)=b之间的轨迹

假设5次多项式的轨迹可以满足要求

设 x(t) = c5t^5 + c4t^4 + c3t^3 + c2t^2 + c1t + c0

边界条件 x(0) = a x(T) = b

可以得到

左边[a b 0 0 0 0]T = [x(0) x(T) x’(0) x’(T) x’’(0) x’’(T)]T

5次多项式 2个点 是求解不出一条轨迹的,我们需要在无穷多的解中 根据我们的优化目标找出最好的那个

Optimal Boundary Value Problem (OBVP)

我们的优化目标 希望在T时间段内jerk平方的积分最小

三维空间所以jk有三个

设状态为9维状态 s = [x,y,z,vx,vy,vz,ax,ay,az]T = [p,v,a]T

设控制量就为jerk u = [jx,jy,jz]T=[j1,j2,j3]T

三阶积分系统 系统方程

sk’ = f(sk,uk) =(p,v,a)’|k = (vk,ak,jk) k=1,2,3=x,y,z

拉格朗日因子 又叫 协态costate /\ = [/\1,/\2,/\3]

系统方程中有多少个状态s就需要多少个协态变量

H = /\Tf + L

= /\T * (v,a,j) + j^2/T

H(s,u,/) = j^2/T + /\1v + /\2a + /\3j

上面的H,v,a,j 都是列向量 都有三个元素H1,H2,H3

下面讲一下构造J

J由两项构成 第一项是一个终止状态的惩罚项 – 驱动算出来的u使s朝终止状态s(T)前进(软约束) 第二项是系统在运行过程中的代价(能量损耗)
