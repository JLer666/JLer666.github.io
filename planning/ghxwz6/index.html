5 基于minimum snap的轨迹优化2 分段轨迹表达,约束形式,凸优化简介

创建于 2022-03-09 · 最后修改于 2025-03-03 · cant

下面重新描述一下我们的任务，我们的前端轨迹是简单的由较少的必经点之间直线组成的前端路径(JPS)。 计算每两个必经点之间的轨迹，轨迹用参数化的5阶多项式表达，优化多项式参数使，1总体的轨迹(将分段轨迹全部相连后的轨迹)满足首末姿态约束，2并且轨迹一定经过我们规定的必经点，3并且轨迹上的必经点位置的左右极限，以及必经点位置的高阶导数的左右极限都相等(必经点状态光滑)，4同时最小化整体轨迹的snap。

总的轨迹多项式，是分段轨迹多项式的组合。 每段时间区间内的子轨迹多项式组成总的轨迹多项式

我们不需要保证每段多项式的系数一致，但是如果能保持一致那是最好的可以让问题更简单。

每段轨迹的运行时间是已知固定的。(不像前面的OBVP问题，可以求最佳运行时间T*)

下面讲下对于轨迹的约束：

红框中写的有问题，红框中的约束其实就是初态终态约束。

f0(k)(T0) = x(k)(T0) 第一段多项式的T0起始时刻状态的0k阶导数，要和我们规定的初态的0k阶导数全部相等

fN(k)(TM) = x(k)(TM) 最后一段多项式的TM终止时刻状态的0k阶导数，要和我们规定的末态的0k阶导数全部相等

蓝框中的约束，是对连接两段轨迹的必经点的状态约束。

fj(k)(Tj) = fj+1(k)(Tj) 第j段多项式的Tj终止时刻状态的0k阶导数，要和其连接的下一段(j+1段)多项式的Tj起始时刻状态的0k阶导数 全部相等。 保证多项式在这个必经点的0-k阶导数全部连续(此点k阶连续–k-1阶光滑)

这里再强调一下光滑!=连续，k阶光滑=k+1阶连续(k阶再求一次导数)

确保轨迹在某个阶数上光滑 确保轨迹在某个阶数上连续 最小化轨迹的某一阶导数(最小化snap)

这三个要求是彼此独立的互不相关的。

工程上 如果我们要

最小化一段轨迹的jerk,要求轨迹是 2*3(jerk)-1=5 是时间的5次多项式 使轨迹上每点的 p,v,a连续 当然如果你想jerk也连续，那也完全没问题

要最小化一段轨迹的snap,要求轨迹是 2*4(sanp)-1=7 是时间的7次多项式 使轨迹上每点的 p,v,a,j连续 当然如果你想snap也连续，那也完全没问题

我们现在是将轨迹分段了，所以如果总轨迹由k段轨迹组成

要minimum jerk:

必经点约束就有 3(初态p0,v0,a0约束) + 3(末态pf,vf,af约束) + k-1(k段轨迹共k-1个中间必经点 位置约束) = k+5 个约束

假设每段轨迹的阶数是N,N阶轨迹的参数是N+1个(比如5次多项式的参数是a5~a0是6个)，总共有k段轨迹，那么总的未知数量为 (N+1)*k

我们只有k+5个约束最多只能解出k+5个未知量，所以如果我们要将轨迹完全求解要求

自由度>=变量数 (N+1)*k >= k + 5 得N >= 5/k

轨迹的阶数必至少为 5/段数 ，N >= 5/k可以看出来 分的段数越多,每段轨迹的阶数N可以越低

但是前端返回的waypoint(必经点)的数量是未知的，所以我们一般都按照阶数最高的情况来设计(即前段返回的轨迹只有一段 首尾两个点的情况)，认为k=1对应的阶数作为轨迹多项式的次数。

下面讲一些和凸优化相关的基本概念

凸函数(convex function)

如果函数f的定义域domf是凸集，且对于任意在定义域中的x,y,和任意0<=theta<=1有,f(theta*x+(1-theta)y) <= thetaf(x) + (1-theta)*f(y) ,则说f(x)函数在n维欧式空间中是凸的

从几何上来看，凸函数就是函数上任意两点构成的弦，都在这两点之间的函数曲线 的上方(在下方就是 凹的)

如果f是凹(concave)的则-f一定是凸(convex)的

如果在0<theta<1条件下满足上述要求，则称为严格凸

凸函数，沿其梯度下降的方向是一定可以取到全局最小值。

凸集合(convex set)

对于集合C中的任意两点x,y以及任意参数0<=theta<=1,有 theta*x + (1-theta)*y 定义的点 属于C,则称C为凸集合

从几何上来看，凸集合中任意两点的连线，连线上的点一定都在集合内部。

凸优化

对于一般的优化问题可以写为下面这种形式

f0是待优化函数，fi是不等式约束，hi是等式约束。

凸函数的定义为下面这种形式

待优化函数f0，以及不等式约束函数fi都是凸函数，并且等式约束是仿射函数f(x)=Ax-b=0。还有就是x的定义域dom为凸集。

仿射函数即由由1阶多项式构成的函数，一般形式为f(x) = Ax+b ( f(x,y)=Ax+By+C )，这里，A 是一个 m×k 矩阵，x 是一个 k 向量,b是一个m向量，实际上反映了一种从 k 维到 m 维的空间映射关系。(补充一下 线性函数是 b为0向量的仿射函数) 仿射函数和线性函数既是凸的又是凹的

对于凸优化问题，任何的局部最优点，都是全局最优点。 大部分问题在其形式上都不是凸的，但是可以通过一系列变换变为凸优化问题。

下面介绍几种凸优化问题的描述形式

线性规划

线性规划的 待优化函数，不等式约束，等式约束 都是仿射函数

二次规划

待优化函数是凸的二次型，等式约束和不等式约束都是仿射函数，参数P阵都大于0

二次约束的二次规划

待优化函数和不等式约束是凸的二次型，等式约束是仿射函数，参数P0i阵都大于0

二阶锥规划

线性目标函数，二阶锥约束。 是一种更广泛的问题定义方法

ci = 0,变为QCQP问题

Ai不是矩阵是一个行向量，则变为LP问题

半正定规划

待优化目标是线性函数，不等式约束是线性矩阵不等式(LMI),等式约束是仿射函数

LP和SOCP可以等价变换为对应的SDP问题，SDP是凸优化的一种更广泛的描述
