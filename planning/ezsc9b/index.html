Hybrid A–混合A**

在lattice graph采样(control lattice 定输入 定时间 缺点规划出的边分化程度不高 都聚在一起) 我们一般会将输入u分化的非常细(20,30等分) 这导致图非常稠密，我们需要对图进行剪枝

通过栅格地图进行剪枝

在对lattice graph进行图搜索时(是在离散控制空间搜索)，保证每个栅格中只有一个可行的state节点，在图搜索中会发现有的lattice边会落在同一个栅格中，此时若此栅格之前有记录可行的state节点，则比较之前记录的state节点的cost和新的这个节点cost，保留cost最小的这个节点在这个栅格中。

结束循环

g值的计算，是计算的状态变换的代价。父状态->子状态 我们已经固定了这条轨迹长，我们可以根据是前进还是后退 给不同的权重当做路径长度代价。

我们可以知道爷爷->父是前进还是后退，如果爷爷->父的方向和父->子的轨迹方向不一样 则说明父节点需要速度为0才能满足路径方向的变换。这个代价是比较大的是一个先减速到0再加速度的过程，所以如果出现 爷爷->父方向和父->子路径方向不一致 直接给一个比较大的惩罚。

父->子采样的轨迹用的转向角越大，代价越大(我们不喜欢转向 转向也意味着减速)，我们将转向角绝对值乘上一个固定系数作为惩罚

爷爷->父轨迹所用的转向角和父->子轨迹所用的转向角如果相差越大，将会导致车体大幅度的摆动，会造成车体的不稳定。所以如果前后两次转向角相差越大，给的惩罚越大

h值的计算 = max(考虑动力学约束不考虑障碍的当前状态到终点状态RS曲线长度,最开始预计算的从终点到当前节点的考虑障碍不考虑动力学约束的djistra路径长 - 当前节点到终点的欧式距离(减去后的路径长其实就是因为障碍存在所导致的绕路路径长)) 可以取max也可以取权值相加

简化的小车阿克曼模型

认为 tan theta = dyr/dxr – 在dt->0认为后轴中心做的都是直线运动

sin theta/cos theta = tan theta = dyr/dxr

得到

  • xr’* sin theta + yr’*cos theta = 0

同时后轴的速度可由后轴位移推导得到

vr = xr’*cos theta + yr’ * sin theta (xr,yr)是后轴中心在世界坐标系的位置

由上两式得到

xr’ = vrcos theta yr’ = vrsin theta

前轴坐标为 xf = xr +Lcos theta yf = yr + Lsin theta

由上图自行车模型可得 L/R = tan delta ;delta为前轮转角

同时车体角速度公式 w = theta‘ = vr/R = vr*tan delta/L

得到小车的运动学模型

[xr’ yr’ theta’]T = [cos theta sin theta tan delta/L ]T*vr

下面假设小车以一常数行驶 vr = 1(小车只能前进不能后退 并且只有一档速度 这是dubins曲线的特点！！),车长1，

我们的控制量u为 = [-tan delta max,tan delta max] 这个区间

运动学模型变为[xr’ yr’ theta’]T = [cos theta sin theta tan delta ]T

为了简化我们假设小车的最大打脚delta max = pi/4 = 45度则

控制集合 u = [-1 ,1] 区间 我们用3个符号代表3种打脚

S–u=0 L–u=1 R–u=-1 所有Dubins模型车(只能前进 速度只有一档)的最佳曲线都可以用这3种符号+旋转角度(对L,R)和执行距离(对S)构造出来 –

因为车速已经定了最大打脚也定了L,R转向的曲率圆已经被完全固定下来了,dubins曲线要表达的是Dubins模型车从一状态到另一状态的最短路径可以用 执行+完全向左+完全向右来完整描述出这一最短路径 下面举个例子

qI表示起始状态qG表示终止状态

图左dubins模型车由qI到qG的最短路径可由 R_alpha S_d L_gama来表达 代表的意思就是先完全向右转alpha度 再直行d距离 再完全左转gama度就可以到qG

右图同理 为 R_alpha L_beta R_gama

所有最短路径都可以由3种dubins符号组合成

其中规定在第一个位置或第三个位置出现的转向 转向累计角alpha,gama可以是0-2pi中的任何角度，而如果在第二个位置出现的转向 转向累计角beta必须是(pi,2pi)否则dubins轨迹不是最短路径存在其他序列是优于当前符号序列的

前后两个符号不能相同，因为连续的两个相同序号可以合成为一个符号

CSC轨迹(RSR LSR RSL LSL) 转向+直线+转向

对于每一对RR,LL,LR,RL圆只有一条有效切线，CSC轨迹共有4条切线，对于CSC轨迹的计算就变为计算这条切线。

辆沿着最小转弯半径构成的圆周行驶到第一个圆的切点，然后直行到第二个圆的切点(两个切点由计算出的这条切线决定)，再沿着最小转弯半径构成的圆周行驶到目的地

CCC轨迹(RLR LRL)转向1+转向2+转向1

下图是LRL

CCC轨迹的根本就是计算这中间转向圆的位置(3个圆的转弯半径都是固定的)，并且3个圆相切，只要计算得到这中间圆圆心坐标，CCC轨迹就被确定下来了。

下面介绍两种计算CSC轨迹切线的方法

几何法

已有两圆 圆1 圆心p1(x1,y1)半径r1 圆2 圆心 p2(x2,y2)半径r2 我们要计算这两个圆之间的切线

定义V1向量 = (x2-x1,y2-y1) 向量膜长D = sqrt((x2-x1)^2+(y2-y1)^2) 以v1向量的中点p3((x2+x1)/2,(y2+y1)/2)为圆心，r3=D/2为半径作圆3得上图 圆3经过p1,p2

构造圆4 圆心和圆1同 半径r4 = r1+r2 记圆4和圆3的上交点为pt

记pt-p1向量为v2=pt-p1如下图 黑箭头

此时v2和圆1的交点就是，连接圆1和圆2切线的第一个切点

记录角pt_p1_p3为gama–以v1为0度标准 就是向量v2和向量v1的夹角

记向量v2和世界坐标x正方向所成角为 theta=gama+atan2(v1)

得到pt在世界坐标系下坐标 xt=x1+(r1+r2)cos theta yt=y1+(r1+r2)sin theta

记录v3向量 = r1*v2/||v2|| 下图红箭头

得到切点pit1世界坐标为 piit1=p1+v3

下面做pt和p2的连线 得到向量v4=p2-pt

将向量v4的起点平移到pit1上，此时向量的终点就是第二个圆的切点

pit2 = pit1+v4

我们在计算的时候用的是圆3和圆4的上角点pt，同样可以用圆3，4下交点经过同样的计算过程得到另外两个切点pit3,pit4 注意这样计算出来的切点为内切点 要求内切点我们要画的圆4 r4=|r1-r2|

方法2向量法 – 其实就是方法1的向量形式 求外！！切点

定义c1圆心p1半径r1 c2圆心p2半径r2 定义v1=p2-p1 膜长D

待求c1,c2外切点pot1,pot2, 定义v2=pot2-pot1

(对于dubins车而言 两个圆的半径是相等的 这个方法也可以计算圆半径不等的情况)

定义n为垂直于v2的单位向量

因为r1可能!=r2 我们想修改v1使其平行于v2—就是要让v1==v2 向量相等不需要起点相同 只需要指向的方向相同

v2 = v1 - (r2-r1)*n

因为有v2n=0–n垂直于v2 所以有 n(v1 - (r2-r1)n)=0 n为单位向量–nn=1

得到 n*v1=r2-r1

两侧同时除膜长D 将向量v1也变为单位向量 这样可以将单位v1旋转就能得到向量n

nv1/D = (r2-r1)/D 向量点乘AB=|A||B|cos theta

n和v1/D的膜长都为1 – 即我们知道两向量夹角的余弦值 cos theta = (r2-r1)/D

我们将cos theta = (r2-r1)/D 标记为C

向量A逆时针旋转theta得到向量B

xB = xAcso theta - yAsin theta yB = xAsin theta - yAcos theta

设n=(nx,ny) C(就是cos theta) 以及 向量旋转公式得到

nx = v1xC - v1ysqrt(1-C^2) ny = v1xsqrt(1-C^2) + v1yC

得到向量n后就得到了两个切点

pot1 = p1+r1n pot2 = p2 + r2n

theta = theta+2pi

else if theta>0 and d=顺–R

theta = theta-2pi

gama= gama+2pi

else if gama>0 and d=顺–R

gama= gama-2pi

下面介绍一下Reeds-Shepp的一些对称特性

我们求解出了初态到(x,y,theta)的L+S+R+(随便举个例子)的曲线后

timefilp对称性

我们将终态改为(-x,y,-theta)用求解L+S+R+同样的方法就能得到初态到(x,y,theta)的L-S-R-曲线

reflect对称性

我们将终态改为(x,-y,-theta)用求解L+S+R+同样的方法就能得到初态到(x,y,theta)的R+S+L+(顺序相反)曲线

timefilp+reflect

我们将终态改为(-x,-y,theta)用求解L+S+R+同样的方法就能得到初态到(x,y,theta)的R-S-L-(顺序相反)曲线
