已知一系列点序列，想要拟合或插值得到样条曲线的多项式。拟合不要求方程通过所有的已知点，讲究神似，就是整体趋势一致。插值则是形似，每个已知点都必会穿过，但是高阶会出现龙格库塔现象，所以一般采用分段插值。今天我们就来说说这个分段三次样条插值。

传入x,y散点坐标，设共nx个点,计算dx数组h = [x1-x0,x2-x1,…,x_{nx-1}-x_{nx-2}]，设其中两个端点x0=a,x_{nx}=b。我们要求的三次样条需要满足以下要求

S0(x) x0<=x<=x1

S1(x) x1<=x<=x2

S(x)=…

S_{nx-2}(x) x_{nx-2}<=x<=x_{nx-1}

1 对于每个分段区间[xi,xi+1]上，此段分段曲线Si(x)都是三次多项式

2 在我们给定的点上满足插值条件即 S(xi) = yi

3 曲线光滑S(x),S’(x),S’’(x)都连续

一段yi= dix^3 + cix^2 + bix +ai有4个未知数，共nx个点，nx-1个区间，所以共4*(nx-1)个未知数要求

为了求解4*(nx-1)个未知数，就需要找到4*(nx-1)个等式方程

1 给定的(xi,yi)必须在曲线上即S(xi) = yi。对于起始和终止点只在一条曲线上S0(x0) = y0,S_{nx-1}(x_{nx-1}) = y_{nx-1}。对于中间点因为其既是上条的终点也是下条的起点，为了满足S(x)连续，所以每个中间点都可以提供2个等式。Si(xi+1) = yi,S_{i+1}(xi+1) = yi+1。共1+1+(nx-2)*2 = 2nx-2个方程

2 要求S(x)‘连续，对于所有中间点都有一个约束Si’(xi+1) = Si+1’(xi+1)共nx-2个方程

3 要求S(x)‘‘连续，对于所有中间点都有一个约束Si’’(xi+1) = Si+1’’(xi+1)共nx-2个方程

目前共 2nx-2 + nx-2 + nx-2 = 4nx - 6个方程

还差两个方程，由边界给定。共三种边界条件

1 自然边界，端点的二阶导数为0. S’’(x0) = S’’(x_{nx-1}) = 0

2 固定边界条件，给定端点的一阶导数。S0’(x0) = A,S_{nx-2}’(x_{nx-1}) = B

3 非扭结边界( Not-A-Knot Spline ): 强制第一个插值点的三阶导数值等于第二个点的三阶导数值，最后第一个点的三阶导数值等于倒数第二个点的三阶导数值.

S0’’’(x0) = S1’’’(x1) and S’’’{nx-3}(x{nx-2}) = S’’’{nx-2}(x_{nx-1})

求解

Si(x) = di(x-xi)^3 + ci(x-xi)^2 + bi(x-xi) + ai

S’i(x) = 3di(x-xi)^2 + 2ci(x-xi) + bi

S’‘i(x) = 6di(x-xi) + 2ci

hi = xi+1-xi

1 由Si(xi) = yi代入得到 ai = yi

2 S(x)连续得到 Si(xi+1) = Si+1(xi+1) = yi+1

dihi^3 + cihi^2 + bihi + ai = yi+1

3 S’(x)连续得到Si’(xi+1) = S’i+1(xi+1)

Si’(xi+1) = 3di(xi+1-xi)^2 + 2ci(xi+1-xi) + bi = 3dihi^2 + 2cihi + bi

Si’+1(xi+1) = bi+1

即得到

bi+1 = 3dihi^2 + 2cihi + bi

4 S’’(x)连续得到Si’’(xi+1) = S’‘i+1(xi+1)

Si’’(xi+1) = 6dihi + 2ci

S’‘i+1(xi+1) = 2ci+1

即得到

2ci+1 = 6dihi + 2ci

** 设mi = Si’’(xi) = 2ci,**则改写为 di = (mi+1-mi)/6hi

5 将di = (mi+1-mi)/6hi, ai = yi代入2中dihi^3 + cihi^2 + bihi + ai = yi+1

得到 bi = (yi+1-yi)/hi - himi/2 -hi(mi+1-mi)/6

6 将上面计算得到的ai,bi,ci,di代入3中bi+1 = 3dihi^2 + 2cihi + bi,

得到

** himi + 2(hi+h_{i+1})m_{i+1} + h_{i+1}m_{i+2} = 6[(y_{i+2}-y_{i+1})/h_{i+1} - (y_{i+1}-yi)/hi]**

以此递推式构造一个以m为未知数的线性方程

1 自然边界条件S’’(x0) = S’’(x_{nx-1}) = 0由mi定义mi = Si’’(xi) = 2ci即m0=0,m_{nx-1}=0

由递推式4nx - 6个方程，2个边界条件方程。写成Ax=b矩阵形式

$ \begin{bmatrix} 1& 0& 0& & \cdots & 0 \\ h_0& 2(h_0+h_1)& h_1& 0& & \\ & h1& 2(h_1+h_2)& h2& 0& \\ & & h2& 2(h_2+h_3)& h3& \vdots \\ \vdots& & \ddots& \ddots& \ddots& \\ & &0 &h_{nx-3} &2(h_{nx-3}+h_{nx-2}) &h_{nx-2} \\ 0& \cdots& & 0& 0&1 \\ \end{bmatrix} \cdot \begin{bmatrix} m0\\ m1\\ m2\\ \vdots\\ m_{nx-1}\\ \end{bmatrix} = 6 \begin{bmatrix} 0\\ \frac{y2-y1}{h1}-\frac{y1-y0}{h0}\\ \frac{y3-y2}{h2}-\frac{y2-y1}{h1}\\ \frac{y4-y3}{h3}-\frac{y3-y2}{h2}\\ \vdots\\ \frac{y_{nx-1}-y_{nx-2}}{h_{nx-2}}-\frac{y_{nx-2}-y_{nx-3}}{h_{nx-3}}\\ 0\\ \end{bmatrix} $

左侧的系数矩阵为严格对角占优矩阵。即：每一行中对角元素的值的模 > 其余元素值的模之和。故线性方程组有唯一解，且雅克比迭代法、高斯-赛德尔迭代法和0<ω≤1的超松弛迭代法均收敛。(不懂)

2 固定边界条件，给定端点的一阶导数。S0’(x0) = A,S_{nx-2}’(x_{nx-1}) = B

S0’(x0) = A – b0=A – 由(5)bi = (yi+1-yi)/hi - himi/2 -hi(mi+1-mi)/6 – A = (y1-y0)/h0 - h0/2m0 - h0/6(m1-m0)

得到 2h0m0 + h0m1 = 6[(y1-y0)/h0 - A]

S_{nx-2}’(x_{nx-1}) = B – b_{nx-2} = B

得到 h_{nx-2}m_{nx-2} + 2h_{nx-2}m_{nx-1} = 6[B - (y_{nx-1}-y_{nx-2}/h_{nx-2})]

将这两个条件更换1中A矩阵的第一和最后一行

$ \begin{bmatrix} 2h0& h0& 0& & \cdots & 0 \\ h_0& 2(h_0+h_1)& h_1& 0& & \\ & h1& 2(h_1+h_2)& h2& 0& \\ & & h2& 2(h_2+h_3)& h3& \vdots \\ \vdots& & \ddots& \ddots& \ddots& \\ & &0 &h_{nx-3} &2(h_{nx-3}+h_{nx-2}) &h_{nx-2} \\ 0& \cdots& & 0& h_{nx-2}&2h_{nx-2} \\ \end{bmatrix} \cdot \begin{bmatrix} m0\\ m1\\ m2\\ \vdots\\ m_{nx-1}\\ \end{bmatrix} = 6 \begin{bmatrix} \frac{y1-y0}{h0}-A\\ \frac{y2-y1}{h1}-\frac{y1-y0}{h0}\\ \frac{y3-y2}{h2}-\frac{y2-y1}{h1}\\ \frac{y4-y3}{h3}-\frac{y3-y2}{h2}\\ \vdots\\ \frac{y_{nx-1}-y_{nx-2}}{h_{nx-2}}-\frac{y_{nx-2}-y_{nx-3}}{h_{nx-3}}\\ B-\frac{y_{nx-1}-y_{nx-2}}{h_{nx-2}}\\ \end{bmatrix} $

3 非扭结边界条件

S0’’’(x0) = S1’’’(x1) and S’’’{nx-3}(x{nx-2}) = S’’’{nx-2}(x_{nx-1})

Si’’’(x) = 6di,

所以S0’’’(x0) = S1’’’(x1) – > d0 = d1

S’’’{nx-3}(x{nx-2}) = S’’’{nx-2}(x_{nx-1}) –> d_{nx-3} = d_{nx-2}

并且由于(4)di = (mi+1-mi)/6hi

所以

(m1-m0)h1 = (m2-m1)h0

(m_{nx-2}-m_{nx-3})h_{nx-2} = (m_{nx-1 - m_{nx-2}})h_{nx-3}

$ \begin{bmatrix} -h1& h0+h1& -h0& & \cdots & 0 \\ h_0& 2(h_0+h_1)& h_1& 0& & \\ & h1& 2(h_1+h_2)& h2& 0& \\ & & h2& 2(h_2+h_3)& h3& \vdots \\ \vdots& & \ddots& \ddots& \ddots& \\ & &0 &h_{nx-3} &2(h_{nx-3}+h_{nx-2}) &h_{nx-2} \\ 0& \cdots& & -h_{nx-2}& h_{nx-3}+h_{nx-2}&-h_{nx-3} \\ \end{bmatrix} \cdot \begin{bmatrix} m0\\ m1\\ m2\\ \vdots\\ m_{nx-1}\\ \end{bmatrix} = 6 \begin{bmatrix} 0\\ \frac{y2-y1}{h1}-\frac{y1-y0}{h0}\\ \frac{y3-y2}{h2}-\frac{y2-y1}{h1}\\ \frac{y4-y3}{h3}-\frac{y3-y2}{h2}\\ \vdots\\ \frac{y_{nx-1}-y_{nx-2}}{h_{nx-2}}-\frac{y_{nx-2}-y_{nx-3}}{h_{nx-3}}\\ 0\\ \end{bmatrix} $

8 求s=t处的yaw角

已经通过二分找到t所处分段索引，并求出t处插值出的(x,y)

yj(t) = dyj(t-sj)^3 + cyj(t-sj)^2 + byj(t-sj) + ayj

因为是多项式很方便就能求出dx/ds|s=t,dy/ds|s=t

dyj/ds(t) = 3dyj(t-sj)^2 + 2cyj(t-sj) + byj

**yaw|t **= atan2(dyi/ds(t),dxi/ds(t)) = arctan(dyj/ds(t)/dxi/ds(t)) = arctan(dyj/dxi)

    def xy_to_sd_by_kdtree(self, x, y):
        # 使用kd tree加速找近似投影点(spline上到(x,y)最近的这个点)这个过程
        # 在初始化的时候以0.5m为步长离散s得到spline上的点坐标加入kd tree中
        query_point = (x, y)
        dist, index = self.kd_tree.query(query_point)
        if index <= 0: # 最近的是起点
            start_point = self.calc_position(index)
            start_yaw = self.calc_yaw(0)
            vec_a = [x - start_point[0], y - start_point[1]]
            vec_b = [math.cos(start_yaw), math.sin(start_yaw)]
            d = cross_prod(vec_b, vec_a)
            s = dot_prod(vec_a, vec_b)
            return s, d
        elif index >= len(self.sample_ss) - 1: # 最近的是终点
            end_point = self.calc_position(self.length())
            end_yaw = self.calc_yaw(self.length())
            vec_a = [x - end_point[0], y - end_point[1]]
            vec_b = [math.cos(end_yaw), math.sin(end_yaw)]
            d = cross_prod(vec_b, vec_a)
            s = dot_prod(vec_a, vec_b) + self.length()
            return s, d

        def normalize(vec):
            vec_length = math.hypot(vec[0], vec[1])
            if vec_length >= 1e-3:
                vec = [vec[0] / vec_length, vec[1] / vec_length]
            else:
                vec = [0, 0]
            return vec
        # 最近点的上个点和下个点，各个点之间距离0.5m
        last_point = self.sample_points[index - 1]
        next_point = self.sample_points[index + 1]
        point = self.sample_points[index]
        # 在spline上取了3个点，构成两条线，让(x,y)分别计算到这两条线的距离，取其中更小的距离作为d

        vec_a = [x - last_point[0], y - last_point[1]]
        vec_b = normalize([point[0] - last_point[0], point[1] - last_point[1]])
        last_d = cross_prod(vec_b, vec_a)
        last_s = dot_prod(vec_b, vec_a) + self.sample_ss[index - 1]
        vec_a = [x - point[0], y - point[1]]
        vec_b = normalize([next_point[0] - point[0], next_point[1] - point[1]])
        next_d = cross_prod(vec_b, vec_a)
        next_s = dot_prod(vec_b, vec_a) + self.sample_ss[index]
        if abs(next_d) <= abs(last_d):
            return next_s, next_d
        else:
            return last_s, last_d

    def xy_to_sd(self, x, y):
        # 传入(x,y)计算这点的以spline为s轴的frenet坐标系坐标
        min_dist = float('inf')
        min_s = -float('inf')

        # 找近似投影点(以0.01离散s计算spline上点到传入点的最近距离，那个最近点就是近似投影点)
        for s in np.arange(0.0, self.length(), 0.01): # 以0.01离散s
            ref_x, ref_y = self.calc_position(s)
            dist = math.hypot(ref_x - x, ref_y - y)
            if dist < min_dist:
                min_dist, min_s = dist, s

        # 特别地精确检查终点是否投影点
        ref_x, ref_y = self.calc_position(self.length())
        dist = math.hypot(ref_x - x, ref_y - y)
        if dist < min_dist:
            min_dist, min_s = dist, self.length()

        # 特例
        if min_s <= 1e-6:# 最近点几乎是起点
            start_point = self.calc_position(0)
            start_yaw = self.calc_yaw(0)
            vec_a = [x - start_point[0], y - start_point[1]] # 两点构成的位置矢量
            vec_b = [math.cos(start_yaw), math.sin(start_yaw)] # 单位方向向量
            d = cross_prod(vec_b, vec_a) # 叉乘的几何意义是两向量构成的平行四边形面积 = 底边 ,因为单位向量模长为1，所以这个平行四边形的底边为1，我们求出的面积为高
            # 高为位置矢量终点到方向向量的投影即就是我们要的d
            # ，d>0 min_s点在参考线正方向的左边,d<0 min_s点在参考线正方向的右边
            s = dot_prod(vec_a, vec_b)# 位置矢量在该方向上的投影
            return s, d
        elif min_s >= self.length() - 1e-6:# 最近点几乎是终点
            end_point = self.calc_position(self.length())
            end_yaw = self.calc_yaw(self.length())
            vec_a = [x - end_point[0], y - end_point[1]]
            vec_b = [math.cos(end_yaw), math.sin(end_yaw)]
            d = cross_prod(vec_b, vec_a)
            s = dot_prod(vec_a, vec_b) + self.length()
            return s, d

        # 近似投影点在spline上的yaw和坐标
        yaw = self.calc_yaw(min_s)
        ref_x, ref_y = self.calc_position(min_s)

        # 通过叉乘计算(x,y)和近似投影点的d(叉乘后带正负能够分辨是在线的哪个方位上)
        cross_pd = math.cos(yaw) * (y - ref_x) - \
            math.sin(yaw) * (x - ref_y)
        d = abs(min_dist) if cross_pd > 0.0 else -abs(min_dist)
        return min_s, d

    def sd_to_xy(self, s, d):
        # 先得到s在spline上点坐标和yaw
        x_ref, y_ref = self.calc_position(s)
        yaw_ref = self.calc_yaw(s)
        #(math.cos(yaw_ref),math.sin(yaw_ref))为切向量其指向一定是s增大方向

        #(math.cos(yaw_ref+pi/2),math.sin(yaw_ref+pi/2))为法向量由切向量逆时针转90度得到(就是frenet切向量的定义)
        x = x_ref + d * math.cos(yaw_ref + math.pi * 0.5)
        y = y_ref + d * math.sin(yaw_ref + math.pi * 0.5)
        return x, y

# y(t),x(t)
def ComputeCurvature(dx, ddx, dy, ddy):
    a = dx*ddy - dy*ddx
    norm_square = dx*dx+dy*dy
    norm = sqrt(norm_square)
    b = norm*norm_square
    return a/b

def ComputeCurvatureDerivative(dx, ddx, dddx, dy, ddy, dddy):
    a = dx*ddy-dy*ddx
    b = dx*dddy-dy*dddx
    c = dx*ddx+dy*ddy
    d = dx*dx+dy*dy
    return (b*d-3.0*a*c)/(d*d*d)

# y(x)
def ComputeCurvature(dy, ddy):
    a = ddy
    norm_square = 1+dy*dy
    norm = sqrt(norm_square)
    b = norm*norm_square
    return a/b

def ComputeCurvatureDerivative(dy, ddy, dddy):
    a = ddy
    b = dddy
    c = dy*ddy
    d = 1.0+dy*dy
    return (b*d-3.0*a*c)/(d*d*d)
