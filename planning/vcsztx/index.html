Mixed interger optimization(混合整数优化)

Mixed-integer quadratic program trajectory generation for heterogeneous quadrotor teams , D. Mellinger et al.

无人机和障碍物保持距离d, 那不就是 (fx-obs_x)^2 + (fy-obs_y)^2>=d^2这是一个圆的外部，很遗憾圆的内部是凸集合(集合内任意两点的连线,连线上的任意点依旧在集合内)，但是圆的外部不是凸集合！！这个约束无法作为凸优化的约束

上面这篇论文用于无人机编队，队形变化时保证无人机之间不会发生碰撞

不懂感觉这个约束这么写还是非凸约束

主要是讲了一种 或逻辑约束的数学表达

x1-x2<d||x2-x1<d||y1-y2<d||y2-y1<d||z1-z2<d||z2-z1<d

在某一时刻tk只需要一个约束成立 (老师说是在某一时刻第二架无人机只有可能在第一架无人机的上 或 下 或 左 或 右方向，我们只需要约束两架无人机在这个方向上保持d以上的距离)

如何写成凸优化可以接受的线性的不等式约束

将或逻辑的不等式写成与逻辑

x1-x2-c0M<d && x2-x1- c1M<d && y1-y2-c2M<d && y2-y1-c3M<d && z1-z2-c4M<d && z2-z1-c5M<d

与逻辑的约束就和我们之前讲的所有约束都一样了，就是希望在优化的时候所有约束都要成立。

上式M是个极大的数远大于我们规定的d, c0-c5只能是{0,1}并且每一时刻tk只有一个c可以等于0其余的c都是1

这样就完成了在tk时刻 只有一个约束会是 u1-u2<d 而其他的约束都是n1-n2-cM<d由于c=1,M是个远大于d的数余下的这些约束在n1,n2无论是什么的情况下都会使不等式n1-n2-cM<d成立，这样就实现了在某一时刻下实际只有一个约束在生效，即实现了约束的或逻辑。 其中c0-c5也作为待优化变量，并且为c0-c5添加两个硬约束

sum c0-c5 = 5

Soft constrained optimization(软约束优化)

Distance-based trajectory optimization(基于距离场的轨迹优化)

障碍物周围生成一个场排斥机器人轨迹向其靠近

基于硬约束的方法，将可通行区域(corridor)视为等价，只要是可通行区域都一视同仁等价对待。并不关心可通行区域内部 还是有靠近障碍的部分以及相对原理障碍物的部分，所以基于硬约束的有时会生成非常靠近障碍物的的低容忍度(low clearance 容错率低的轨迹)轨迹,这会给控制部分带来难题

对于基于视觉的建图方法来说，大多数情况下充满噪声导致构造出的corridor的质量很低，就会出现low clearance问题

软约束让环境中的障碍生成距离场对轨迹产生斥力

软约束优化的cost function 多个软约束指标加权求和的结果，最终规划出的轨迹是多个软约束共同作用的结果，这就会导致最后规划出的轨迹并不能使某一约束被严格满足

下面对软约束问题进行描述

状态空间一样选用 flat output {x,y,z,yaw}

分段轨迹 每段轨迹描述为多项式形式(下面用的是普通多项式 其实也可以用贝塞尔曲线多项式)

重点是期望优化的代价函数

J = /\1J1 + /\2J2 +/\3*J3 由3个代价组成 其中J1为光滑性代价(smoothness cost)

J2为碰撞代价(collsion cost), J3 为动力学代价(dynamic cost) 将各项加权求和作为总的代价函数

smoothness cost 指的就是我们之前常用的minimum jerk or snap,当我们将轨迹的高阶导数最小化也就意味着轨迹更顺滑(光滑)

collsion cost

用于惩罚靠近障碍的轨迹点

注意上面的积分不是dt而是ds是对曲线积分

如果是对时间积分那么这项代价值的大小和沿此条轨迹运行的速度相关，速度越快此条轨迹的运行时间越短此项代价越小。 但我们想要的是轨迹离障碍物越远此项代价越小

为了对曲线积分 对轨迹进行离散 离散最小小单位为delta t,轨迹上某一点Tk时刻(=T0+第k step*delta t)，我们认为机器人在这很短的一段时间做的是匀速运动

所以

ds = ||v(Tk)||delta t – ||v(Tk)||(上面的形式写错了不是v(t)而是一样是v(Tk)) 各轴轨迹一阶导数在运行delta t时间以前的值做L2,其实也就是那个时刻各轴速度向量的合向量的膜长， ||v(Tk)|| delta t 就是那一小段轨迹

可以这么理解，我们就是将轨迹离散成小段(不是离散时间) 求每一小段所受的斥力，再求和，得到的就是这段轨迹所受的总的斥力

ESDF地图为欧式距离场地图 地图上每点的坐标中保存了，这个坐标离与其最近的障碍物的距离大小

c(p(Tk))为Tk时刻轨迹点在距离场中受到的合斥力大小

对离散点代价求和，近似求出上面那个积分(此项代价不像上面的光滑性代价可以闭式求出解析形式) 只能近似求解

dynamic cost

此项形式和collsion cost类似 一样将轨迹离散化(不离散段了 离散t)，求出离散点上的速度和加速度 惩罚超过限制的轨迹点，对这些点做惩罚

sum 离散步数 超过限制速度和加速度惩罚 * dt

这个待优化函数不是凸函数(距离场本身就不可能是凸的)，只能用非线性优化的方法去求数值解，求待优化函数的代数，去迭代求数值解

下面讲求目标函数的导数

smoothness cost项对dp(自由)求导

这里的dp和minimum snap中的dp有所不同，在minimum snap中 必经点的位置属于固定的约束项，而在这里不存在必经点，轨迹和轨迹之间的连接点位置也是属于自由项可优化，只有起点状态和终点状态属于固定项。u为x,y,z其中一轴

collsion cost 项对dp(自由变量)求导

c(p)和v都和自由变量有关，乘法求导

c(p)是复合函数，求导用链式法则，先求出 c(p)在u轴的梯度

pu==fu就是某一轴的位置

再乘上dpu(Tk)/d dpu,pu(Tk)就是多项式在Tk时刻的点的位置 = [1 Tk Tk^2 .. Tk^n][p0 p1 p2..pn]T

1 Tk Tk^2 .. Tk^n都是定值常数 , p0 p1 p2..pn是多项式参数 和 dp的关系在minimum snap中有讲如下

M-1CT[df dp]T = p 所以 dpu/d dp = M-1CT的右半部分(最后dp向量维度数的列)*

我们记M^-1CT的右半部分 = Ldp,[1 Tk Tk^2 .. Tk^n] = T

dpu(Tk)/d dpu = T*Ldp==F

接下来是d||v||/d dpu 因为||v(t)||=sqrt(vx^2 + vy^2 + vz^2),我们只在一个轴方向u上求导,一样是复合函数求导先对外部的这个norm函数求导再求dvu/d dpu，所以 d||v||/d dpu = vu/||v|| * dvu/d dpu

我们在上面写出了dpu(Tk)/d dpu，而vu(Tk)就是pu(Tk)再对时间求一次导

vu(Tk) = [1 Tk Tk^2 .. Tk^n][p1 2p2 3p3..npn 0]T

[p1 2p2 3p3..npn 0]T和[p0 p1 p2..pn]T的映射关系为

[0 1 …0,0 0 2….0,…. ]n*n * [p0 p1 p2..pn]T–p = [p1 2p2 3p3..npn 0]T–v

记p->v的系数映射矩阵[0 1 …0,0 0 2….0,…. ]n*n为Vm

所以dvu(Tk)/d dpu = dVm*pu(Tk)/d dpu

而dpu(Tk)/d dpu上面求过 = T*Ldp == F

所以 dvu(Tk)/d dpu = TVmLdp == Vm*F == G

d2 Jc/d dpu^2== d2 fo/d dpu^2 碰撞代价对自由变量求二阶导，通过和上面一样的推导方法可以得到

形式虽然复杂但是还算好可以将导数的闭式形式求出来，有些优化问题求不了导数的闭式解只能以加扰动求差分的形式去求数值导数。

ESDF(Euclidean signed distance field) 欧式有符号距离场

二维ESDF地图如下 离障碍物越近代价越大

collsion cost项中的c函数，计算轨迹点到障碍物的代价。 传入p(t)，先通过距离场地图得到此轨迹点在距离场中的值(与此轨迹点最近的障碍物的距离)，再将距离值传入下面这种类指数函数得到碰撞代价。

离障碍物在一定距离内，碰撞代价爆炸增长

对于动力学代价 也很类似

离散轨迹，计算每一点轨迹是否超出了我们规定的动力学限制，类似的指数代价函数形式，只要我们的动力学参数超出限制，动力学代价爆炸增长。

Numerical optimization(数值优化)

无硬约束优化问题(约束都加到代价函数中)，优化计算代价函数使代价函数的导数接近于0(代价值极小)

minimize f(x) 求x* 使df(x*)=0

梯度法

xk+1 = xk +lr_k*delta x 我们希望更新后f(xk+1)<f(xk)

其中delta x是这次搜索的方向

lr_k为step_size，是朝搜索方向前进多少来得到一个新参数，可以通过线搜索的方式来选择

General descent method

given a starting point x ∈ dom f.

repeat

  1. Determine a descent direction ∆x.

  2. Line search. Choose a step size lr > 0.

  3. Update. x ≔ x + lr∆x.

until stopping criterion is satisfied df/dx接近0.

Line search 线搜索

lr = argmin(t>0) f(x+tdelta x) 在delta x方向(参数的更新方向)上选择t使更新后的f值最小

backtracking line search回溯线搜索 (alpha(0,1/2) beta(0,1) )

起始于lr = 1，重复lr = beta*lr直到

f(x+lrdx) < f(x) +alphalr df/dx * dx(这里的dx指的是参数更新方向)

t == lr

x已知，搜索lr,当上面的条件成立时要求alpha满足

单次步长太长导致错过极小，则迭代缩小步长

无约束优化方法

一阶Gradient descent method 梯度下降

我们朝梯度下降的方向搜索新的参数

即delta x = -df/dx

given a starting point x ∈ dom f.

Repeat

  1. ∆x ≔ −∇f x .

  2. Line search. Choose step size t via exact or backtracking line search.

  3. Update. x ≔ x + t∆x.

until stopping criterion is satisfied.

⚫ Stopping criterion usually of the form ||∇f(x)||2≤ε 前后两次的函数f值变化很小

二阶Newton method 牛顿法

https://www.cnblogs.com/liuwu265/p/4714396.html

在当前参数xk处对f函数二阶泰勒展开

f(x) 约等于 f(xk) + df(x)/dx|x=xk * (x-xk) + d2f/dx^2|x = xk *(x-xk)^2/2

对x求导

f’(x) = 0 + df(x)/dx|x=xk + d2f(x)/dx2|x=xk* (x-xk) 3阶项省略?

令x = xk+1带入得到

f’(xk+1) = df(x)/dx|x=xk + d2f(x)/dx2|x=xk* delta x

我们期望新参数xk+1处的导数为0

0 = df(x)/dx|x=xk + d2f(x)/dx2|x=xk* delta x

得到delta x = -df(x)/dx|x=xk*d2f(x)/dx2|x=xk ^-1

given a starting point x ∈ dom f.

Repeat

  1. ∆x ≔ −∇ 2 f(x) −1 ∇f(x).

  2. Line search. t = argmin t>0 f(xk− t∇ 2 f(x) −1 ∇f(x))..

  3. Update. x ≔ x + t∆x.

until stopping criterion is satisfied.

对于最小二乘问题(优化目标为0 平方形式 值不会很大)可以用高斯牛顿法对Hession阵进行近似 ⚫ For Gauss-newton: ∇ 2 f x ≈ J fT J f , J f is Jacobi matrix, ∆x = −(J fT J f ) −1 J fT

二阶 Levenberg-Marquardt method 一阶法和二阶的折中

Improvement of Gauss-newton method: ∆x = −(J fT J f + λI) −1 J fT

given a starting point x ∈ dom f, start λ 0 > 0 .

Repeat

  1. ∆x = −(J fT J f + λI) −1 J fT .

  2. Update. λ , the updating is controlled by the gain ratio

  3. Update. x ≔ x + ∆x.

until stopping criterion is satisfied.

⚫ Stopping criterion usually of the form ||∇f (x)||2≤ε

⚫ Whenλ->0, LM method -> Gauss-newton method

⚫ Whenλ->∞, LM method -> Gradient descent method
