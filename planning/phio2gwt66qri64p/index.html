2 anchor范围约束

anchor内存有其在原始line上的s，首先根据此s计算其在多项式中对应的t(t其实就是每段归一化后的s)

$ scale=\frac{anchor.back.s-anchor.front.s}{s_{n,1}-s_{1,0}} $

按照anchor所在s在整条原始line上的比例得到对应t，将这一系列对应t记位anchor_t(在程序中为evaluated_t)

$ anchor_t=\frac{anchor[?].s-anchor.front.s}{scale} $

每个anchor内存有原始参考线上此点的位置和角度。由于spline的划分是按照长度等距离将原line的某个s范围分给某段spline，spline的端点并不会加这个约束，这个约束只加到anchor位置上。

$ \begin{gathered} t_knot=[ s_{1,0}]\\ sum=s_{1,0}\\ for\quad i \quad in \quad range(1,n):\\ \quad sum += (s_{i,1}-s_{i,0})\\ \quad t_knot .append(sum) \end{gathered} $

3 anchor heading约束

$ x_i^{'}(s)=[a_{i,0},a_{i,1},a_{i,2},a_{i,3},a_{i,4},a_{i,5}] \begin{bmatrix} 0 \\ 1 \\ 2s\\ 3s^2\\ 4s^3\\ 5s^4 \end{bmatrix} = a_iS^{'T} $

$ y_i^{'}(s)=[b_{i,0},b_{i,1},b_{i,2},b_{i,3},b_{i,4},b_{i,5}] \begin{bmatrix} 0 \\ 1 \\ 2s\\ 3s^2\\ 4s^3\\ 5s^4 \end{bmatrix} = b_iS^{'T} $

$ heading=arctan(\frac{dy}{dx}) $

要求优化后的heading方向与anchor heading一致(硬约束==0)

$ \arctan(\frac{y'_i(anchor_t[?]-t_knot[which])}{x'_i(anchor_t[?]-t_knot[which])}) = heading $

$ y'_i(anchor_t[?]-t_knot[which]) - tan(heading)x'_i(anchor_t[?]-t_knot[which])=0 $

$ [b_iS'^T - tan(heading)a_iS'^T]|_{s=anchor_t[?]-t_knot[which]}= 0 $

$ [- sin(heading )a_iS'^T + cos(heading)b_iS'^T]|_{s=anchor_t[?]-t_knot[which]}= 0 $

以上为代码中的等式约束，不能保证优化后heading与原heading一致，还有可能相差pi。因此再添加以下同向不等式约束。

优化后一阶导方向 点乘 anchor heading >= 0则为同向。

但代码中为 约束优化后heading与anchor heading所处象限的45度角方向的点积大于0，由于如果优化后导数与anchor heading同向则两角度是完全相等的，heading与anchor heading所处象限的45度角方向的角度差不会大于45度，heading与anchor heading所处象限的45度角方向点积后的正负与heading与anchor heading点积后的正负是一致的。而如果heading与anchor heading相差180度，则优化后一阶导方向 点乘 anchor heading的正负和优化后一阶导方向 点乘 anchor heading所处象限的45度角方向的正负是一致的。所以用anchor heading所处象限的45度角方向代替anchor heading与优化后一阶导方向点积。

如果正则化heading在[0, pi/2]: sign = [1, 1]

如果正则化heading在[pi/2, pi]: sign = [-1, 1]

如果正则化heading在[pi,3*pi/2]: sign = [-1, -1]

如果正则化heading在[3pi/2, 2pi]: sign = [1, -1]

只需要最后的内积 $ sign\cdot (a_iS'^T,b_iS'^T) \geq 0 $表明方向一致。

我想要施加heading的不等式约束将 优化后heading约束在$ [heading-yaw_eps,heading+yaw_eps] $区间内，要求$ [heading-yaw_eps,heading+yaw_eps] $处于[-pi/2,pi/2]内即处于tan的同一个周期内(才能保证tan后结果保持单调增)。由于此原因不能直接对yaw做范围约束，因此尝试在提供的yaw_ref附近对yaw(s)计算进行线性化。

参考线的坐标系为以第一个raw point为原点的坐标系下，方向与地图坐标系一致没有做旋转，则保证了从地图坐标系下拿到的yaw和曲率与优化变量所在坐标系是一致的可以直接使用。

$ yaw_i(s) = arctan(\frac{y_i'(s)}{x_i'(s)}) $，yaw角计算非线性，如果tan后会产生上述的非同周期问题，导致计算后不等式不再成立。假设优化前后的$ dyaw $为小量尝试在提供的raw point附近对yaw计算进行线性化，已知一raw point$ (x_{ref},y_{ref},yaw_{ref},kappa_{ref}) $，在此点处对yaw计算一阶泰勒展开。

$ \frac{dyaw_i(s) }{dx_i(s)}=\frac{x_i'(s)y_i''(s)-y_i'(s)x_i''(s)}{x_i'(s)(x_i'^2(s)+y_i'^2(s))} $因为hdmap没有提供x,y的高阶导数而是yaw、kappa信息所以进一步处理得到

$ \frac{dyaw_i(s) }{dx_i(s)}=\frac{\sqrt{x_i'^2(s)+y_i'^2(s)}kappa_i(s)}{x_i'(s)}=\frac{kappa(s)}{cos(yaw_i(s))} $

同理得到

$ \frac{dyaw_i(s) }{dy_i(s)}=\frac{\sqrt{x_i'^2(s)+y_i'^2(s)}kappa_i(s)}{y_i'(s)}=\frac{kappa(s)}{sin(yaw_i(s))} $

在$ (x_{ref},y_{ref},yaw_{ref},kappa_{ref}) $处展开

$ \begin{gathered} yaw_i(s) \approx yaw_{ref} + \frac{dyaw_i(s) }{dx_i(s)}|_{(x_{ref},y_{ref},yaw_{ref},kappa_{ref} }(x_i(s)-x_{ref})+ \frac{dyaw_i(s) }{dy_i(s)}|_{(x_{ref},y_{ref},yaw_{ref},kappa_{ref} }(y_i(s)-y_{ref})\\=yaw_{ref} +\frac{kappa_{ref}(x_i(s)-x_{ref})}{cos(yaw_{ref})} + \frac{kappa_{ref}(y_i(s)-y_{ref})}{sin(yaw_{ref})} \end{gathered} $

由于x、y实际并非以s为参数，而是以t为参数，s与t存在缩放关系$ t=\frac{t_{max}-t_{min}}{s_{max}-s_{min}}(s-s_{min}) $,$ ds=\frac{s_{max}-s_{min}}{t_{max}-t_{min}}dt $，每一点的$ \sqrt{(x'^2+y'^2)} $为常数

$ ds=\sqrt{dx^2+dy^2}=\sqrt{(x'^2+y'^2)}dt $(从根号内提出一dt)

$ \frac{dyaw_i }{dt}=\frac{x_i'(t)y_i''(t)-y_i'(t)x_i''(t)}{x_i'^2(t)+y_i'^2(t)} $

$ \frac{dyaw_i }{ds}=\frac{dyaw_i/dt}{ds/dt}=\frac{x_i'(t)y_i''(t)-y_i'(t)x_i''(t)}{(x_i'^2(t)+y_i'^2(t))^{3/2}}=kappa_i $

得到近似线性的yaw计算公式。同理kappa也可在参考点处展开，但是目前高精地图未直接提供三阶导相关信息，同时地图中的原始lane的曲率有非常多不合理的地方，参考意义不大，因此并未基于原始曲率做进一步约束

$ \frac{dkappa }{ds}=\frac{(y'''x'-x'''y')(x'^2+y'^2)-3(x'x''+y'y'')(y''x'-x''y')}{(x'^2+y'^2)^3} $,xy是对t求导$ ds=\sqrt{dx^2+dy^2}=\sqrt{(x'^2+y'^2)}dt $(从根号内提出一dt)

$ \frac{dkappa }{dt}=\frac{(y'''x'-x'''y')(x'^2+y'^2)-3(x'x''+y'y'')(y''x'-x''y')}{(x'^2+y'^2)^{\frac{5}{2}}} $

$ \frac{dkappa }{dx}=\frac{(y'''x'-x'''y')(x'^2+y'^2)-3(x'x''+y'y'')(y''x'-x''y')}{cos(yaw)(x'^2+y'^2)^3} $

$ \frac{dkappa }{dy}=\frac{(y'''x'-x'''y')(x'^2+y'^2)-3(x'x''+y'y'')(y''x'-x''y')}{sin(yaw)(x'^2+y'^2)^3} $

推导minimize jerk的泛函为5次多项式，但做约束时在连接点处也最多只约束到3阶连续(每一点的3阶导不突变)。那么对于离散点的优化来说，确保两个点之间的三阶导为线性变化的(那么可认为 两点间曲线的三阶导连续)，然后去约束四阶导的大小即可。

背景#

Appollo smoother方法对比[1]

平滑150m的路线，**max_constraint_interval(最大锚点采样距离)**设置为5m

耗时: discrete_smoother**(小于1ms) < qp_spline_smoother(40-60ms)** <= spiral_spline**(100-200ms)**

平滑度: qp_spline_smoother == spiral_smoother >= discrete_smoother

  • qp_spline_smoother方法对于引导线切向突变大的工况时平滑效果稍差，需要大幅减小anchor_point之间的距离间隔以及spline长度，以此来达到优化后的轨迹贴合原始轨迹;算法耗时适中;平滑度高;贴和原始轨迹能力偏弱。
  • spiral_smoother方法贴合原始轨迹能力稍好于qp_spline_smoother;平滑度高;算法耗时受max_constraint_interval影响较大，上面的例子中若将max_constraint_interval设置为2m则耗时增加至秒级。
  • discrete_smoother，在相同max_constraint_interval的条件下femf方法的优化变量数量少、同时因为松弛因子存在的缘故曲率约束并硬约束所以耗时较少;轨迹平滑度、曲率连续性差，但可通过缩小max_constraint_interval来接近"曲率连续";不受首尾点曲率、航向约束;方法简单。

目前使用的平滑器为qp_spline_smoother。但是qp_spline_smoother并没有提供曲率约束的方法，在refactor-2.0中使用RPLanePkg形式将地图中的Lane组合或分割作为参考线平滑单位，则车辆跟踪的参考线为smooth后的Pkg拼接而成的参考线，这就要求smoother提供始末点heading和曲率约束的方法保证拼接处的heading和曲率连续。(曲率不连续对于类似em planner的曲率敏感规划器影响较大)。

discrete_smoother即fem方法，其约束只到二阶导(曲率约束，二阶导还是3个三点近似计算出来的，剩下的约束只有dx,dy(近似一阶导)范围的约束) 因此结果的三阶导可突变。fem cost中的平滑项为三点近似计算出的曲率半径相关量，平滑项中并没有三阶(dkappa相关)阶导项，而qp_spline_smoother和spiral_smoother的平滑项中都考虑了三阶导项，所以fem的平滑程度相较于另两个方法较差。

期望以较快的速度完成平滑优化，一样使用离散点形式作为优化变量形式，同时想要结果尽可能平滑，需要优化三阶量。考虑到平滑器的作用为在已有粗解的前提下对粗解进行优化，大部分平滑场景下不需要很大的解空间对可行解进行搜索，因此考虑在s,l下平滑参考线，将anchor_point转到(s,l)下进行平滑。

(1) 优化变量少，优化变量只有l’’’，而xy优化需要x’’’,y’‘‘优化变量多一倍。(但解空间较xy小很多)

(2) 优化结果s,l对应的match point就是被优化的anchor point，将结果(s,l)->(x,y)的准确性可以保证

(3) 可作为path optimizer组件，将静态障碍物约束转为l的约束

  if (!sliced || num == 0) {
    return;
  }
  const T delta = (end - start) / num;
  sliced->resize(num + 1);
  T s = start;
  for (uint32_t i = 0; i < num; ++i, s += delta) {
    sliced->at(i) = s;

曲线简化

道格拉斯降采样

用于将线段组成的曲线降采样为点数较少的类似曲线，根据原曲线与简化曲线之间的最大距离来定义相似程度。用于选择合适的anchor point，在直道时时采样点较少，在弯道时采样较多点(提升投影精度)。

1）对曲线的首末点虚连一条直线，求曲线上所有点与直线的距离，并找出最大距离值dmax，用dmax与事先给定的阈值D相比：

2）若dmax<D，则将这条曲线上的中间点全部舍去；则该直线段作为曲线的近似，该段曲线处理完毕。

3）若dmax≥D，保留dmax对应的坐标点，并以该点为界，把曲线分为两部分，对这两部分重复使用该方法，即重复1），2）步，直到所有dmax均<D，即完成对曲线的抽稀。

显然，本算法的抽稀精度也与阈值相关，阈值越大，简化程度越大，点减少的越多，反之，化简程度越低，点保留的越多，形状也越趋于原曲线。

Douglas-Peuker算法(DP算法)过程如下:

  • 1、连接曲线首尾两点A、B；
  • 2、依次计算曲线上所有点到A、B两点所在曲线的距离；
  • 3、计算最大距离D，如果D小于阈值threshold,则去掉曲线上出A、B外的所有点；如果D大于阈值threshold,则把曲线以最大距离分割成两段；
  • 4、对所有曲线分段重复1-3步骤，知道所有D均小于阈值。即完成抽稀。

function DouglasPeucker(PointList[], epsilon)

** // Find the point with the maximum distance**

** dmax = 0**

** index = 0**

** end = length(PointList)**

** for i = 2 to (end - 1) {**

** d = perpendicularDistance(PointList[i], Line(PointList[1], PointList[end]))**

** if (d > dmax) {**

** index = i**

** dmax = d**

** }**

** }**

** ResultList[] = empty;**

** // If max distance is greater than epsilon, recursively simplify**

** if (dmax > epsilon) {**

** // Recursive call**

** recResults1[] = DouglasPeucker(PointList[1…index], epsilon)**

** recResults2[] = DouglasPeucker(PointList[index…end], epsilon)**

** // Build the result list**

** ResultList[] = {recResults1[1…length(recResults1) - 1], recResults2[1…length(recResults2)]}**

** } else {**

** ResultList[] = {PointList[1], PointList[end]}**

** }**

** // Return the result**

** return ResultList[]**

end

这种算法的抽稀精度与阈值有很大关系，阈值越大，简化程度越大，点减少的越多；反之简化程度越低，点保留的越多，形状也越趋于原曲线。

//计算点到直线的距离
double pointToLineDistance(Point2D p, Point2D start, Point2D end) {
    double a = end.y - start.y;
    double b = start.x - end.x;
    double c = end.x * start.y - start.x * end.y;
    return abs(a * p.x + b * p.y + c) / sqrt(a * a + b * b);
}

void DouglasPeucker(const std::vector<Point2D>& points, double epsilon_square, std::vector<Point2D>* result) {
    if (points.size() == 2) {
        result->push_back(points[0]);
        result->push_back(points[1]);
        return;
    }
    else if(points.size() < 2)
      return;

    double max_dist = 0;
    size_t max_index = 0;
    for (size_t i = 1; i + 1 < points.size(); i++) {
        double dist = pointToLineDistance(points[i],points[0], points.back());
        if (dist > max_dist) {
            max_dist = dist;
            max_index = i;
        }
    }

    if (max_dist > epsilon_square) {
        std::vector<Point2D> left(points.begin(), points.begin() + max_index + 1);
        std::vector<Point2D> right(points.begin() + max_index, points.end());
        DouglasPeucker(left, epsilon_square, result);
        result->pop_back(); // 当前点max_index下面对右边的递归也会添加，这里pop去重
        DouglasPeucker(right, epsilon_square, result);
    }
    else {
        result->push_back(points[0]);
        result->push_back(points.back());
    }
}

void DouglasPeucker(const std::vector<Point2D>& points, double epsilon_square,size_t start_index,size_t end_index, std::vector<size_t>* result) {
    if (end_index == start_index + 1) {
        result->push_back(start_index);
        result->push_back(end_index);
        return;
    }
    else if(end_index < start_index + 1)
      return;

    double max_dist = 0;
    size_t max_index = start_index;
    for (size_t i = start_index + 1; i < end_index; ++i) {
        double dist = pointToLineDistance(points[i],points[start_index], points[end_index]);
        if (dist > max_dist) {
            max_dist = dist;
            max_index = i;
        }
    }

    if (max_dist > epsilon_square) {
        DouglasPeucker(points, epsilon_square,start_index,max_index, result);
        result->pop_back(); // 当前点max_index下面对右边的递归也会添加，这里pop去重
        DouglasPeucker(points, epsilon_square,max_index,end_index, result);
    }
    else {
        result->push_back(start_index);
        result->push_back(end_index);
    }
}

// 非递归版
void DouglasPeucker(const std::vector<Point2D>& points, double epsilon_square, std::vector<size_t>* result) {
    if(points.size() < 2) return;
    size_t start_index = 0,end_index = points.size() - 1;
    std::stack<std::pair<size_t, size_t>> segments;
    std::stack<size_t> res;
    res.emplace(points.size() - 1);
    segments.emplace(start_index,end_index);
    while(!segments.empty())
    {
        start_index = segments.top().first;
        end_index = segments.top().second;
        segments.pop();
        if (end_index == start_index + 1) {
            res.emplace(start_index);
            continue;
        }
        else if(end_index < start_index + 1)
            continue;

        double max_dist = 0;
        size_t max_index = start_index;
        for(size_t i = start_index + 1;i < end_index;++i)
        {
            double dist = pointToLineDistance(points[i],points[start_index], points[end_index]);
            if (dist > max_dist) {
                max_dist = dist;
                max_index = i;
            }
        }

        if (max_dist > epsilon_square) {
            // res->emplace(start_index);
            segments.emplace(start_index,max_index);
            segments.emplace(max_index,end_index);
        }
        else {
            res.emplace(start_index);
        }

    }

    while(!res.empty())
    {
        result->emplace_back(res.top());
        res.pop();
    }
}

未顾及支撑域的度量方法

角度度量法

$ \alpha(i)=\angle P_iP_{i-1}P_{i+1} (1\leq i\leq n-1) $

角度越大重要性越大，则保留。(b)中Pj的角度大于Pi但是删除Pi对曲线的影响更大

面积度量

$ A(i)=S_{\bigtriangleup } P_iP_{i-1}P_{i+1} (1\leq i\leq n-1) $

面积越大，重要性越高。但容易受变化平缓的长条三角形的影响，如(b)中的S1=S2但是删除S1对曲线的影响更大

顾及支撑域的度量方法

垂比弦度量

对于$ P_i $的重要性可由该点到其临近点$ P_{i-k} $,$ P_{i+k} $所成弦的垂直距离$ D_{i,k} $与弦长$ C_{i,k} $的比值来度量。

$ DC(i)=D_{i,k}/C_{i,k}(1\leq i \leq n-1) $

与角度度量类似，易受尖点噪声影响(我们的场景中不存在噪声)。k的取值从1开始直到$ D_{i,k}/C_{i,k}\geq D_{i,k+1}/C_{i,k+1} $

弧比弦度量

支撑域半径$ R=L_0/(V+1) $,其中$ L_0 $为曲线总长，$ V $为曲线总点数-1。$ L_i $为在支撑域范围内的弧线长度，$ C_i $为弧对应的弦长。

$ LC(i)=L_i/C_i(1\leq i \leq n-1) $
