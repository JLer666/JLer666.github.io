下面重新描述一下我们的任务，我们的前端轨迹是简单的由较少的必经点之间直线组成的前端路径(JPS)。 计算每两个必经点之间的轨迹，轨迹用参数化的5阶多项式表达，优化多项式参数使，1总体的轨迹(将分段轨迹全部相连后的轨迹)满足首末姿态约束，2并且轨迹一定经过我们规定的必经点，3并且轨迹上的必经点位置的左右极限，以及必经点位置的高阶导数的左右极限都相等(必经点状态光滑)，4同时最小化整体轨迹的snap。 总的轨迹多项式，是分段轨迹多项式的组合。 每段时间区间内的子轨迹多项式组成总的轨迹多项式 我们不需要保证每段多项式的系数一致，但是如果能保持一致那是最好的可以让问题更简单。 每段轨迹的运行时间是已知固定的。(不像前面的OBVP问题，可以求最佳运行时间T*) 下面讲下对于轨迹的约束： 红框中写的有问题，红框中的约束其实就是初态终态约束。 f0(k)(T0) = x(k)(T0) 第一段多项式的T0起始时刻状态的0k阶导数，要和我们规定的初态的0k阶导数全部相等 fN(k)(TM) = x(k)(TM) 最后一段多项式的TM终止时刻状态的0k阶导数，要和我们规定的末态的0k阶导数全部相等 蓝框中的约束，是对连接两段轨迹的必经点的状态约束。 fj(k)(Tj) = fj+1(k)(Tj) 第j段多项式的Tj终止时刻状态的0k阶导数，要和其连接的下一段(j+1段)多项式的Tj起始时刻状态的0k阶导数 全部相等。 保证多项式在这个必经点的0-k阶导数全部连续(此点k阶连续–k-1阶光滑) 这里再强调一下光滑!=连续，k阶光滑=k+1阶连续(k阶再求一次导数) 确保轨迹在某个阶数上光滑 确保轨迹在某个阶数上连续 最小化轨迹的某一阶导数(最小化snap) 这三个要求是彼此独立的互不相关的。 工程上 如果我们要 最小化一段轨迹的jerk,要求轨迹是 2*3(jerk)-1=5 是时间的5次多项式 使轨迹上每点的 p,v,a连续 当然如果你想jerk也连续，那也完全没问题 要最小化一段轨迹的snap,要求轨迹是 2*4(sanp)-1=7 是时间的7次多项式 使轨迹上每点的 p,v,a,j连续 当然如果你想snap也连续，那也完全没问题 我们现在是将轨迹分段了，所以如果总轨迹由k段轨迹组成 要minimum jerk: 必经点约束就有 3(初态p0,v0,a0约束) + 3(末态pf,vf,af约束) + k-1(k段轨迹共k-1个中间必经点 位置约束) = k+5 个约束 假设每段轨迹的阶数是N,N阶轨迹的参数是N+1个(比如5次多项式的参数是a5~a0是6个)，总共有k段轨迹，那么总的未知数量为 (N+1)*k 我们只有k+5个约束最多只能解出k+5个未知量，所以如果我们要将轨迹完全求解要求 自由度>=变量数 (N+1)*k >= k + 5 得N >= 5/k ...
