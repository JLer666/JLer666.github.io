基于密度的去噪空间聚类 +层次聚类

从最简单的kmeans(基于中心的聚类)开始，需要预先提供需要将期望的聚类数量k

1 随机选择k个数据作为类簇中心–随机是个不好的策略，初始点和最终结果关系非常大，可用更好的策略如kmeans++

2 计算剩余数据与这k个数据的距离(对称、凸)，分配到与其最近的类簇中

3 更新k个簇的新中心，可以计算簇内数据的质心或者$ x_i $为新中心，要求中心到簇内其他数据的距离之和是簇内最小的(即簇内其他数据到others的总误差平方和SSE都大于此中心，在聚类中SSE也被叫做CSS cluster sum of squarez或者Inertia)，kmeans的本质是求解让整个数据集Inertia最小化的k个质心

$ \begin{gathered} SSE_i=\sum_{\mu_j\in c_i}||d(x_i,\mu_j)||^2\\ \min_{x_i}SSE_i\\ SSE=\sum_{i=1}^kSSE_i \end{gathered} $

4 计算新中心和原中心的eps，如果小于一值认为收敛。否则回到2

期望SSE小，理论上k越小SSE越小当k==n(总数据量)，SSE=0但k==n没有聚类意义不是我们希望的。基于经验k_{max}<=sqrt(n)，期望找到一k*当k大于此值时SSE的下降斜率明显变小(d2SSE/dk2==0 二阶导极值 拐点)

不过遗憾的是，若SSE的下降是均匀的，传统的肘部图法也就失灵

除了肘部图，常用的还有轮廓系数法(Silhouette coffient)，某个样本的轮廓系数计算方法如下

$ S=\frac{b-a}{\max(a,b)},-1\leq S \leq 1 $

a为此样本到同簇样本的平均距离(簇内相似度)，b为样本到 除所属簇外最近的簇中心 对应的 簇内所有样本的平均距离(簇间相似度)

数据点与自己所属的簇内的其他数据点的距离很小，但是与其他簇中的数据点的距离很大(a小b大)，就表示这个数据点所在的簇内紧密度高，簇间分离度大,聚类效果好，那么该数据点的轮廓系数就会越大

计算轮廓分数： 所有样本点的轮廓系数的平均值#

silhouette_score(x, y_pred)

计算所有样本点的轮廓系数#

silhouette_samples(x, y_pred)

簇结构非凸的情况，轮廓系数失真

Calinski-Harabasz指数

类似是簇间距离和簇内距离的比值又名方差比准则，计算所有簇的簇内距离和的均值，再计算总样本中心，各簇中心与样本中心的距离和作为簇间距离和

def get_calinski_harabasz(X, labels):
     n_samples = X.shape[0]
     n_clusters = np.unique(labels).shape[0]
     betw_disp = 0.  # 所有的簇间距离和
     within_disp = 0.  # 所有的簇内距离和
     global_centroid = np.mean(X, axis=0)  # 全局簇中心
     for k in range(n_clusters):  # 遍历每一个簇
         x_in_cluster = X[labels == k]  # 取当前簇中的所有样本
         centroid = np.mean(x_in_cluster, axis=0)  # 计算当前簇的簇中心
         within_disp += np.sum((x_in_cluster - centroid) ** 2)
         betw_disp += len(x_in_cluster) * np.sum((centroid - global_centroid) ** 2)

     return (1. if within_disp == 0. else
             betw_disp * (n_samples - n_clusters) /
             (within_disp * (n_clusters - 1.)))

CH越大代表着类自身越紧密，类与类之间越分散，即更优的聚类结果。类别内部数据的协方差越小越好，类别之间的协方差越大越好。当聚类数目k的值较大时，CH指数可能失去意义，因为此时类内距离可能变得很小，导致CH值偏大，凸簇的分数会更高，不太适合基于密度的聚类算法

Davies-Bouldin Index(戴维森堡丁指数)

任意两类别的类内距离平均距离(CP)之和除以两聚类中心距离 取最大值。DB越小意味着类内距离越小同时类间距离越大。(越小越好)。

 1 def get_davies_bouldin(X, labels):
 2     n_clusters = np.unique(labels).shape[0]
 3     centroids = np.zeros((n_clusters, len(X[0])), dtype=float)
 4     s_i = np.zeros(n_clusters)
 5     for k in range(n_clusters):  # 遍历每一个簇
 6         x_in_cluster = X[labels == k]  # 取当前簇中的所有样本
 7         centroids[k] = np.mean(x_in_cluster, axis=0)  # 计算当前簇的簇中心
 8         s_i[k] = pairwise_distances(x_in_cluster, [centroids[k]]).mean()  #
 9     centroid_distances = pairwise_distances(centroids)  # [K,K]
10     combined_s_i_j = s_i[:, None] + s_i  # [K,k]
11     centroid_distances[centroid_distances == 0] = np.inf
12     scores = np.max(combined_s_i_j / centroid_distances, axis=1)
13     return np.mean(scores)

簇与簇之间的相似度越高（DB指数偏高），也就说明簇与簇之间的距离越小（直观上理解只有相距越近的事物才会约相似），那么此时聚类结果就越差。该指标的缺点是因使用欧式距离所以对于环状分布聚类评测很差

kmeans对初始聚类中心的位置十分敏感，每次迭代，初始点的不同往往会导致不同的聚类结果。常见的优化方法是采用最大距离法，如：首先选取数据集中距离最大的两个点作为初始聚类中心，将剩余数据对象依据到聚类中心点距离的远近分配到相应的簇中，并更新聚类中心，然后继续寻找与聚类中心距离最远的点作为下一个中心点.keans++，同样是基于最大距离，这合加权概率的思想优化了对K个初始中心的选取，使得在选取第n+1个聚类中心时，距离当前n个聚类中心越远的点会有更高的概率被选为第n+1个聚类中心，即初始中心尽可能差异越大越好

根据距离的度量方式容易发现，K-Means所划分出的类别是类球形的，换句话说，只有类球型分布的连续型样本数据，才能得到较好的聚类效果，而如果非数值型、样本类别极不平衡、非球形的分类，则聚类效果会受限

同时kmeans对噪声敏感，聚类前需要去噪

二分kmeans法，将所有点作为一个簇，将该簇一分为二，然后选择能最大程度降低聚类代价函数的簇划分为两个簇，以此进行下去，直到簇的数目等于给定的个数K为止。值得一提的是，该法更突出的优点在于能够很好地解决K-Means收敛到局部最优的问题，帮助我们找到全局最优解

K-Means中，K个初始点设置后，各个簇的大致范围其实也就落定了，无论更新多少次，中心点的位置也不会有过大的变化，也因此我们只是不断在调整当前类簇的大小（或者说形状），然后找到这K个类簇取得最小SSE时的聚类结果，这也就是我们所找到的局部最优。然而K相同的情况下，更换初始点，有可能会得到更小的SSE，而继续换，可能会继续获得更小的SSE，直到再也没有更小的情况出现，此时才是真正的全局最优解

DBSCAN(基于密度的聚类)

类簇可以是任意形状，簇被定义为密度相连点的最大集合，算法中将点分为3类

核心点 样本在指定的eps邻域内含至少(>=)min_samples个点，则此点作为核心点。

边界点 样本在eps邻域内样本数<min_samples个点，但它在其他核心点的邻域内，则被称作边界点

噪声 既不是核心点也不是边界点

直接密度可达 核心点到其(->)eps邻域内的其他点都是直接密度可达,无相互性 只能是核心点->边界点

密度可达(Reachability) 可传导无相互性，a->b->c若每个(->)都是直接密度可达，则a–>c被称为密度可达

p1,p2,p3,…,pn，若其中任意连接p_{j+1}->p_{i}都是直接可达则说明这条路径上除pn外所有点都是核心点，pn(可能不是)，可以说从p1-p_{n-2}和pn的关系都是密度可达的

cluster由关键点作为种子扩展而成，cluster内从种子到其他任意节点一定可达(直接可达)。每个cluster至少有一个关键点，cluster的边界由边界点构成(这也就是边界点名字的来源)，除边界点外内部点一定全部都为核心点，这些边界点无法再到达cluster外的点。

图结构。定义密度连通概念，如过祖先节点o经过不同path到达p，q两点称，q和p间为密度连通，密度连通的概念是对称的q和p–p和q密度连通。

一个cluster有以下两个特点:

cluster中任意两点都是相互密度连通(这肯定，因为都是由同一seed扩展得到的)

如果有一点和cluster中的某点密度可达，则此点一定是此cluster的一部分

Hierarchical clustering层次聚类(基于连接的聚类)

分为两种 Agglomerative(自下而上的合并)，初始每个点都是单独一类随着层级向上逐层合并。 Divisive(自上而下的分裂)，初始所有点属于同一类随着层级向下分裂

Agglomerative 时间O(n^3)基于堆降为n^2logn 空间O(n^2) 在SLINK(single linkage)和CLINK(complete linkage)下时间降为O(n^2)

Divisive 时间O(2^n)几乎算不完，一般需要好的启发项比如先kmean算一次再在子类中进行分割

在判断哪个cluster需要合并或split哪部分时需要评估两个集合的dissimilarity 。一般是用两个set中单个观测数据之间的距离以及linkage标准来评估，dist mertric以及linkage决定。dist决定最相似的物体，linkage标准影响cluster形状，比如完全链接相较于单链接倾向于产生更多的球形簇。

所谓的linkage标准可以理解为在已知两两点间距离后，评价相似度所用的函数，具几个简单的linkage标准

A,B为待评估的两样本集合，a,b为集合中的样本

maximum or complete linkage 聚类 $ \max_{a\in A,b\in B}d(a,b) $

minimum or single linkage 聚类 $ \min_{a\in A,b\in B}d(a,b) $

Unweighted average linkage(UPGMA) 聚类 $ \frac{1}{sizeof(A)sizeof(B)}\sum_{a\in A}\sum_{b\in B}d(a,b) $

上面的都是n^2

weighted average linkage(WPGMA) 聚类 $ d(i\cup j,k) = \frac{d(i,k)+d(j,k)}{2} $

Agglomerative clustering流程–下面是简化流程，具体流程可以看上面WPGMA的例子

有NxN的样本距离矩阵D，L(i)表示第i团(第i个节点)的高度，自下而上过程中的每一个cluster(包括子cluster或合并后的cluster)都有唯一编号m(及树上的每个节点都有唯一id),(r)簇和(s)簇的相似度描述为d[(r),(s)]

1 初始化所有样本是单独一个culster其高度L(.)=0，初始化节点编号m不断递增

2 根据指定的linkage规则找到相似度最高的两个cluster，(r)、(s)。合并(r)、(s)形成一个新节点(m+=1)，设置节点高度L(m)= d[(r),(s)]–即就是簇的相似度，同时也保存我们一般意义的其所在树的高度，记录簇merge的总次数

3 更新相似度矩阵D，因为(r),(s)簇合并所以需要将(r),(s)簇从D中删除，并在其中新增一行和列表示(rs)合并簇，同时按定义的linkage规则计算(r,s)簇和其他簇的相似度–每次都要重新算O(n)

5 如果所有样本都在某一簇中则自下而上过程结束否则回到2

Divisive clustering DIANA (DIvisive ANAlysis clustering)

初始所有样本在同一类中，每次会split目前的样本数最多的cluster直到每个样本单独为一cluster(叶子节点，绝大多数不会这么极端)，时间复杂度为O(2^n)所以需要启发项，DIANA选择最大平均相异度作为启发。

通俗地说，DIANA 与其说是一个split的过程，不如说是一个“掏空”的过程：每次迭代，都会选择一个现有的簇（例如整个数据集的初始簇）来在其中形成一个新的簇。对象逐渐移动到这个嵌套簇，并挖空现有簇。记$ \delta(i,j) $表示样本i和j的相异度

1 标记C0={1,…,n所有样本}，C={C0}簇树

2 迭代直到C的叶子节点数==n

(1) 找到目前已分类簇内 样本pair间距最大的簇(簇内间距最大的簇)$ C_*=\arg\max_{c\in C}\max_{i_1,i_2\in c}\delta(i_1,i_2) $

(2) 找到簇内样本间距最大的属于C*簇的样本 $ i*=\arg\max_{i\in C_*}\frac{1}{sizeof(C_*)-1}\sum_{j\in \{C_* -i\}}\delta(i,j) $

(3) 将i从C中删除并加入一新cluster $ C_{new}=\{i^*\} $

(4) 只要C非空，不断从C中取样本加入到Cnew中，在挑选样本时除了与C*相异度外，同时计算了其与Cnew的相异度

$ i^*=\arg\max_{i\in C^*}D(i),D(i)=\frac{1}{sizeof(C^*)-1}\sum_{j\in\{C^*-i\}}\delta(i,j)-\frac{1}{sizeof(C_{new})}\sum_{j\in C_{new}}\delta(i,j) $

选择与C相异度较大与Cnew相异度较小的样本(样本移出C的动力)，迭代到D(i*)<0停止迭代

Cnew作为C*子节点

(5) 将C*加入C中

最大团问题视为一个子集选取问题{0/1,0/1,…}n个节点集合0代表不选1代表选，共2^n中子集

在其中挑选满足约束条件(完全子图，集合内节点全连接)，同时有一目标函数(团内节点最多)挑选最有团

限界函数(剪枝条件):在不考虑团的约束下，将余下节点全视为团节点，此团节点数依旧小于当前记录的最大团节点数量，则可提前退出

用子集树结构的搜索算法来解这个问题，

树上的每个节点 含 此节点对应于图内的某个节点，节点的左子树表示将此父节点加入团中后的搜索过程， 右子树表示不将此节点加入团中。

是否存在左子树由团条件约束，需要从此节点回溯路径上的所有属于其父的左节点的节点，检查此节点与路径上节点是否全都连通，若连通则满足条件，存在左子树。否则只有右子树

		for(int j = 0; j < an; ++j)
			all[d+1][j] = all[d][j];
		all[d+1][an] = v;
		int tsn = 0, tnn = 0;
		for(int j = 0; j < sn; ++j)  if(mp[v][some[d][j]])  some[d+1][tsn++] = some[d][j];
		for(int j = 0; j < nn; ++j)  if(mp[v][none[d][j]])  none[d+1][tnn++] = none[d][j];
		dfs(d+1, an+1, tsn, tnn);
		some[d][i] = 0, none[d][nn++] = v;
		if(ans > 1000) return;    // 极大团数量超过1000就不再统计
	}
}

int work()
{
	ans = 0;
	for(int i = 0; i < n; ++i) some[1][i] = i+1;
	dfs(1, 0, n, 0);
	return ans;
}

void BK(ll r,ll p,ll x){
	if(!p&&!x){mx=max(mx,popcnt(r));return ;}
	int z=n+1,u=-1;
	ll st=p|x;
	for(int i=0;i<n;i++){
		if(!((st>>i)&1))continue;
		int w=popcnt(p&N[i]);
		if(w<z)z=w,u=i;
	}
	st=p&N[u];
	for(int i=0;i<n;i++){
		if(!((st>>i)&1))continue;
		BK(r|(1ll<<i),p^(p&N[i]),x^(x&N[i]));
		p^=(1ll<<i),x|=(1ll<<i);
	}
	return ;
}

# 寻找图中所有最大团，通过迭代方式实现（相比递归空间复杂度更低一些），输入是networktx的内部类graph。
def find_cliques(G):
    if len(G) == 0:
        return
    # 寻找节点u以及其的所有邻居节点的邻接表，这个是为了后续处理方便
    adj = {u: {v for v in G[u] if v != u} for u in G}
    Q = [None]      # 伪代码中的集合R
    subg = set(G)
    cand = set(G)   # 伪代码中的P集合
    # u是在G中，相邻节点最多的点。max是根据key寻找最大的结果返回，此处key通过匿名函数lambda定义，
    # u是参数，也就是遍历集合中的点，返回值是len(cand&adj[u])，就是与邻居集合与cand集合交集的大小。
    # 本句话的意思是：返回邻居集合与cand集合的交集最大的节点u。其实这目的就是选出一个结点，对应伪代码中的Line4
    u = max(subg, key=lambda u: len(cand & adj[u]))
    ext_u = cand - adj[u]    # 差集，对应伪代码Line5中的P \ N(u)
    stack = []
    try:   # 接下来是一个死循环，通过except抛出错误跳出这个循环
        while True:
            if ext_u:   # P \ N(u)，也就是还存在可以扩展的候选的点
                q = ext_u.pop()   # 弹出一个点进行最大团的搜索并入操作
                cand.remove(q)    # 要从cand（P）中移除这个点，相当于伪代码中的for循环了
                Q[-1] = q    # 将刚刚弹出的节点放入Q中，也就是为团新增节点了，对应R ⋃ {v}
                adj_q = adj[q]    # 找q所有的邻居
                subg_q = subg & adj_q   # 取交集，对应 P ⋂ N(v)
                # 也就是当subg_q为空的时候。
                if not subg_q:    # 也就是sub_q为空，这个sub_qduiying对应集合X
                    yield Q[:]    # 每次yield都返回一个Q的生成器，这个Q就是最大团啦
                else:
                    cand_q = cand & adj_q  # X ⋂ N(v)
                    if cand_q:
                        stack.append((subg, cand, ext_u))   # 入栈，相当于递归过程中的参数传递，只不过给用显示的堆栈存起来了
                        Q.append(None)
                        subg = subg_q   # 以下四步都相当于参数更新
                        cand = cand_q
                        u = max(subg, key=lambda u: len(cand & adj[u]))
                        ext_u = cand - adj[u]  # 更新完毕则执行下一个循环，相当于又执行了一次BronKerbosch函数
            else:   # 当前状况下不存在可拓展的点了
                Q.pop()   # 最大团出栈
                subg, cand, ext_u = stack.pop()    # 参数出栈
    # 这是一个索引错误，其报错源头在实际测试中是subg, cand, ext_u = stack.pop()
    # 也就是我堆栈中不存在任何参数了，这代表所有的回溯过程的结束
    except IndexError:
        pass

    def find_cliques_recursion(self,R, P, X):
        '''
        a Recursion version of finding all max cliques in graph
        '''
        # print(P)
        if len(self.G) == 0:
            return
        if not P and not X:
            self.Cliques.append(R)
            return
        '''
        Fundamental study: Enumerating all connected maximal common subgraphs in two graphs
        use max degree for node selection
        '''
        u = max(P|X, key=lambda u: len(P & self.adj[u]))
        for v in (P - self.adj[u]):
            self.find_cliques_recursion(R|set([v]), P&self.adj[v], X&self.adj[v])
            P = P - set([v])
            X.add(v)

如果你希望求解出的极大团之间不包含共同节点，这意味着你实际上是在寻找一组互不相交的极大团（即每个节点只能属于一个团）。这种问题通常被称为最大独立集问题（Maximum Independent Set, MIS），或者更具体地说是最大团覆盖问题（Maximum Clique Covering Problem），其中每个团内的节点互不相邻。

HDBSCAN

基于Soft Clustering思想，在DBSCAN中只要泛洪扩展到的节点标签都是一样的，但是对于cluster的edge node可能距离另一个cluster非常近，这样的标签分配导致edge节点和簇内中心节点的性质完全一致，不利于区分。软聚类的思想就是用于解决这种问题，每个节点不再会被分配到一个确定标签，而是被分配到一个可能性向量(vector of probabilities)，向量长度与目前被发现的簇数量相同。每个节点变为混合类型，噪声是被分到任意簇中概率都很低的节点。
