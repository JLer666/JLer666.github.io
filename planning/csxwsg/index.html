同时Minimum snap每段轨迹的运行周期T需要另外给定，T对这条轨迹是否能在动力学约束下完成跟踪有很大的影响。

在障碍物周围的可通行区域加bounding box硬约束，保证轨迹一定通过bounding box中的这段轨迹来连接。

一般的带约束的优化问题描述为下面的形式

min f(x) s.t. gi(x) = ci i = 1,..,n等式约束 hj(x) >= di j = 1,..,n不等式约束

上面写的等式约束以及不等式约束都是硬约束是一定要被满足的。

min f(x) +/\1g(x) +/\2h(x)

将等式约束和不等式约束改写，添加到待优化函数J中。这样g,h都算作软约束–以代价函数中的惩罚项形式存在，变为最小化loss function的形式。不是一定要满足的条件，变为了一种在优化时的倾向性

软约束中经常用Barrier function作为惩罚项的形式

当被约束的变量在约束范围内，Barrier function的值都很小，当不在约束范围内Barrier function迅速增大。注意Barrier function是连续可导的的函数

这种方法用的地图是八叉树地图(不再是最熟悉的栅格地图了)，

八叉树地图

将空间中的一个立方体可以分为8个小的立方体，如果立方体中没有障碍信息则这个节点没有子节点，有障碍信息则这个节点有8个子节点(即将这个1/8空间继续分割成8份)，一直递归地切分下去直到将分割到最小障碍立方体这一层。

第一步构造八叉树地图(上面这张二维地图 构造的是四叉树地图 每次将空间四等分)

第2步

通过前端path finding(A* 图搜索RRT* )在八叉树地图上找到从起点到终点的最短路径(最短可通行区域 可通行走廊)。

八叉树地图不再是栅格地图了,八叉树地图会比栅格地图稀疏很多 搜索会快很多，在进行A*时对于障碍物的判断 八叉树地图可以像栅格地图一样快，在计算g值时以 两个子区域的中心坐标的距离作为代价。

我们找到的最短可通行走廊，只占了八叉树地图中很少的一部分。

第三步 将找到的最短可通行走廊膨胀，得到地图中绝大多数可通行区域

如何膨胀，将每个蓝框的边界向x,y,z(对于三维来说 这张图是二维)方向延伸直到碰到障碍物。将膨胀后的框去重并只保留最大得到所有黄框。– 减少了地图上的节点，每个节点代表的体积已经是它所能表示的最大体积

第四步 在膨胀过后的可通行走廊生成优化后的分段轨迹多项式

优化轨迹的方法基本与minimum sanp一致，但是多了软约束项

代价函数 是轨迹的n阶导数后平方—写成二次型只有H阵部分 没有f(一阶)和0阶部分

多了不等式约束

一样是个标准QP问题

之前minimum sanp中用前段pathfinding找到的路径点，当做必经点约束等式硬约束。但是膨胀后的可通行走廊已经不是以点的形式存在了。

取而代之的是规划出的两段轨迹的交点(必经点)一定在两个boundingbox的重叠区域,这样一个不等式范围硬约束。

在地图膨胀时也可以不用矩形来作为可通行区域形状可以用其他多边形，但是一定要是凸的形状确保最后问题可以化为凸优化问题。(凸优化问题求法标准 凸优化问题的求解与初值无关，无论什么初值最后一定可以得到全局最优解参数)

下面具体讲约束

instant linear constraints

1 起点终点状态等式硬约束(Start, goal state constraint)

2 必经点的位置约束(Transition point constraint)

对必经点位置不做像之前一样的 等式约束一定要必须经过这些中间点。

必经点 == 两段轨迹的连接点

我们现在只要求必经点的位置在两个 可通行矩形的重叠区域

为了避障，将完整一段轨迹所有点的位置约束在一个凸图形中(我们例子中是矩形)，如何去施加这个约束。

最暴力的做法是，我们已知轨迹时间段T，我们将T离散为dt，以dt间隔取多项式位置点，对每个求出来的位置点(我们以二维为例子) (xi,yi)，做不等式约束 box_min_x<=xi<= box_max_x,box_min_y<=yi<= box_max_y。我们对区域内这段轨迹离散了n点，就有2n个不等式约束，注意哦 这只是一段轨迹，如果有m段轨迹，将会有2mn个不等式约束，约束数量太多了，求解极慢 非常难解。

论文的做法是将两段轨迹的连接点位置，限制在两段轨迹所属区域的重叠部分。至少能保证轨迹一定会经过重叠部分。

(但还是没法保证不在重叠区域的轨迹点一定在其对应的cube里，还是存在安全性不完备，用之后的 interval线性约束来解决)

3 连续性约束(Continuity constraint)

约束两段轨迹在其连接点位置的各阶导数相等

interval linear constraints

4 对轨迹的边界约束(Boundary constraint)

就是在上面说的对必经点的位置约束(Transition point constraint)的补充

为了避障，将完整一段轨迹所有点的位置约束在一个凸图形中(我们例子中是矩形)，如何去施加这个约束。

最暴力的做法是，我们已知轨迹时间段T，我们将T离散为dt，以dt间隔取多项式位置点，对每个求出来的位置点(我们以二维为例子) (xi,yi)，做不等式约束 box_min_x<=xi<= box_max_x,box_min_y<=yi<= box_max_y。我们对区域内这段轨迹离散了n点，就有2n个不等式约束，注意哦 这只是一段轨迹，如果有m段轨迹，将会有2mn个不等式约束，约束数量太多了，求解极慢 非常难解。

此约束是个后验的检查 检查轨迹是否超出边界，前面的Transition point constraint相当于是个启发式的条件。

5 动力学约束(Dynamic constraint–velocity constraints,Acceleration constraints)

限制速度，加速度(限制姿态)

这个约束一样也是不好加的，相当于是Boundary constraint的高阶导数版

一样需要将轨迹以dt离散成很多份，分别求这么多份每一份的v,a。再对每一个v,a做不等式约束。一样会导致约束的数量爆炸多

一样采取后验的迭代检查形式，来做这个约束。

corridor-based trajectory optimization的优点

首先是因为采用八叉树地图而非栅格地图，前端的path finding的速度会大大加快。以及后端的在少数个bounding box内的凸优化速度也非常快。

同时没有多点的必经点约束 只是连接点位置的范围约束(连接点不再限制在一个点而是限制在一个范围内 连接点这个范围内是可以自由移动的 经过优化连接点会自动移到最优的位置上) ，同时如果出现不合理的轨迹运行时间T的分配 连接点经过优化也会自动移动到T下的最优位置上，是bounding box这样一个范围更大的约束 提供给了优化更大的自由发挥空间。

corridor-based trajectory optimization的缺点

如何去施加两个麻烦的interval linear constraints

需要每次后验迭代检查 超出bounding box的离散dt区域点，

我们不做dt时间离散，而是直接计算轨迹在每个轴上的极值(多项式极值点好求)，检查极值点是否在bounding box内，对于不在box内的极值点施加额外的不等式约束(注意只检查极值点，只对极值点做约束)

多项式的极值点可以直接求得解析解的形式，我们对解析解形式的极值点做不等式约束

因为这次的轨迹检查不满足边界约束，所以需要重新求解问题，在重新求解时将极值点的不等式约束加上(对于这个不等式约束的范围不要刚好卡在bounding box的那个界限上，比如超过了yb，在下次加不等式约束是不要给<=yb,而是给<=yb-dy 比yb更小的数使这个约束更“紧”一些)

对于动力学约束也是同理 – 直接求轨迹v,a多项式的极值点解析形式，对极值点施加不等式约束

缺点就是需要迭代求解多次QP问题

下面讲一下如何快速求解多项式极值

对于多项式p(x)的极值点是dp(x)/dx= 0的点

对于0-4阶的dp(x)/dx= 0 直接有求根公式可以直接得阶，对于高阶的方程

可以用伴随矩阵的方法 对于多项式dp(x)/dx== x^n + an-1x^n-1 + …+a0=0构造这个的多项式的伴随矩阵

det(xI - A)=0的根就是dp(x)/dx=0的根，而det(xI - A)=0的根就是矩阵A的特征值。就将问题由求多项式极值变为求矩阵特征值。

Bezier Curve optimization(贝塞尔曲线优化)–很好用的一个曲线

minimum snap中没有施加动力学约束，将动力学约束全部交于T,并不断迭代检查修改T

我们常用的多项式叫做monomial多项式

使用Bernstein多项式代替普通的多项式

(n i)指的是Ci,n=Cn-i,n从n个选i的组合数 n!/(i!*(n-i)!)

Bernstein多项式的系数ci,j叫做控制点，是有具体的物理意义的

Bernstein多项式代表的函数也叫做贝塞尔曲线(Bezier Curve)

将贝塞尔曲线完全展开，可以得到得到和monomial多项式一样的形式，即贝塞尔曲线的多项式参数和monomial多项式的参数存在映射关系

p = M*c 对于6阶多项式而言，其M阵如下

pj = n!/(n-j)!sum_i(0,j)(-1)^(i+j)ci/i!(j-i)!

= 连乘_m(0,j-1)(n-m)sum_i(0,j)(-1)^(i+j)ci/i!(j-i)!

贝塞尔曲线的重要性质

Endpoint interpolation

ci,j叫做控制点 ， 一定起始于第一个控制点,一定终止于最后一个控制点(最低阶和最高阶次数对应系数为必经点)但是绝对不会通过任何其他的控制点。

下图是一个四阶的贝塞尔曲线

Convex hull

一段贝塞尔曲线一定被，其控制点形成的凸包所完全包围住

Hodograph

贝塞尔曲线 B(t),在求导之后B’(t)依旧为贝塞尔曲线，B’(t)的控制点ci’ = n*(ci+1-ci),n为B(t)阶数。即已知B(t)可通过上面这个规则很容易地得到其导数多项式

B’’(t) ci’’ = n*(n-1)*(ci+2-ci+1-(ci+1-ci))

即如果我们想要约束B(t)的导数，我们只需要对没求过导的B(t)的控制点做约束即可

如何好好地利用贝塞尔曲线的凸包(Convex hull)性质

在上面的corridor-based trajectory optimization中，一个难点就是如何将一段轨迹sh上的所有点给完全约束在一个bounding box(corridor)中。我们利用贝塞尔曲线的凸包性质就可以将问题转为 将贝塞尔曲线的几个控制点给约束在bounding box中(因为轨迹一定被凸包包围，所以如果控制点在box内则 所有轨迹点也一定在box内)

，约束的数量大大减少。贝塞尔曲线几阶就有几个控制点

1 起点终点–必经点状态约束

a(l,i,u,j)第j条轨迹的第u个轴的贝塞尔曲线求l阶导后的第i项系数 – 贝塞尔导数曲线的第i个必经点

**我们直接设置起点和终点的各阶状态在贝塞尔曲线中的控制点系数，**贝塞尔曲线是一定经过第一个和最后一个控制点的

第0条贝塞尔轨迹的第0个控制点 第u轴的0-l阶导数 设置成初始状态

a(l,0-第0项系数即第一个控制点,u,0) * s0(第0条轨迹的放缩系数) = d(l,u,0)规定的u轴初始状态的各阶导数

第m条贝塞尔轨迹的第n个控制点(n阶贝塞尔曲线的最后一个控制点) 第u轴的0-l阶导数 设置成终止状态

a(l,n-第n项系数即最后一个控制点,u,m–最后一条轨迹) * sm(第m条轨迹的放缩系数)^(1-l) = d(l,u,m)规定的u轴终止状态的各阶导数

为什么会有 sj^(1-l)项呢，因为我们对贝塞尔曲线对t求导，对[(t-Tj)/sj]^n求导

= n*[(t-Tj)/sj]^n-1 * sj^-1, 其中n被归到a项中去了，[(t-Tj)/sj]^n-1是a中要求的形式，所以就多了一个sj^-1，而多项式前面正好有sj(在上面有 就是缩放)一项，所以求导后就是a*sj(1-1)。更高阶导数同理。 这里要强调一下控制点就是b(自变量0~1)前面所有系数乘起来的结果。

2 连续性约束

上条终点的各阶导数和下调起点的各阶导数相等

j条终点各阶导数 == j+1条终点的各阶导数

**我们直接设置j条终点和j+1条起点的各阶状态在贝塞尔曲线中的控制点系数，**贝塞尔曲线是一定经过第一个和最后一个控制点的

a(0,i,u,j) = c(i,u,j)

k = 0~n-1如果我们minimum snap需要保证到jerk的导数连续

a(k,n-第n项系数即最后一个控制点,u,j上条) * sj^(1-k) ==

a(k,0-第0项系数即第一个控制点,u,j+1下条) * sj+1^(1-k)

3 安全约束

贝塞尔曲线位置(0阶导) 控制点构成的凸包一定在规定的bounding box内 (即n阶贝塞尔曲线的n个控制点都在boundingbox内)

box(u,j)_mim<=c(i,u,j)<= box(u,j)_max

注意这里的 beta是 物理意义的坐标上下限再除了sj的！！！！！！

4 动力学约束

贝塞尔曲线1,2,3阶导数(v,a,j) 控制点构成的凸包一定在规定的动力学约束范围

贝塞尔曲线一阶导控制点系数 n*(c(i,u,j) - c(i-1,u,j))

贝塞尔曲线二阶导控制点系数 n*(n-1)(c(i,u,j) - 2c(i-1,u,j) + c(i-2,u,j))/sj

v(u)_min<=n*(c(i,u,j) - c(i-1,u,j))<=v(u)_max

a(u)_min<=n*(n-1)(c(i,u,j) - 2c(i-1,u,j) + c(i-2,u,j))/sj<=a(u)_max
