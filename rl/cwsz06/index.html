20 Phasic Policy Gradient

创建于 2022-02-10 · 最后修改于 2022-03-09 · cant

这个算法实现了我之前的想法，actor和critic共用一部分网络作为提取状态的深度信息的作用，有解决了之前的loss不好确定的问题。

actor和critic有一部分的联合网络的有点是能够共享状态的深度特征** 特别在输入状态的维度特别大的时候(比如输入的是一幅图像)共享网络的效果比不共享网络的效果好很多**，缺点是难以确定actor和critic两者优化的权重，同时优化两个目标可能会相互干扰，并且同时优化必须使用相同的数据、相同的数据重利用率，但实际策略网络特别是类PPO的on policy策略是不允许数据重用的(actor-critic中值函数不直接影响策略，而策略网络的变化直接影响表现，因此策略的sample reuse容忍度更低（类似于学习率不能过大），这在TD3中也有体现，TD3中同样发现了以更低的频率去更新策略网络训练更加稳定，表现更好

其实在TD3中actor网络的更新频率慢于critic网络也是因为这个原因)，而值网络特别是类DQN的Q网络是off policy是可以进行数据重用的。这就导致actor训练时使用和critic一样的数据和数据重利用率 将会导致actor的训练效果很差。

想改进PPO，经过实验发现PPO的策略网络在sample reuse(用过去的轨迹进行训练)后给训练带来负面影响(废话 PPO本就是on polciy策略才能保证策略单调变好 这样改相当于改成了off policy 效果肯定会变差)，但是PPO的critic网络在sample reuse后训练效果变的更好。

PPG中和其他Actor-Critic结构的网络一样使用了一个网络作为policy pi(actor)一个网络作为state value function V(critic)，使得两者训练阶段不会相互影响，又再增加了一个辅助阶段(知识蒸馏)，**将值函数网络的有用信息(V θv)传递给策略网络(V θpi),**既能避免两者训练过程中的相互干扰，同时共享了一部分表示信息，PPG能显著提高数据利用率。

PPG分为了两个阶段，策略阶段(Policy Phase)和辅助阶段(Auxiiary Phase)。策略阶段分别独立训练值函数和策略网络，优化目标与PPO一样。

Loss_pi = L_clip = E[min(rtAt,clip(rt,1-^,1+^)At)] +βentpopy pi 更新pi

At是GAE通过Vθv网络估计的价值来进行计算的

Loss_V = E[(Vθv(st) - Vtar t)^2/2] Vtar t是通过客观地累加环境返回的奖励计算得到的 更新V

(Loss_V指的的是value network的loss不是指的V θpi)

在此阶段需要存在 (st,Vtar t) 和 策略函数在st下所做分布pi(.|st)

在Loss_pi和Loss_V **经过optimizer优化后！**进行辅助阶段

Loss_joint = L_aux + β_clone*E[KL[pi_old(.|st),pi(.|st)]]

Loss_joint是单独去更新policy网络的

L_aux=E[(Vθpi(st) - Vtar t^2)/2]

Vtar t是通过客观地累加环境返回的奖励计算得到的

先来解释一下policy网络的结构，我们能看到policy网络有两个输出

class Policy_Model(nn.Module):
    def __init__(self, state_dim, action_dim):
        super(Policy_Model, self).__init__()

        self.nn_layer = nn.Sequential(
                nn.Linear(state_dim, 256),
                nn.ReLU(),
                nn.Linear(256, 128),
                nn.ReLU()
              ).float().to(device)

        self.actor_layer = nn.Sequential(
                nn.Linear(128, action_dim),
                nn.Tanh()
              ).float().to(device)

        self.critic_layer = nn.Sequential(
                nn.Linear(128, 1)
              ).float().to(device)

    def forward(self, states):
        x = self.nn_layer(states)
        return self.actor_layer(x), self.critic_layer(x)

policy中有个前置的nn_layer用于提取深度信息，再将深度信息分别输入到actor_layer得到pi分布和critic_layer得到Vθpi(st)

现在来分析一下这个Loss_joint，此Loss是单独用来更新策略网络pi的，其中

L_aux=E[(Vθpi(st) - Vtar t^2)/2] 是用于训练前置的深度信息提取网络nn_layer和critic_layer，但是由于policy是一体的训练

        self.policy             = Policy_Model(state_dim, action_dim)
        self.policy_optimizer   = Adam(self.policy.parameters(), lr = learning_rate)

L_aux训练了nn_layer和critic_layer优化了前置的特征提取网络，但是会影响actor_layer对最终动作的输出造成可能不好的影响，所以添加了β_clone*E[KL[pi_old(.|st),pi(.|st)]]–KL散度的惩罚，希望在优化前置特征提取网络的基础上，策略的变化越小越好。
