14 TRPO 6 共轭梯度法2

创建于 2022-02-07 · 最后修改于 2022-04-23 · cant

三个重要推论

1 第i步的梯度$ \triangledown_{x}f(x)|_{x=x_i} $与p0,p1,..,pi-1正交正交

证

k<i $ \begin{gathered} \triangledown_{x}f(x)|_{x=x_{i}}=Ax_{i}+b=A(x_{i-1}+\alpha_{i-1}p_{i-1})+b\\=Ax_{i-1}+\alpha_{i-1}Ap_{i-1}+b\\ =\triangledown_{x}f(x)|_{x=x_{i-1}}+\alpha_{i-1}Ap_{i-1} \end{gathered} $得到了一步迭代形式继续展开

$ \begin{gathered} \triangledown_{x}f(x)|_{x=x_{i}}=\triangledown_{x}f(x)|_{x=x_{i-1}}+\alpha_{i-1}Ap_{i-1}\\ \because x_k = x_{k-1} + \alpha_{k-1}p_{k-1}\\=A(x_{i-2}+\alpha_{i-2}p_{i-2})+b+\alpha_{i-1}Ap_{i-1}\\=A(x_{i-3}+\alpha_{i-3}p_{i-3}+\alpha_{i-2}p_{i-2})+b+\alpha_{i-1}Ap_{i-1}\\=...\\=A(x_{0}+\alpha_{0}p_{0}+...+\alpha_{i-2}p_{i-2})+b+\alpha_{i-1}Ap_{i-1}\\=Ax_0+b+\alpha_0Ap_0+\alpha_1Ap_1+...+\alpha_{i-1}Ap_{i-1}\\\triangledown_{x}f(x)|_{x=x_{0}}=Ax_0+b\\=\triangledown_{x}f(x)|_{x=x_{0}}+\alpha_{0}Ap_{0}+\alpha_{1}Ap_{1}+...+\alpha_{i-1}Ap_{i-1} \end{gathered} $

为了证明和所有pk正交需要缩回k+1这一层

等$ =\triangledown_{x}f(x)|_{x=x_{k+1}}+\alpha_{k+1}Ap_{k+1}+\alpha_{k+2}Ap_{k+2}+...+\alpha_{i-1}Ap_{i-1} $式两边左乘$ p_k^T $

$ \begin{gathered} p_k^T\triangledown_{x}f(x)|_{x=x_{i}}=p_k^T\triangledown_{x}f(x)|_{x=x_{k+1}}+\alpha_{k+1}p_k^TAp_{k+1}+\alpha_{k+2}p_k^TAp_{k+2}+...+\alpha_{i-1}p_k^TAp_{i-1}\\ \because p_i^TAp_j=0,i\neq j\\ p_k^T\triangledown_{x}f(x)|_{x=x_{i}}=p_k^T\triangledown_{x}f(x)|_{x=x_{k+1}} \end{gathered} $因为共轭梯度的定义第k步的步长是计算过的最优步长αk将pk这个方向误差更新完 第k步的优化方向是垂直于xk+1所在等高线的$ p_k^T\triangledown_{x}f(x)|_{x=x_{k+1}}=0 $

$ \therefore p_k^T\triangledown_{x}f(x)|_{x=x_{i}}=0 $得到$ \triangledown_{x}f(x)|_{x=x_{i}} $和前i-1步的优化方向 p0,p1,..,pi-1正交

2第i步的梯度$ \triangledown_{x}f(x)|_{x=x_i} $和前i-1步的梯度$ \triangledown_{x}f(x)|_{x=x_k};k=0,1,2,..,i-1 $正交

$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_{k}})^T\cdot \triangledown_{x}f(x)|_{x=x_{i}}\\ \because p_{i+1} = -\triangledown_{x}f(x)|_{x=x_{i+1}}-\sum_{k=1}^{i}\beta_kp_k\\ \therefore \triangledown_{x}f(x)|_{x=x_{k}} = -(p_k + \sum_{j=1}^{k-1}\beta_jp_j)\\=-(p_k + \sum_{j=1}^{k-1}\beta_jp_j)^T \cdot \triangledown_{x}f(x)|_{x=x_{i}} \end{gathered} $

由1可知$ \triangledown_{x}f(x)|_{x=x_{i}} $和前i-1步的优化方向 p0,p1,..,pi-1正交

所以$ \begin{gathered} -(p_k + \sum_{j=1}^{k-1}\beta_jp_j)^T \cdot \triangledown_{x}f(x)|_{x=x_{i}}\\=-(p_k^T \triangledown_{x}f(x)|_{x=x_{i}}+ \sum_{j=1}^{k-1}\beta_jp_j^T\triangledown_{x}f(x)|_{x=x_{i}})\\p_k^T\triangledown_{x}f(x)|_{x=x_{i}}=0,p_j^T\triangledown_{x}f(x)|_{x=x_{i}}=0 \end{gathered} $

证得第i步的梯度$ \triangledown_{x}f(x)|_{x=x_i} $和前i-1步的梯度$ \triangledown_{x}f(x)|_{x=x_k};k=0,1,2,..,i-1 $正交

3第i步的梯度$ \triangledown_{x}f(x)|_{x=x_i} $和前i-2步的优化方向p0,p1,..,pi-2共轭正交$ p_k^TA\triangledown_{x}f(x)|_{x=x_i}=0 $

计算df(xk+1)Tdf(xi)的结果

$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_{k+1}})^T\triangledown_{x}f(x)|_{x=x_i}\\=(Ax_{k+1}+b)^T\triangledown_{x}f(x)|_{x=x_i}\\ \because x_{k+1}=x_k +\alpha_kp_k\\=(A(x_k +\alpha_kp_k)+b)^T\triangledown_{x}f(x)|_{x=x_i}\\=(Ax_k+b+\alpha_kAp_k)^T\triangledown_{x}f(x)|_{x=x_i}\\ \because Ax_k+b=\triangledown_{x}f(x)|_{x=x_k}\\ =(\triangledown_{x}f(x)|_{x=x_k}+\alpha_kAp_k)^T\triangledown_{x}f(x)|_{x=x_i}\\ = (\triangledown_{x}f(x)|_{x=x_k})^T\triangledown_{x}f(x)|_{x=x_i}+\alpha_k(Ap_k)^T\triangledown_{x}f(x)|_{x=x_i}\\ (Ap_k)^T = p_k^TA^T,A^T=A\\ = (\triangledown_{x}f(x)|_{x=x_k})^T\triangledown_{x}f(x)|_{x=x_i}+\alpha_kp_k^TA\triangledown_{x}f(x)|_{x=x_i} \end{gathered} $

(1)当k=i-1时$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_i})^T\triangledown_{x}f(x)|_{x=x_i}\\ = (\triangledown_{x}f(x)|_{x=x_{i-1}})^T\triangledown_{x}f(x)|_{x=x_i}+\alpha_{i-1}p_{i-1}^TA\triangledown_{x}f(x)|_{x=x_i} \end{gathered} $

由2可知$ \triangledown_{x}f(x)|_{x=x_i} $和前i-1步的梯度正交

$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_i})^T\triangledown_{x}f(x)|_{x=x_i}\\ = \alpha_{i-1}p_{i-1}^TA\triangledown_{x}f(x)|_{x=x_i} \end{gathered} $2并没有说$ \triangledown_{x}f(x)|_{x=x_i} $是与自身正交的

所以$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_i})^T\triangledown_{x}f(x)|_{x=x_i} \neq 0\\ = \alpha_{i-1}p_{i-1}^TA\triangledown_{x}f(x)|_{x=x_i}\neq 0 \end{gathered} $

即$ p_{i-1}^TA\triangledown_{x}f(x)|_{x=x_i}\neq 0 $，df(xi)与pi-1并非共轭正交的

(2)当k<i-1时$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_{k+1}})^T\triangledown_{x}f(x)|_{x=x_i}\\= (\triangledown_{x}f(x)|_{x=x_k})^T\triangledown_{x}f(x)|_{x=x_i}+\alpha_kp_k^TA\triangledown_{x}f(x)|_{x=x_i} \end{gathered} $

由2可知$ \triangledown_{x}f(x)|_{x=x_i} $和前i-1步的梯度正交,k<i-1

所以$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_{k+1}})^T\triangledown_{x}f(x)|_{x=x_i}=0\\ (\triangledown_{x}f(x)|_{x=x_{k}})^T\triangledown_{x}f(x)|_{x=x_i}=0 \end{gathered} $

$ \begin{gathered} (\triangledown_{x}f(x)|_{x=x_{k+1}})^T\triangledown_{x}f(x)|_{x=x_i}\\= \alpha_kp_k^TA\triangledown_{x}f(x)|_{x=x_i}=0 \end{gathered} $时

得到了 $ \alpha_kp_k^TA\triangledown_{x}f(x)|_{x=x_i}=0 $即当k<i-1即k=0,1,2…k-2。df(xi)是与pk共轭正交的

由3可将$ p_{i+1}=-\triangledown_{x}f(x)|_{x=x_{i+1}}-\sum_{k\lt i+1}\frac{p_k^TA(-\triangledown_{x}f(x)|_{x=x_{i+1}})}{p_k^TAp_k}\cdot p_k $

因为$ \triangledown_{x}f(x)|_{x=x_i} $和前i-2步的优化方向p0,p1,..,pi-2共轭正交$ p_k^TA\triangledown_{x}f(x)|_{x=x_i}=0 $,可以得到$ p_k^TA\triangledown_{x}f(x)|_{x=x_{i+1}}=0 $k=1,2,..,i+1-2=i-1都是等于0

证得了优化方向的简化形式

$ p_{i+1}=-\triangledown_{x}f(x)|_{x=x_{i+1}}-\frac{p_i^TA(-\triangledown_{x}f(x)|_{x=x_{i+1}})}{p_i^TAp_i}\cdot p_i $

继续简化优化方向

由1中的推导部分得到

$ \begin{gathered} \triangledown_{x}f(x)|_{x=x_{i+1}}=\triangledown_{x}f(x)|_{x=x_{i}}+\alpha_iAp_i\\ Ap_i=\frac{\triangledown_{x}f(x)|_{x=x_{i+1}}-\triangledown_{x}f(x)|_{x=x_{i}}}{\alpha_i} \end{gathered} $带回到βi的表达式中

$ \begin{gathered} \beta_i=\frac{p_i^TA(-\triangledown_{x}f(x)|_{x=x_{i+1}})}{p_i^TAp_i}=-\frac{(Ap_i)^T\triangledown_{x}f(x)|_{x=x_{i+1}}}{(Ap_i)^Tp_i}\\= -\frac{(\frac{\triangledown_{x}f(x)|_{x=x_{i+1}}-\triangledown_{x}f(x)|_{x=x_{i}}}{\alpha_i})^T\triangledown_{x}f(x)|_{x=x_{i+1}}}{(\frac{\triangledown_{x}f(x)|_{x=x_{i+1}}-\triangledown_{x}f(x)|_{x=x_{i}}}{\alpha_i})^Tp_i}\\= -\frac{(\frac{\triangledown_{x}f(x)|_{x=x_{i+1}}-\triangledown_{x}f(x)|_{x=x_{i}}}{\alpha_i})^T\triangledown_{x}f(x)|_{x=x_{i+1}}}{(\frac{\triangledown_{x}f(x)|_{x=x_{i+1}}-\triangledown_{x}f(x)|_{x=x_{i}}}{\alpha_i})^T(-\triangledown_{x}f(x)|_{x=x_{i}}-\beta_{i-1}p_{i-1})}\\= -\frac{(\triangledown_{x}f(x)|_{x=x_{i+1}})^T\triangledown_{x}f(x)|_{x=x_{i+1}}-(\triangledown_{x}f(x)|_{x=x_{i}})^T\triangledown_{x}f(x)|_{x=x_{i+1}}}{\beta_{i-1}(\triangledown_{x}f(x)|_{x=x_{i}})^Tp_{i-1}-\beta_{i-1}(\triangledown_{x}f(x)|_{x=x_{i+1}})^Tp_{i-1}+(\triangledown_{x}f(x)|_{x=x_{i}})^T\triangledown_{x}f(x)|_{x=x_{i}}-(\triangledown_{x}f(x)|_{x=x_{i+1}})^T\triangledown_{x}f(x)|_{x=x_{i}}} \end{gathered} $由1、2结论

1 第i步的梯度$ \triangledown_{x}f(x)|_{x=x_i} $和前i-1步的优化方向p0,p1….,pi-1正交

2第i步的梯度$ \triangledown_{x}f(x)|_{x=x_i} $和前i-1步的梯度$ \triangledown_{x}f(x)|_{x=x_k};k=0,1,2,..,i-1 $正交

$ \begin{gathered} =-\frac{(\triangledown_{x}f(x)|_{x=x_{i+1}})^T\triangledown_{x}f(x)|_{x=x_{i+1}}}{(\triangledown_{x}f(x)|_{x=x_{i}})^T\triangledown_{x}f(x)|_{x=x_i}}\\ \beta_i=\frac{|||\triangledown_{x}f(x)|_{x=x_{i+1}}||^2}{||\triangledown_{x}f(x)|_{x=x_{i}}||^2} \end{gathered} $

证得了优化方向的最简形式

$ p_{i+1}=-\triangledown_{x}f(x)|_{x=x_{i+1}}+\frac{|||\triangledown_{x}f(x)|_{x=x_{i+1}}||^2}{||\triangledown_{x}f(x)|_{x=x_{i}}||^2}\cdot p_i $

步长计算简化

$ \alpha_i=-\frac{p_i^T\triangledown_{x}f(x)|_{x=x_{i}}}{p_i^TAp_i} $

将上面的简化形式$ p_{i+1}=-\triangledown_{x}f(x)|_{x=x_{i+1}}+\frac{|||\triangledown_{x}f(x)|_{x=x_{i+1}}||^2}{||\triangledown_{x}f(x)|_{x=x_{i}}||^2}\cdot p_i $代入

$ \begin{gathered} \alpha_i=-\frac{(-\triangledown_{x}f(x)|_{x=x_{i}}+\frac{|||\triangledown_{x}f(x)|_{x=x_{i}}||^2}{||\triangledown_{x}f(x)|_{x=x_{i-1}}||^2}\cdot p_{i-1})^T\triangledown_{x}f(x)|_{x=x_{i}}}{p_i^TAp_i}\\ =-\frac{(-\triangledown_{x}f(x)|_{x=x_{i}})^T\triangledown_{x}f(x)|_{x=x_{i}}+(\frac{|||\triangledown_{x}f(x)|_{x=x_{i}}||^2}{||\triangledown_{x}f(x)|_{x=x_{i-1}}||^2}\cdot p_{i-1})^T\triangledown_{x}f(x)|_{x=x_{i}}}{p_i^TAp_i} \end{gathered} $由推理1，2可简化为

$ \begin{gathered} \frac{(\triangledown_{x}f(x)|_{x=x_{i}})^T\triangledown_{x}f(x)|_{x=x_{i}}}{p_i^TAp_i}\\=\frac{||\triangledown_{x}f(x)|_{x=x_{i}}||^2}{p_i^TAp_i} \end{gathered} $

证得了最简的优化步长

$ \alpha_i=\frac{||\triangledown_{x}f(x)|_{x=x_{i}}||^2}{p_i^TAp_i} $

梯度计算简化

$ \begin{gathered} \triangledown_{x}f(x)|_{x=x_{i+1}}=Ax_{i+1}+b\\x_{i+1}=x_i+\alpha_i\cdot p_i\\ =A(x_i+\alpha_i\cdot p_i)+b\\ =Ax_i+b+\alpha_iA p_i\\ =\triangledown_{x}f(x)|_{x=x_{i}}+\alpha_iA p_i \end{gathered} $可由xi的梯度直接计算xi+1的梯度$ x_{i+1}=x_i+\alpha_i\cdot p_i $

def conjugate_gradients(Avp_f, b, nsteps, rdotr_tol=1e-10):
    x = zeros(b.size(), device=b.device)
    r = b.clone()# r = -df(x)|x=xi--- -dloss/dθ_old
    p = b.clone()# 初始的优化方向就是梯度方向 在后面迭代时会改为共轭梯度中的更新公式
    # f = G = gts-/\*stFs/2  g=dL/dθ|θ=θ_old F=d2Dkl待优化函数
    # 这里做了个近似 f =  r应该是df
    # r = -g = -dL 反推这题的f就是 f = L 没错就是我们在将L在θ_old展开到一次导前，还没有将限制条件 加入待优化公式中
    # 要优化的就是L
    # 在泰勒展开得到G之前 G的一次项和常数项来自于L 二次项来自于KL散度
    # 在优化时求df 将二次项忽略(将KL散度忽略 不对KL散度求导)
    # (KL散度可以直接展开成二次导项+更高次导项 将这个二次导项再求一次导数值很小可以忽略) 所以r = df= dL
    # 仅仅只是求r初值的时候忽略KL散度 在更新中要求Ap无法忽略散度(散度的二次导就是二次项A)
    rdotr = torch.dot(r, r) # ||r||^2--||df(x)|x=xi||^2
    for i in range(nsteps):# 10 最多只进行10次更新迭代 进行10次共轭搜索 理论上对N维问题求极小只用对N个方向都求出极小就行了
        # 虽然这个问题明显不止10维 维度的多少由网络的参数量决定， 因为共轭梯度在前几次的迭代中的提升最大
        # 所以我们可以只执行固定次数的共轭梯度更新 比如几百次(例子里的10次确实有点少了)
        Avp = Avp_f(p) # Avp_f函数中的v其实就是传入的这个p Ap -- A*pi
        alpha = rdotr / torch.dot(p, Avp) # 最优优化步长 alpha_i=||r||^2/pi_T*A*pi
        x += alpha * p # alpha 优化步长 p优化方向 网络参数更新 xi+1 = xi + alpha_i*pi
        r -= alpha * Avp # 梯度计算简化 df(x)|x=xi+1 = df(x)|x=xi + alpha_i*A*pi
        new_rdotr = torch.dot(r, r)# ||df(x)|x=xi+1||^2
        betta = new_rdotr / rdotr
        p = r + betta * p # 优化方向更新 pi+1 = - df(x)|x=xi+1 + ||df(x)|x=xi+1||^2/||df(x)|x=xi||^2 * pi
        rdotr = new_rdotr
        if rdotr < rdotr_tol:# 当前梯度已经很小了 接近于0 找到了一个局部极小值 提前结束
            break
    return x
