2 重要性采样

**引入MC重要性采样来实现将PG变为off-policy，**Q-learning线的算法都是off-policy的，Sarsa是on-policy的，这种区别主要是因为他们的目标不同，Q-learning,DQN目标都是求解Q(s,a)函数，我们只需要保证(s,a,r,s’)服从环境分布；Sarsa的目标是求解Qpi(s,a)即在策略pi下的Q函数，我们需要保证 (s,a,r,s’,a’)服从环境与当前策略pi分布。PG明显就是off-policy $ \triangledown _{\theta }J(\theta )=E_{\theta }[\triangledown _{\theta }ln\,P_{\theta}(\tau)R(\tau)];\tau\sim P_{\theta}(\tau) $**，**这个式子在1推导时有提到，$ P_{\theta}(\tau) $ 是在策略$ \pi _{\theta } $下采样到轨迹$ \tau $的概率。在$ \pi _{\theta } $下采样到m条轨迹并求出每条轨迹的$ \triangledown _{\theta }ln\,P_{\theta}(\tau_{i})R(\tau_{i}) $值，并求均值 $ E_{\theta }[\triangledown _{\theta }ln\,P_{\theta}(\tau)R(\tau)]\approx \frac{\sum _{i=0}^{m}\triangledown _{\theta }ln\,P_{\theta}(\tau_{i})R(\tau_{i})}{m} $ 作为期望$ E_{\theta }[\triangledown _{\theta }ln\,P_{\theta}(\tau)R(\tau)] $的估计。注意这个期望的定义我们必须要保证m条轨道$ \tau\sim P_{\theta}(\tau);i=1,...,m $是服从Pθ分布的。当训练到下一步网络的参数会被更新为θ’，之前采样的数据因为是在参数θ下得到的所以就不能用了，我们必须利用新策略$ \pi_{\theta^{'}} $去产生服从$ P_{\theta^{'}}(\tau) $分布的很多条轨迹，并用这些轨迹来求θ’对应的策略梯度。(这其实是非常浪费的，所以其实PG是一个会花很多时间来采样数据的算法，大部分时间都在采样数据。agent跟env互动得到轨迹，只能用轨迹更新一次网络参数，接下来就要重新去收集数据。) 我们想将on-policy变为off-policy,这样做就可以用另一个$ \pi_{\theta^{'}} $去跟环境做互动(θ’被固定了)。用θ’收集到的数据去训练θ，意味着我们可以把θ’收集到的数据用非常多次，可以用于更新θ非常多次。 策略梯度公式唯一妨碍我们采用off-policy的地方就只有一个，那就是用参数θ采样的轨迹$ \tau_{i} $不服从当前的$ P_{\theta^{'}}(\tau) $分布。 想求 $ \triangledown _{\theta }J(\theta )=E_{\theta }[\triangledown _{\theta }ln\,P_{\theta}(\tau)R(\tau)]=E_{\tau\sim P_{\theta }(\tau)}[f(\tau)] $ 但我们只有一组$ \tau_{i} \sim P_{\theta }(\tau_{i});i=1,...,m $的样本。我们掌握$ f(\tau) $的计算方法(θ已知可以直接视为轨迹涛的函数)，并且也掌握$ p(\tau)=P_{\theta}(\tau),q(\tau)=P_{\theta^{'}}(\tau) $的表达式(θ和θ’是已知的参数所以这两个分布可以直接视为轨迹涛的函数)。 ...

1 policy grident 基本原理

PG梯度算法的效果并不好。其核心原因就在于难以确定合适的步长。 策略网络，$ \pi (a|s) $输入量是s(状态)输出量是个n维向量(假设只有一种动作 线速度+角速度这种算两种动作)，对n维向量softmax后到n个不同的概率（其和为1），分别对应于最佳动作是各个a不同取值(这里的action的取值是离散的)的概率。设策略网络的参数为θ，则策略网络可记为$ \pi_{\theta } (a|s) $。$ \pi_{\theta } (a_{i}|s) $表示在s状态下最佳动作是ai的条件概率。对于n个ai对应的$ \pi_{\theta } (a_{i}|s) $相加结果总是1。 以分类问题的交叉熵loss为例 定义loss为训练集label与输出的predict向量的交叉熵。对于两个离散概率分布p,q。 交叉熵$ H(p,q)=\sum_{x}^{}p(x)lnq(x) $。在上图这个例子中predict输出为q = (0.78,0.15,0.3,0.4)，label为onehot编码后的p=(1,0,0,0)。则H = -ln(0.78)在训练过程中通过梯度法减小这个H交叉熵(即将是牛的0.78的这个概率变大)。 但是对于强化学习来说不存在label,但是有状态价值函数V和动作价值函数Q和动作优势函数A。如果策略采取的动作分布q使Q或A的评价变大则说明这个策略ok，减小则说明这个策略不行。 q = (0.58,0.39,0.001) ，这里有三个label (1,0,0) (0,1,0) (0,0,1)但与监督学习不同label不等于正确答案，对于这几个label A或Q函数对其有不同的评价，(1,0,0) +3 好,(0,0,1) -2不好，则我们策略输出q的分布要尽量与好的这个分布(1,0,0)接近。reward为正则接近reward为负则远离，接近或远离的程度由reward绝对值决定 reward 接近/远离某个label的程度。 记轨迹$ \tau:(s_{0},a_{0},r_{0},s_{1},a_{1},r_{1},....,s_{n},a_{n},r_{n}) $，$ P_{\pi _{\theta }}(\tau ) $代表在$ \pi _{\theta } $策略下出现轨迹$ \tau $**的概率。**比如$ \tau_{1}:(s_{0},a_{0},r_{0},s_{1},a_{1},r_{1},s_{2},a_{2},r_{2}) $则 $ P_{\pi _{\theta }}(\tau _{1})=P(s_{0})\pi _{\theta }(a_{0}|s_{0})P(s_{1}|s_{0},a_{0})\pi _{\theta }(a_{1}|s_{1})P(s_{2}|s_{1},a_{1})\pi _{\theta }(a_{2}|s_{2}) $ 其中$ P(s_{0}) $为初始状态的分布一般这是给定的。$ P(s'|s,a)=P_{s.s'}^{a} $状态转移概率， ...
