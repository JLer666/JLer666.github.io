9 TRPO 1 策略得分差的变式

在上一节中，我们介绍了自然梯度法。具体而言，我们原本以参数 θ在参数空间的距离来衡量策略之间的差别，但是这种度量会严重依赖于你人为设计的策略网络$ \pi_{\theta} $的结构。采用了费舍尔信息矩阵之后，就相当于用策略 $ \pi $之间的KL散度来衡量策略之前的差别。这样，策略之间的距离度量就不依赖于你的人为设计，这无疑是一个“更好的度量”。 在优化算法中(牛顿法)，我们可以用目标函数 的海森阵来更好衡量$ \pi $之间的差别，这个海森阵就是比参数空间的欧式距离更好的度量。但是求$ J(\pi_{\theta}) $关于θ的海森阵 对于强化学习来说这个计算量是无法接受的。所以NPG退而求其次用KL散度作为这种度量。最优化中的信赖域方法（Trust Region Method）和近似点方法（Proximal Point Method）类比于TRPO与PPO算法（KL penalty version）。它们背后的基本原理都是“更好地度量策略分布之间的距离”，而它们的实际表现形式都是“控制策略更新的步长”、“控制单调提升”。 为了讲清TRPO需要先讲TRPO的前作Approximately Optimal Approximate， 这篇提出一种Conservative Policy Iteration algorithm，可以在较小步数内，找到近似最优策略(Approximately Optimal Policy)。 状态价值函数，动作状态价值函数的TD定义是 $ V_{\pi}(s_{i})=E[\sum_{i=0}^{\infty}\gamma ^{i}R(s_{i+1})]=R(s_{i})+\gamma E[V_{\pi}(s_{i+1})|s_{i}] $ 为当前状态为st后未来得到的总收益的期望。 $ Q_{\pi}(s_{i},a_{i})=E[\sum_{i=0}^{\infty}\gamma ^{i}R(s_{i+1},a_{i+1})]=R(s_{i},a_{i})+\gamma E[Q_{\pi}(s_{i+1},a_{i+1})|s_{i},a_{i}]=R(s_{i},a_{i})+\gamma E[V_{\pi}(s_{i+1})|s_{i},\pi] $为当前状态是st在此状态下采取动作at后未来得到的总收益的期望。 $ A_{\pi}(s_{t},a_{t})=Q_{\pi}(s_{t},a_{t})-V_{\pi}(s_{t})=E_{s_{t+1}\sim P(s_{t+1}|s_{t},a_{t})}[R(s_{t},a_{t})+\gamma V_{\pi}(s_{t+1})-V_{\pi}(s_{t})] $优势函数之前有讲过就是动作状态奖励-状态奖励，减去一个baseline来突出这个动作at的真实作用是好还是坏。 定义在策略下的未来状态分布 又叫折扣访问频率。 $ d_{\pi,D}(s)=P(s_{0}=s)+\gamma P(s_{1}=s) +\gamma^{2} P(s_{2}=s) + ... $表示在策略和初始分布D=P(s0)下状态s被访问到的频率这个频率是带折扣的。—E下标可以理解为条件，在这个条件下求相应对象的期望值。 先定义一下$ \begin{gathered} Q_{\pi}(s_{t},a_{t})=E_{s_{t+1},a_{t+1},...\sim \pi}[\sum_{i=0}^{\infty}\gamma ^{i}R(s_{t+i},a_{t+i})]\\ V_{\pi}(s_{t})=E_{a_{t},s_{t+1},a_{t+1},...\sim \pi}[\sum_{i=0}^{\infty}\gamma ^{i}R(s_{t+i},a_{t+i})] \end{gathered} $ 设$ \pi $为老策略$ \pi^{'} $为新策略，$ \eta(\pi)=E_{\tau\sim\pi}[\sum\gamma ^{i}R(s,a)] $为在老策略$ \pi $下采样到的轨迹涛的总奖励期望，$ \eta(\pi^{'})=E_{\tau\sim\pi^{'}}[\sum\gamma ^{i}R(s,a)] $为为在新策略下采样到的轨迹涛(和之前的轨迹是不一样的)的总奖励期望。观察新策略是否优于老策略有一个很明显的指标就是将新老策略的得分相减大于0说明策略有提升，$ \eta(\pi^{'})-\eta(\pi)\gt 0 $ ...

自然梯度法计算流程 1对模型进行正向传播计算$ L(\theta)=-ln\,p(x|\theta) $在强化学习改进的PG中应该是$ L(\theta)=-\sum_{i=0}^{m}\sum_{t=0}^{T-1}A(a_{i,t},s_{i,t})ln\,\pi_{\theta}(a_{i,t}|s_{i,t})/m $ 2对L求梯度$ \triangledown_{\theta}L(\theta) $ 3计算经验费舍尔信息阵 $ E[\triangledown log\,p(x|\theta)\triangledown log\,p(x|\theta)^{T}]\approx F=\sum_{i=1}^{N}\triangledown log\,p(x|\theta)\triangledown log\,p(x|\theta)^{T}/N $ $ \underset{y=p(x|\theta)}{E}[\triangledown ln\,y\triangledown ln\,y^{T}]\approx F $ 将p(x|θ)这个整体看作是个随机变量，并对以这个随机变量组成的式子求期望。 (假设在θ参数下xi出现的概率都相等则协方差均值就是这个期望的近似) 在强化学习中的$ p(x|\theta) $应该为$ p(a|s,\theta)\equiv \pi_{\theta}(a|s) $这样计算出来的F应该是$ F(\theta)=\sum_{i=1}^{M}p(s_{i}|\pi_{\theta})\sum_{j=1}^{N}\triangledown log\,\pi_{\theta} (a_{j}|s_{i})\triangledown log\,\pi_{\theta} (a_{j}|s_{i})^{T}/N $，$ p(s_{i}|\pi_{\theta})\equiv p_{\theta}(s_{i}) $为在策略pi theta下出现状态si的概率(这个概率其实非常难求(MC采样后统计?) 在PG中也遇到了 在这无法忽略求这个概率)。这个F阵很难求 4计算自然梯度 $ \widetilde{\triangledown_{\theta}}L(\theta) = F^{-1}\triangledown_{\theta}L(\theta) $** 矩阵逆也很难求** 5更新参数 $ \theta^{'}=\theta + d =\theta - lr\widetilde{\triangledown_{\theta}}L(\theta) $ 总结 待优化函数为对数似然函数希望优化参数使似然概率最大，在所有可能由参数θ实现的策略似然函数构成的空间中移动(在似然函数空间上移动 而不仅仅是在θ参数空间上移动)，由于策略似然函数本身是一个概率分布，我们称这个空间为分布空间，因此在这个分布空间而不是参数空间中采取最陡峭的下降方向对优化更有意义，我们需要定义一个分布空间中的二范数距离概念来衡量不同似然函数之间的距离(类比θ参数空间中用欧式距离作二范数来衡量不同参数θ之间的距离)。 我们使用KL散度来作为分布空间的距离衡量量。将KL散度作为对数似然函数的优化限制，再将优化限制利用拉格朗日乘数法直接加到待优化函数中，KL散度直接计算需要知道θ’这个我们优化完了才知道的参数，我们无法直接计算只能将θ’=θ+d中的d作为未知量，将KL散度泰勒展开展开成含d的式子，但由于KL散度的泰勒展开的无导数项，一阶导数项都为0所以至少展开到二次导数项。 求二次导就需要求海森阵但计算量太大，费舍尔信息阵与海森阵有关计算量稍微少点，所以用FIM替代海森阵计算KL的二次导数项，自然梯度的本质就是将KL散度约束直接加到待优化的式子中，并将KL散度利用FIM阵的计算方法计算其二次展开含d的近似项代替KL散度本身，待优化式子对d求导求出最优的参数更新量d=dθ。 参考 https://agustinus.kristia.de/techblog/2018/03/14/natural-gradient/ 本人水平拉跨，哪里写不对的地方请大佬们赐教

5 自然梯度法NPG 1 海森阵与费舍尔信息量

在策略梯度法中，策略$ \pi_{\theta} $和它的参数θ是一一对应的。所以，我们把θ当成自变量，把期望效用J(θ)当成是θ的函数。在算法中，我们要预先设定一个步长lr，然后迭代地计算J关于θ的梯度，并让θ沿着梯度方向前进给定的步长lr。在实际运行策略梯度法的时候，有时会出现忽然的“模型崩溃”。比如我们发现随着训练迭代，模型的效果正在稳步提升，但在某一步中模型的效果忽然大幅下降，然后几乎又要从头再来。发生这种情况的主要原因是因为我们人为设定了步长并一直保持不变。在有的θ处沿着梯度前进lr会使得目标函数充分上升，有的θ处可能上升的不充分，而有的θ处沿着梯度前进lr或许会“走过”了最优点，使得目标函数大幅下降。在每个θ处将步长都统一设定为lr不变无疑是不合理的。换句话说，用策略的参数空间中的距离作为策略之间的度量是不合理的。对于在参数空间中θ之间距离1为的参数θ’，对应的$ 4 信赖域方法与近似点方法

梯度算法的效果并不好。其核心原因就在于难以确定合适的步长。让策略$ \pi_{\theta} $沿着$ J(\theta) $上升的方向，向前前进给定的步长lr*dJ/dθ。Actor-Critic方法仅仅相当于提供一种更好的方法计算梯度（可以减少估计梯度的方差），但其仍然是一个梯度上升法。然而，在很多优化问题中，梯度(下降or上升)算法的效果并不好。其核心原因就在于难以确定合适的步长。 如果说PG对应于优化中的梯度下降法的话，那么TRPO和PPO确实就对应于优化中的信赖域方法和近似点法。 梯度下降法求函数最小值：梯度下降法邻域内一次展开近似，并通过公式直接求得这个一次函数在邻域内的最值点就是$ x_{k+1}=x_{k}-lr\cdot g(x_{k}) $这条公式，因为邻域的限制无法一次求到最值，需要不断迭代更新。 f(x)在当前位置xk一阶泰勒展开f(x)=f(xk)+g(xk)(x-xk)，沿着梯度方向g(xk)下降就可以最快地下降，但是**一阶泰勒展开只适用于很小的邻域，**在较大的范围内会不准确，所以人为设定步长lr只要lr不太大则f(xk-lr*g(xk))应该比f(xk)更小。 我们之前的PG与AC方法相当于没有g(x)的表达式(dJ/dθ的显示表达式)，而是用不同的方法通过数据估计得到了g(x)的估计值(采用诸如GAE的技巧权衡g(x)的偏差和方差)。 这种方法是最简单的梯度法(线搜索)，但大部分线搜索方法都不太适合求解$ J(\theta) $这种很复杂的函数的优化。梯度法有个很大的缺点对于病态问题收敛速度非常慢例如$ f(x)=x^{T}H x $当H矩阵的条件数很大时其优化路径会呈现出S型走位需要多步才能达到最优点，即使采取精确搜索，找到梯度方向上的极值点任然需要多步才能到达最优点。 为了解决梯度法的缺点，一种方法是采用牛顿法在xk位置二阶泰勒展开 f(x) = f(xk)+g(xk)(x-xk)+(x-xk)TH(xk)(x-xk)/2 H为二阶梯度阵 对于$ f(x)=x^{T}H x 3 添加策略熵来引入随机探索，以及一些补充

DQN采用的是-greedy的探索方法，1-的概率按照argmaxQ(s,a)选择a，而以的概率随机选择一个a。PG和DQN是完全不同的，它没有一个充当环境估计的Q网络来估计某个客观价值，而是要直接输出最佳策略。PG需要我们随机采样很多轨迹，才能求出$ J_{\theta^{'}}(\theta) =E_{(a^n_{t},s^n_{t})\sim\theta^{'} }[\frac{\pi_{\theta}(a^n_{t}|s^n_{t})}{\pi_{\theta^{'}}(a^n_{t}|s^n_{t})}\cdot A_{\theta^{'}}(s^n_{t},a^n_{t})] $这个期望的较准确的估计。我们希望采样出的轨迹更加多样，这样求出来的这个期望才稍微准确些。 策略网络天然就具有探索的方式–它输出的本来就是的概率，我们可以根据这个策略概率分布去随机抽样a,则得到的涛自然就是具有多样性。但是这样的探索力度还是有所欠缺(在训练的后期很多$ \pi_{\theta}(a|s) $接近1，也就确定了策略不再探索)。 熵函数定义为$ H(s)=\sum{_{a}}\pi_{\theta}(s,a)ln\;\pi_{\theta}(s,a) $，表示面对输入状态s时，策略网络输出的a的概率分布的熵。若a的概率分布越均匀，熵越大，越混乱，采取的动作越随机，它决策中(s,a)越丰富，决策出来的轨迹就越多样。设在策略$ \pi_{\theta}(s,a) $下状态s的分布为$ P_{\theta}(s) $。定义策略函数的熵为不同状态下熵的期望值: $ E_{\theta}[H(s)]=\int_{s}P_{\theta}(s)H(s)ds $ 向待优化函数中增加这一鼓励探索的熵函数 $ J_{\theta^{'}}(\theta) =E_{(a^n_{t},s^n_{t})\sim\theta^{'} }[\frac{\pi_{\theta}(a^n_{t}|s^n_{t})}{\pi_{\theta^{'}}(a^n_{t}|s^n_{t})}\cdot A_{\theta^{'}}(s^n_{t},a^n_{t})]+\alpha E_{\theta}[H(s)] $我们希望J越大越好也隐含了希望策略的熵越大越好(探索的越多越好)，最大化总奖励的同时希望决策也同样具有多样性。α越高，就代表我们越重视多种不同的经验，越会努力去尝试让自己人生丰富多彩。 无任何trick的PG程序里 reward 中保存着G0,G1,..Gt,…GT for log_prob, reward in zip(policy.saved_log_probs, rewards): policy_loss.append(- log_prob * reward) # optimizer优化是将loss极小化 而我们是想得到最大奖励 所以将loss = -log_prob*reward将loss极小化就是将log_prob*reward极大化 optimizer.zero_grad() policy_loss = torch.stack(policy_loss).sum() # 求总loss policy_loss.backward() optimizer.step()# 优化 # 之前学的笔记上都是 dJ(θ)/dθ的公式 而我们现在要写的 policy_loss是J(θ)所以要反推一下!!!!!!! # d sum_loss/dθ = d Σ(当前eps的每一步)(- log_prob * reward)/dθ = Σ(当前eps的每一步)(- d log_prob/dθ * reward) # 等同于Σ(当前eps的每一步)(- d log pi(w)(a|s)/dθ * Gt) 连续动作PG ...
