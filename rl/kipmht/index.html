15 TRPO 7 TRPO 算法流程

创建于 2022-02-09 · 最后修改于 2022-04-24 · cant

下面提出一种不用计算海森阵的优化方法

$ f(x+\Delta x)\approx f(x)+\triangledown f(x)^T+\triangledown x^T H(f)\triangledown x/2 $

在牛顿法中我们必须计算海森阵的逆从而计算出下个参数值,但是利用共轭梯度则我们不再需要计算这个海森阵的逆。

$ f(x+\alpha \cdot p)\approx g_x(v)=f(x)+\triangledown f(x)^Tv+\triangledown v^T B\triangledown v/2;v=\alpha \cdot p,B=H+\lambda I $一般海森阵是不确定的f可能不存在最小值，并且当v太大后上面的这个展开的置信度降低，因此取B=H+/\I，/\被称为阻尼系数，Bv=Hv+/\v表示费舍尔向量积(Fisher Vector Product)。

$ (Hv)_i=\sum_{j=1}^{N}\frac{\partial^2f(x) }{\partial x_i\partial x_j}\cdot v_j=\triangledown \frac{\partial f(x)}{\partial x_i}\cdot v $

牛顿法中最小化f的迭代方法是

$ x_{i+1}=x_i-H(f)^{-1}|_{x=x_i}\cdot\triangledown f(x)|_{x=x_i} $

在共轭梯度的更新求新的优化方向中不需要求KL散度的二阶导H，也不需要求二阶导的逆H^-1(牛顿法中要)，要求的是Hv(Ap)这个矩阵和向量(更新方向)的乘积，经过多次迭代后能得到一个较优的优化方向，求Hv(v为任意向量)有Fisher vector product这种快速算法来求解。

下面先将我们的问题重新描述一遍$ \begin{gathered} \underset{\theta}{max}(\triangledown_{\theta} L_{\theta_{old}}(\theta)|_{\theta=\theta_{old}})^T\cdot(\theta - \theta_{old})\\s.t.(\theta - \theta_{old})^T F (\theta - \theta_{old})/2 \leqslant \delta \end{gathered} $

$ \underset{\theta}{max}(\triangledown_{\theta} L_{\theta_{old}}(\theta)|_{\theta=\theta_{old}})^T\cdot(\theta - \theta_{old})-\lambda((\theta - \theta_{old})^T F (\theta - \theta_{old})/2 - \delta) $其中$ \triangledown_{\theta} L_{\theta_{old}}(\theta) $在上面写过表达式，维度时[K,1]其中K为策略网络的总参数量(将网络参数打平 θ代表总参数的集合 维度也为[K,1])所以$ (\triangledown_{\theta} L_{\theta_{old}}(\theta)|_{\theta=\theta_{old}})^T\cdot (\theta - \theta_{old}) $=[1,K][K,1]=1是个常量。F的维度为[K,K]所以约束条件的维度也为[1,K][K,K]*[K,1]=1。

用s代表dθ，用g代表$ \triangledown_{\theta} L_{\theta_{old}}(\theta) $，同时因为$ \lambda \cdot \delta $为一个常数从待优化的式子中去掉

得到简化后的待优化式子$ G=g^Ts-\lambda s^T Fs/2 $

注意虽然我们定义了s代表dθ =θ-θ_old，s的方向是最优的但是值可能偏大，我们需要满足每次参数更新的幅度在我们的规定范围内，所以s需要乘上一个权值β保证参数更新的幅度在我们的控制范围内。

在求步长时我们将dθ重新定义为βs去求在最优方向上满足约束条件的最大步长(注意对于dθ的意义改变并没有关系 因为上面求的时最优方向 在方向上乘上常数并不会导致方向变化)

dθ=βs代入下式得到步长的最大值

$ \begin{gathered} (\theta - \theta_{old})^T F (\theta - \theta_{old})/2 \leqslant \delta\\ \beta s^TF\beta s \leqslant 2\delta\\ \beta \leqslant \sqrt{\frac{2\delta}{s^TFs}} \end{gathered} $

TRPO的程序流程

1 多线程用policy 采集轨迹，采集的是done的完整轨迹，将轨迹加入经验池中。

(看RL\5TRPO&NPG\TRPO\PyTorch-RL-master代码还是on policy的感觉，每次采集完轨迹sample一个batch 用来更新后其他的所有经验都抛弃了 不再用了，TRPO PPO算法是on policy的，虽然都用了important sampling 但是都是用上步θ_old来采集轨迹 并没有用更早的策略来采集轨迹 在更新时也没有用比θ_old更老的策略采集的轨迹来更新最新参数 off policy是用任意时刻参数采集到的轨迹都可以拿来更新 single path(on policy))

2 sample一个batch的轨迹，求这个轨迹的advantages

def estimate_advantages(rewards, masks, values, gamma, tau, device):
    rewards, masks, values = to_device(torch.device('cpu'), rewards, masks, values)
    tensor_type = type(rewards)
    deltas = tensor_type(rewards.size(0), 1)
    advantages = tensor_type(rewards.size(0), 1)

    prev_value = 0
    prev_advantage = 0
    for i in reversed(range(rewards.size(0))):
        deltas[i] = rewards[i] + gamma * prev_value * masks[i] - values[i]
        advantages[i] = deltas[i] + gamma * tau * prev_advantage * masks[i]
        prev_value = values[i, 0]
        prev_advantage = advantages[i, 0]
    returns = values + advantages
    advantages = (advantages - advantages.mean()) / advantages.std()
    advantages, returns = to_device(device, advantages, returns)
    return advantages, returns

3 使用共轭梯度法迭代求出 此步最佳的更新方向，共轭梯度迭代的过程本身就是不断求共轭方向和最优步长的过程，将每次迭代的最优步长最优方向累加得到此步参数的更新方向s(stepdir)， 这里是将共轭梯度一次更新能直接找到当前方向的极小值 一次直接将这个方向更新完，下个方向与之前的所有方向正交，经过一定次数的迭代后x中累加的和就是最优的那个下降方向。

对于natural 中的 下降方向是F-1g, 牛顿法终点 下降方向是 H-1g。H的计算量很大，H-1的计算量更大 不可能计算。但是在共轭梯度法中不需要计算H或H-1要计算的是Hv 计算Hv可以通过Fisher Vector Product来快速计算 所以是应用共轭梯度法来求优化方向。 H为海森阵 F为FIM信息阵

回溯线搜索 Backtracking line search

在已知的搜索方向上先设置一个初始步长(1*fullstep) 如果步长太大了 则缩减步长 直到合适为止。 fullstep 由KL散度的最大值δ限制，参数更新只能在

dθ<fullstep 的范围内更新(fullstep 就是trust region的最大的这个范围)。通过Backtracking line search 从最大更新幅度fullstep 开始搜索 更新参数后得分能提升到期望得分的dθ，然后更新dθ。更新后没达到期望的提升则等比例缩小参数更新幅度(dθ/2),直到达到满足期望的提升幅度

BLS中要求 更新后f-原f <= 步长(stepfrac )*c(accept_ratio )m(m = 优化方向Tdf = expected_improve )

由于做的是梯度上升求最大值所以上面的这个不等式要变号(上面这个不等式用于梯度下降) 再将符号都替换掉得到
