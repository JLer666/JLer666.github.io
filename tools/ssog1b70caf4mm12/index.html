ObserveEnvironmentChange 环境更新

plmap

plgraph update

先构造所有row(左到右 之间没有属性检查) -> 建立row前后拓扑 (row拓扑非常严格要求前后继的大量属性都要一致)-> 基于row拓扑泛洪得到用于构造单个block的所有lane -> 构造block -> 在构造block中构造node(单列) 单个node的属性一定一样(因为row的前后继严格检查)，同时加上nodes的前后左右拓扑

有点像lane包

BuildRamps

ramp理解为进出高速HIGHWAY的闸道是重要的汇入或者分流节点。分为ENTRANCE_RAMP(merge)和EXIT_RAMP(split)

ramp的构造还有很多不懂，以后对照着地图可视化看吧.ExitRamp逻辑较EntranceRamp简单清晰很多

BuildIntersections 和 UpdatePatch这部分目前被注释了

UpdateSegments

给segment设置属性，包括segment的左右num，segment是否是进出ramp属性,merge区域属性。很多merge的处理看不懂

FrameContext构造

其中更新上帧过渡态Transition包含，from/to/time/reason 状态机

StateType from_state{StateType::DEFAULT};
StateType to_state{StateType::DEFAULT};
Timestamp transition_time; // timestamp when to_state start
TransitionReason reason{TransitionReason::EMPTY};

enum class StateType { LANE_FOLLOW, LANE_CHANGE, DEFAULT = LANE_FOLLOW };

// transition reason
enum class TransitionReason {
  EMPTY,
  RESET,
  START_LANE_CHANGE,
  FINISH_LANE_CHANGE,
  CANCEL_LANE_CHANGE_FROM_LEFT,
  CANCEL_LANE_CHANGE_FROM_RIGHT
};

如果非启动reset状态，存在上帧的决策。更新上帧决策rote对应的各种lane
