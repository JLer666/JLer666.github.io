1 安装vim-plug

不要用他github主页上提供的方法下载，没翻q下不了。直接在home目录下

git clone https://github.com/junegunn/vim-plug

mkdir -p ~/.vim/autoload/

cp ~/vim-plug/plug.vim ~/.vim/autoload/plug.vim

2 安装插件

在下面网站查找需要的vim插件

https://vimawesome.com/

编辑 ~/.vimrc 文件中的内容，比如安装“vim-cpp-enhanced-highlight” 插件

set number

call plug#begin(’~/.vim/plugged')

Plug ‘octol/vim-cpp-enhanced-highlight’

call plug#end()

更新后,打开一个新的vim窗口在其中输入命令

:source ~/.vimrc

:PlugStatus #查看插件状态

:PlugInstall #安装之前在配置文件中声明的插件

打开 vim 使用命令 :PlugInstall 插件

打开 vim 使用命令 :PlugClean 插件

所有插件的都是在Github上面获取的 https://blog.51cto.com/u_11555417/2150626#

https://zhuanlan.zhihu.com/p/360981919

vscode安装

去官网获取下载的链接地址，如：

https://az764295.vo.msecnd.net/stable/30d9c6cd9483b2cc586687151bcbcd635f373630/code_1.68.1-1655263094_amd64.deb

改为用国内的镜像下载

修改其中的主机域名：az764295.vo.msecnd.net为 vscode.cdn.azure.cn，即

https://vscode.cdn.azure.cn/stable/30d9c6cd9483b2cc586687151bcbcd635f373630/code_1.68.1-1655263094_amd64.deb

可以直接命令在ubuntu中vscode叫code

sudo snap install code –classic

snap商店中下载的有问题 无法使用中文输入法 卸载重新安装官方版本

sudo snap remove –purge code

插件安装，在vim中执行

:PlugInstall
