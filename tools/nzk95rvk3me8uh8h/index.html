版本是 0.17.2

Dev Container 里已自带，手动安装可以参考：https://github.com/kiron1/bazel-compile-commands

安装好后，在 Mantastyle 项目根路径下运行：

bazel-compile-commands --replace=-fno-canonical-system-headers= //...

需要等待几十秒，根路径下会生成 compile_commands.json

注意，每当目标的构建规则修改时，要重新运行上面这行命令

推荐在user_custom.sh里搞一个alias以简化命令👆，例如：

echo "alias bazel-lsp=\"bazel-compile-commands --replace=fno-canonical-system-headers= //...\"" >> $HOME/.bashrc

这样以后用在终端里用bazel-lsp替代上面一长串即可。

想看某模块的 Intellisense 需要先 bazel build该模块的所有构建目标，比如如果想看 src/simulator路径下 .h/.cc文件的 Intellisense，需要先调用

bazel build //src/simulator/...

或者也可以直接调用来编译所有构建目标，第一次调用可能要花费几分钟

bazel build //src/...
