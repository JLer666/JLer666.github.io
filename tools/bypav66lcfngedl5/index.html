bash downloaded.sdk

待开发工程放在src目录下

crmake默认编译优化选项为-O2 -s (最大程度优化代码)，自己调试时可在Cmakelist中添加add_compile_options("-g -O0") 不优化代码。但注意在代码合并时移除此选项。

使用ccache提高编译速度

在build文件夹中创建ccache文件夹

写进bash中

export CCACHE_DIR=/cowarobot/build-docker/.ccache

ccache -M 15G

ccache -s 看cache保存目录

ccache -C 清空ccache

crmake configure -DCMAKE_BUILD_TYPE=Debug

crmake -j6

如果修改后的文件结构发生变化需要先

crmake clean

再重新configure

有些头文件为了提供给其他人，在上次编译成功时会保存到build_docker/crpilot-x86_v2.4/include中，编译时也会检查这些头文件，当文件结构发生变化后，要将这里面的部分文件也删除，否则其中的文件依旧会变更前的内容。

sdk版本变化后需要从以下链接先将最新sdk下载(养成好习惯将老sdk备份 备份和替换的都是指的buid-docker/crpilot-x86_v2.4中除3rd链接外的其他所有东西)

http://crpilot.sandbox.cowarobot.cn/x86_v2.4/

将下载好的内容直接替换

在编译时新sdk可能缺一些lib文件，去老sdk中找直接替换

/usr/bin/ld: 找不到 -lnode

/usr/bin/ld: 找不到 -ltask

同时可能要更新simultor，下载后直接解压即可，下次运行仿真时直接使用新的可执行文件即可
